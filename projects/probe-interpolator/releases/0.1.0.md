# Probe Interpolator v0.1.0

Release date: 2026-07-20
Package: probe-interpolator-0.1.0-amd64-installer.exe

## Summary

首次发布。将 5 孔 / 3 孔 / 7 孔探针 PRB 插值整合为单一桌面程序，
取代旧的独立程序 `projects/five-hole-interpolator` 与 `projects/three-hole-interpolator`。

## Added

### 整合架构

- **启动选择页**：3 个卡片按钮（5 孔 / 3 孔 / 7 孔），session-locked（重启后切换探针类型）。
- **共享 UI 框架**：三个工作区组件遵循同一设计语言（顶部标题栏 / 信息卡片 / 标签页 / 状态栏），
  每个探针有独立的工作区组件（`FiveHoleWorkspace.vue` / `ThreeHoleWorkspace.vue` / `SevenHoleWorkspace.vue`），
  通过 `App.vue` 动态 `import()` 懒加载。
- **共享算法包**：直接引用 `shared/algorithms/go/{fivehole,threehole,sevenhole}/interpolation`，
  不再为每个探针维护独立的算法实现。

### 探针选择器与并发安全

- `probe_selector.go` 基于 `sync.RWMutex` 实现 `GetActiveProbe` / `SetActiveProbe` 并发安全。
- 每个 probe 类型有独立 state 结构（含自己的 `sync.RWMutex`），避免锁混用。
- 5 孔 / 3 孔 / 7 孔 state 互相隔离，单 probe 加载 PRB 不影响其他 probe。

### 7 孔探针端到端实现

- **后端**：`seven_hole_types.go` / `seven_hole_service.go` 提供 8 个 Wails 方法
  （`LoadSevenHolePrbFiles` / `IsSevenHolePrbLoaded` / `GetSevenHolePrbFiles` / `GetSevenHoleValidRange`
  / `CalculateSevenHole` / `BatchCalculateSevenHole` / `ImportSevenHoleCsvData` / `OpenSevenHoleHelpDoc`）。
  所有类型加 `SevenHole` 前缀避免 Wails binding 生成冲突。
- **适配层**：`adapters/seven-hole.ts` 桥接 Wails bindings 与 Vue 组件，
  统一 `[GenericResponse, Data]` 元组返回，组件无需 try/catch。
- **工作区**：`SevenHoleWorkspace.vue` 实现 7 个压力输入 + ValidRange 显示 + 分区判定结果表格。
- **测试套件**：`seven_hole_service_test.go` 11 个测试覆盖内区/外区插值、批量计算、
  并发安全（20 goroutines + -race）、PRB 加载、ValidRange 查询等场景。
  使用算法包 golden test data（`boundary.json` 481 个边界用例）作为权威输入输出对。

- `docs/five-hole-用户说明书.html`（从旧 5 孔项目迁移）

## Behavior

### 5 孔 / 3 孔工作区（与旧独立程序完全兼容）

- PRB 文件格式：兼容。
- CSV 输入格式：兼容（含 PressureMode 列）。

### 7 孔工作区（spec §1.1 / §2.2 约束）

- **强制表压输入**：所有 P1~P7 必须为表压（gauge），不提供 PressureMode 切换开关。
  绝压数据需在导入前由用户自行转换（表压 = 绝压 - 大气压）。
- **PRB 文件命名**：必须为 `1.prb`~`7.prb`，basename 决定扇区角色
  （7.prb=内区 ±30°，1~6.prb=外区扇区 n，覆盖 30°~60° + 60° 方位角）。
- **角度语义反转**：α=侧滑角（sideslip）、β=迎角（angle of attack），与 5 孔相反。
  CSV 导出表头明确标注 `α(°) 侧滑角` 和 `β(°) 迎角`，避免混淆。
- **结果字段**：含 α / β / Ma / V / P0 / Ps，**不含** Vx/Vy/Vz 速度分量（5 孔有，7 孔无）。
- **CSV 输入**：必含 P1-P7 + Patm + Tatm 共 9 列，全部必需，不含 PressureMode 列。
