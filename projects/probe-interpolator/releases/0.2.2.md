# Probe Interpolator v0.2.2

Release date: 2026-08-05
Package: probe-interpolator-0.2.2-amd64-installer.exe

## Summary

三孔探针插值算法新增气流速度 Velocity 输出，为三孔探针风洞验证提供"速度误差范围"验收对象。本次发布共享算法包与前序小程序端口同步（同源对齐），probe-interpolator 桌面端重新打包以体现新字段。

## User-visible Changes

- 三孔插值结果新增 `Velocity` 字段（m/s），由马赫数与大气温度经 `V = Ma · sqrt(γ · R · T_K)` 推导（R=287 J/(kg·K)，γ 复用 calcGamma 温度修正）。
- 业务背景：三孔探针风洞验证需要"速度误差范围"作为验收指标，原先算法只输出 Ma，调用方需各自离线换算 V，跨实现一致性无法保证。
- 兜底语义：Velocity 严格跟随 MachNumber——Ma 有效或兜底（initMa/currentMa）时给出对应速度，Ma 为 0/NaN（输入非法、calcMach 失败）时返回 0。
- 5 个返回点全部填充 Velocity，与现有 MachNumber 行为对齐。
- 数值示例：Ma=0.8 / Tatm=20℃ → V≈274.55 m/s；Tatm=-40℃ → V≈245.90 m/s。

## Added

- **三孔插值算法输出 Velocity**（对应 `shared/algorithms/go/threehole/interpolation`）：
  - `InterpolationResult` 新增 `Velocity float64` 字段（JSON tag `velocity`）。
  - 新增 `calcVelocity(ma, tatm)` helper + `airGasConstant=287` 常量。
  - 5 个返回点全部填充 Velocity（finalizeSingle 3 点 + calculateMulti 4 点 + 入口校验 3 点）。
- 小程序端口（`projects/probe-interpolator-miniprogram/utils/algorithms/threehole/three-hole.js`）同步输出 velocity，跨实现验证链闭环。
- Go 算法包新增 4 个单元/集成测试：`TestCalcVelocity`、`TestCalcVelocity_TemperatureEffect`、`TestCalculate_VelocityOutput`（单文件路径）、`TestCalculate_VelocityOutput_MultiFile`（多文件路径）。

## Install / Upgrade

- **从 0.2.1 升级**：直接运行 `probe-interpolator-0.2.2-amd64-installer.exe`，安装程序会覆盖旧版本（相同安装路径）。用户数据不存储在安装目录，升级无数据丢失风险。
- **全新安装**：运行 `probe-interpolator-0.2.2-amd64-installer.exe`。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `probe-interpolator-0.2.2-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
