# Probe Interpolator v0.4.0

Release date: 2026-08-19
Package: probe-interpolator-0.4.0-amd64-installer.exe

## Summary

七孔探针插值新增**外区 θ 角度外推**能力：当测点偏角超出校准网格上限（θ>45°）时，不再直接判无效，而是基于最外层网格单元的仿射反演线性外推 θ/φ，能算出数据就显示，结果带"外推点"Warning 标注，有效性由用户自行判断。按 MINOR 递增（新增用户可见能力）。

## User-visible Changes

- **七孔外区角度外推**（`shared/algorithms/go/sevenhole/interpolation`）：
  - 外区两候选扇区均未命中时，用第一候选扇区最外层 θ 单元（θ∈[θMax-5, θMax]）4 角点建立仿射映射，反演 `(ka,kb) → (θ,φ)`，θ 可超过校准上限 45°（实测可达 70°），φ 解析而非落回扇区中心。
  - θ 计算值钳制到 `θMax+5°`（系数外推有界），展示 θ_raw 保留原始外推值。
  - 外推结果 `IsValid=true` + 非空 Warning（标注外推点、校准上限、计算用 θ），UI 可据此提示用户。
  - 内区命中但物理结果非法（`Pt<Ps`）时回退继续尝试外区/外推路径，全部失败才返回原始错误（不静默取绝对值）。
  - 新增文件 `outer_extrapolation.go`；`Calculate` 越界分支改为"确认 θ 外边界方向才外推"。
- **实测效果**（`102原始.csv`，85 m/s PRB）：此前 61 行中 12 行越界无效；0.4.0 下 61/61 行全部可算，越界行输出 theta_raw 46°~70°、带外推 Warning（参考 spec `docs/spec-seven-hole-extrapolation.md` §6.1）。
- **结果"状态"列三态分类**（前端）：有效（角度在校准 PRB 范围内）/ 参考（外推、超出校准范围，黄色警示）/ 无效（计算失败，红色）。统计卡片、顶部徽章、计算完成提示与导出 CSV 同步区分"有效/参考/无效"。

## Compatibility

- 配置/数据文件格式：兼容。
- API 契约：兼容（`InterpolationResult` 无字段变更；越界行为由"无效"变为"可显示 + Warning"，属预期变更）。
- 正常网格内路径：数值零回归（golden 435 点对拍不变）。
- golden 测试：越界样本按 §3.3 分类更新——确认为 θ 外边界越界的样本改为外推结果断言，其余保持 `IsValid=false` 断言。

## Install / Upgrade

- **从 0.3.x 升级**：直接运行 `probe-interpolator-0.4.0-amd64-installer.exe`，安装程序覆盖旧版本（相同安装路径）。用户数据不存储在安装目录，升级无数据丢失风险。
- **全新安装**：运行 `probe-interpolator-0.4.0-amd64-installer.exe`。
- 推荐步骤：
  1. 关闭正在运行的旧版本；
  2. 运行 `probe-interpolator-0.4.0-amd64-installer.exe`；
  3. 启动新版本并确认 GUI 正常出现；
  4. 加载七孔 PRB/校准 CSV，对已知测点抽查角度与压力结果。
