# Probe-Interpolator v0.1.0-win7.1 (Windows 7 LTS)

Release date: 2026-07-24
Package: Probe-Interpolator-Win7-Setup-0.1.0-win7.1-x64.exe
SHA-256: A07D1DA25CFFF0245EE1B125EE579E38BD4070915B449748CEFEE0BE07AA5B4C

## Summary

Windows 7 LTS 首个可交付版本。基于 Electron 22.3.27（Chromium 108，最后兼容 Win7 的 Electron 主版本）承载 Vue 3 前端，Go 后端改为 `net/http` server 监听 `127.0.0.1:18183`，前端通过 HTTP fetch 与后端通信。**无 WebSocket 事件流**（纯请求-响应模式，无硬件设备通信）。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch（无 WebSocket） |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:18183` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 文件选择 | Wails dialog | Electron IPC dialog（后端仅接收文件路径参数） |

## User-visible Changes

- 与 master 0.1.0 功能对齐：5/3/7 孔探针插值、共享探针选择状态、CSV 导入导出。
- Win7 专属：文件选择对话框由 Electron IPC 处理，后端 `LoadPrbFiles`/`ImportCsvData` 改为接收文件路径参数。
- Win7 专属：`wails-adapter.ts` 重命名为 `probe-adapter.ts`，改为 HTTP fetch 实现。

## Compatibility

- 配置文件格式：与 master 0.1.0 兼容。
- .prb 文件格式：无变化。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 master 安装包不可共存：两者注册表项、安装目录独立，但同名快捷方式可能冲突，建议二选一。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `Probe-Interpolator-Win7-Setup-0.1.0-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，探针插值面板能加载。
  4. （可选）验证：导入 .prb 文件，确认 5/3/7 孔插值结果正常。
- 安装目录默认 `%LOCALAPPDATA%\Programs\probe-interpolator-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- `VERSION` 文件为 `0.1.0`，但 `desktop-electron/package.json` 版本号为 `0.1.0-win7.1`（带 Win7 后缀以区分 master 安装包）。后续版本应统一版本号策略。

## Rollback

- 可回退到 master 0.1.0（Wails 版）。配置文件格式兼容。
- 卸载 Win7 版后安装 master 版即可，两者注册表项独立。
