## Summary

Win7 LTS 维护版本，自 0.1.0-win7.1 以来同步 master 0.2.0~0.2.1 全部业务改动：七孔校准 CSV 导入功能（7 个 GBK CSV 文件，内区 1 + 外区 6）、PRB 加载流程重构、CSV 导入重构为 csvFieldSetter 数据驱动模式、七孔工作区组件精简、文件对话框过滤器不再污染 CSV 导入、应用图标 embed 修复、NSIS installer 文件名前缀修复、三孔插值健壮性修复。所有变更通过 master→lts/win7 cherry-pick 同步，业务层零代码差异。

## Changes vs 0.1.0-win7.1

### Added

- **七孔校准 CSV 导入功能**（同步 master 0.2.0）：新增 `LoadSevenHoleCalibrationCsvFiles` API，支持 7 个 GBK 编码 CSV 文件（内区 1 + 外区 6）导入，退化为边缘自动 dither，复用 PRB 折线渲染器展示校准曲线，并返回 warnings 用于退化边缘可视监测。
- **七孔文件选择 API**（同步 master 0.2.0）：新增 `PickSevenHoleFiles` / `GetSevenHoleDataSource` API，支持前端槽位 UI 文件选择与 PRB/CSV 校准数据源切换。
- **七孔槽位 UI 组件**（同步 master 0.2.0）：前端新增 `SevenHoleSlotRow.vue` 组件，与 wind-daq traversal-test 槽位 UI 模式一致，每个槽位独立选择 PRB 或 CSV 校准文件。

### Changed

- **七孔 PRB 加载流程重构**（同步 master 0.2.0）：`LoadSevenHolePrbFiles` 接受前端预分配的 inner + outer[6] 路径数组，取代后端多次选对话框 + 后端 basename 路由的旧实现，与 wind-daq traversal-test slot-UI 模式对齐。
- **CSV 导入重构**（同步 master 0.2.0）：`ImportSevenHoleCsvData` 改为 `csvFieldSetter` 数据驱动模式，取代 9 个独立解析调用 + 9 路错误联合，降低维护成本。
- **七孔工作区重写**（同步 master 0.2.0）：`SevenHoleWorkspace.vue` 从 947 行精简至约 440 行，校准逻辑迁移至 `useSevenHoleCalibration.ts` composable。
- **`loadSevenHoleCalibrationCsvFiles` 签名**（同步 master 0.2.0）：从 `[6]string` 改为 `[]string`，移除调用方冗余的数组转换。
- **应用图标**（同步 master 0.1.x）：`main.go` 的 `//go:embed` 由 `appicon.png` 改为 `app_icon.png`，对应图标文件重命名，避免编译时找不到 embed 文件。

### Fixed

- **三孔插值健壮性修复**（同步 master 0.2.1）：0.2.1 三孔插值健壮性修复。
- **文件对话框过滤器不再污染 CSV 导入**（同步 master 0.1.x）：`openFileDialog` 预设 PRB 过滤器，CSV 导入链式 `AddFilter` 只是追加而非替换，导致 CSV 对话框同时显示 PRB 文件类型。改为 `openFileDialog` 以 `SetTitle`，各调用方按场景显式 `AddFilter`（PRB 加载用 `.prb`，CSV 导入用 `.csv/.txt/.dat`）。
- **Windows dev 模式下 GetHelpDocPath 找不到 docs/**（同步 master 0.1.x）：补充 cwd 兜底及上 4 级目录扫描，并校验命中是文件而非目录。
- **NSIS installer 文件名前缀缺失**（同步 master 0.1.x）：本地 makensis 不经过 wails build 时，`wails_tools.nsh` 不会从 `wails.json` 回填 `INFO_PROJECTNAME` 等变量，默认空字符串导致 installer 文件名变成 `-<version>-amd64-installer.exe`。显式 `!define` 所有 `INFO_*` 变量修复。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch（无 WebSocket） |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:18183` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 文件选择 | Wails dialog | Electron IPC dialog（后端仅接收文件路径参数） |

## Compatibility

- 配置文件格式：与 0.1.0-win7.1 兼容。
- .prb 文件格式：无变化。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 0.1.0-win7.1 安装包可覆盖升级。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `Probe-Interpolator-Win7-Setup-0.1.1-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，探针插值面板能加载。
  4. （可选）验证：导入 .prb 文件，确认 5/3/7 孔插值结果正常；导入 7 个 GBK CSV 校准文件，确认七孔校准曲线渲染与退化边缘 warnings 展示。
- 安装目录默认 `%LOCALAPPDATA%\Programs\probe-interpolator-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- `VERSION` 文件为 `0.1.0`（master 版本号），`desktop-electron/package.json` 版本号为 `0.1.1-win7.1`（带 Win7 后缀以区分 master 安装包）。win7 与 master 双轨版本号策略：master 主线 VERSION 跟随 master 发布递增，win7 LTS 通过 desktop-electron/package.json 表达 win7 版本号。

## Rollback
