# Probe Interpolator v0.4.1

Release date: 2026-08-19
Package: probe-interpolator-0.4.1-amd64-installer.exe

## Summary

修复探针校准结果表表头显示与复制内容不一致的问题：表头希腊字母（α/β/θ/Ψ）不再被 CSS 强制大写成与拉丁字母（A/B）近似的形状，所见即所拷。

## User-visible Changes

- 三孔 / 五孔 / 七孔结果表表头希腊字母恢复小写显示（α、β、θ），不再呈现为 A、B、Θ 外观。

## Fixes

- 结果表表头 `text-transform: uppercase` 误将希腊字母转为大写外观，而复制/导出内容为原始小写字符，造成“看着是 A/B、拷贝出来是 α/β”的不一致；已取消表头大写转换。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容。
- 设备协议行为：无变化。

## Install / Upgrade

- 无需卸载旧版本，支持直接覆盖安装（0.4.0 → 0.4.1 同安装路径与注册表结构）。
- 无需清理用户数据目录或 WebView2 缓存。
- 安装步骤：
  1. 关闭正在运行的旧版本探针插值器。
  2. 运行 `probe-interpolator-0.4.1-amd64-installer.exe`。
  3. 选择语言与安装目录，等待安装完成。
  4. 启动新版本，确认结果表表头显示 α/β 小写字母。
