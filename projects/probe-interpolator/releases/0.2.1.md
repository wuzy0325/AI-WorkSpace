# Probe Interpolator v0.2.1

Release date: 2026-08-02
Package: probe-interpolator-0.2.1-amd64-installer.exe

## Summary

修复三孔插值算法在脏数据/非物理恢复/错序校准文件下的静默错误输出，并在 5/3/7 孔结果表中显示无效行的计算参考值（红色标注），同时增强三孔单文件热路径性能与超范围诊断信息。

## User-visible Changes

- **三孔结果状态统一为"参考"**：不再区分"有效/无效"标签，已计算行（含超出校准范围）一律显示"参考"并展示计算数值；超出校准范围的行以琥珀色 + 悬停 Warning 提示原因。导出 CSV 同步输出数值与"参考: 原因"。
- **三孔超范围警告携带数值**：警告从"计算马赫数超出校准范围"改为"计算马赫数超出校准范围: 恢复Ma=X，校准范围[Y,Z]"。
- **三孔单文件不再出现"马赫数被限制到标定边界"噪音警告**，`IterationCount` 固定为 1。

## Fixes

- 三孔输入有限性校验（A1）：`Patm=NaN` 等不再静默产出 `isValid=true, MachNumber=NaN`。
- 三孔完整气动参数校验（A2）：`Patm≤0`、`Tatm≤-273.15℃`、`pt<ps`、`ps+Patm≤0` 等非物理状态统一判无效，不再被 `Abs` 掩盖。
- 三孔 PRB 加载器一致性校验（A4）：各档 Alpha 网格不一致 / Kb 重复 / Kb 非单调的校准文件拒绝加载。
- 无效行批量计算不再因单行脏数据导致整批 `Success=false`（保持结构化无效结果契约）。

## Compatibility

- **PRB 文件格式**：完全兼容 0.2.0（3 孔：`CMa / Nalpha / Kb K0 Kv Alpha`）。
- **CSV 输入/输出格式**：完全兼容 0.2.0（3 孔：P1/P2/P3 + Patm + Tatm）。
- **结果展示**：无效行从显示 "-" 改为显示数值 + 红色标注，仅展示方式变化，不影响数据格式。
- **设备协议行为**：无变化（纯桌面插值工具，无设备接入）。

## Install / Upgrade

- **从 0.2.0 升级**：直接运行 `probe-interpolator-0.2.1-amd64-installer.exe`，安装程序会覆盖旧版本（相同安装路径）。用户数据不存储在安装目录，升级无数据丢失风险。
- **全新安装**：运行 `probe-interpolator-0.2.1-amd64-installer.exe`。
- **与旧独立程序共存**：5 孔 / 3 孔独立程序可与之共存（但建议迁移后卸载）。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `probe-interpolator-0.2.1-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
