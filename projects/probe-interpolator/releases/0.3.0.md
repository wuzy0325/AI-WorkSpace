# Probe Interpolator v0.3.0

Release date: 2026-08-05
Package: probe-interpolator-0.3.0-amd64-installer.exe

## Summary

七孔探针插值算法加载与插值链路修复：校准 CSV 系数改为从原始压力列全精度重算，替代历史 3 位小数 K 列；新增网格节点精确往返路由，修复内区边界网格节点被误路由到大角度区、以及自提取 PRB 反推场景下网格边界节点无法定位的问题。本版本为七孔算法行为修正，按 MINOR 递增。

## User-visible Changes

- **七孔校准 CSV 系数全精度重算**（`shared/algorithms/go/sevenhole/interpolation`）：
  - 系数（ka/kb/cpt/cps）不再直接采用 CSV 中 col12..15 的 3 位小数 K 列，改为由原始压力列（col3=P0、col4=Ps、col5..11=P1..P7）在 float64 全精度下按公式重算。
  - 数值影响：历史 3dp K 列误差最大约 5e-4，全精度重算误差约 1e-6，系数更接近真实校准值。
- **网格节点精确往返修复**：
  - 内区 13×13 网格中 21 个边界节点此前因 3dp 截断（~5e-4 偏差）被判定在边界多边形外，误路由到大角度区（错误外插结果）；现正确路由到内区并精确命中网格节点。
  - 校准行（内区 169 + 外区 312）现在按自身网格节点精确往返：`Calculate` 新增外区节点直命中短路径（`findExactOuterCalibrationNode`），内/外区插值新增网格点直命中兜底。
  - 修复自提取 PRB 反推场景：从校准 CSV 重算生成的 PRB，其压力行能精确反推出原网格角度，不再因浮点噪声导致 `locateInvertAB` 漏判网格边界点。
- 内/外区边界节点结果会随上述修复变化（例如原被误路由的内区角落节点现在返回精确网格角度）。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：CSV 校准文件兼容（列位置契约不变，仍按 col0/1 角度 + col3..11 压力读取）；历史 3 位小数 K 列（col12..15）不再参与网格构建，仅用于表头诊断。
- 历史 PRB 文件：旧 3dp PRB 与新的全精度网格存在约 5e-4 差异，建议用新版本重新生成/导出 PRB 校准文件后再加载。
- API 契约：兼容（`InterpolationResult` 无字段变更）。
- 插值结果：普通测量点（非网格节点）结果连续，不受网格节点短路径影响。

## Install / Upgrade

- **从 0.2.x 升级**：直接运行 `probe-interpolator-0.3.0-amd64-installer.exe`，安装程序会覆盖旧版本（相同安装路径）。用户数据不存储在安装目录，升级无数据丢失风险。
- **全新安装**：运行 `probe-interpolator-0.3.0-amd64-installer.exe`。
- 推荐步骤：
  1. 关闭正在运行的旧版本；
  2. 运行 `probe-interpolator-0.3.0-amd64-installer.exe`；
  3. 启动新版本并确认 GUI 正常出现；
  4. 加载七孔校准 CSV/PRB，对已知测点抽查角度与压力结果。
