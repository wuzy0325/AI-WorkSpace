# Probe Interpolator v0.2.0

Release date: 2026-07-31
Package: probe-interpolator-0.2.0-amd64-installer.exe

## Summary

在 0.1.0 基础上新增七孔探针校准模块（CSV 校准数据导入 + 槽位 UI + 校准 composable），
重构七孔 PRB 加载流程为前端预分配路径模式，并修复文件对话框过滤器污染 CSV 导入、
应用图标嵌入错误等缺陷。同时修正 NSIS installer 文件名与 build/config.yml 版本不同步问题。

## User-visible Changes

### 七孔探针校准模块（新功能）

- **CSV 校准数据导入**：新增 `LoadSevenHoleCalibrationCsvFiles` API，
  支持 7 个 GBK 编码 CSV 文件（内区 1 + 外区 6）导入，退化边缘自动 dither，
  复用 PRB 折线渲染器展示校准曲线，并返回 warnings 用于退化边缘可观测性。
- **槽位 UI（Slot UI）**：前端新增 `SevenHoleSlotRow.vue` 组件，
  与 wind-daq traversal-test 槽位 UI 模式一致，每个槽位独立选择 PRB 或 CSV 校准文件。
- **数据源切换**：新增 `PickSevenHoleFiles` / `GetSevenHoleDataSource` API，
  前端可在 PRB 与 CSV 校准数据源之间切换。
- **校准 composable**：新增 `useSevenHoleCalibration.ts`，
  封装校准流程状态管理与 CSV 导入交互逻辑，简化 `SevenHoleWorkspace.vue`。

### 七孔 PRB 加载流程重构

- `LoadSevenHolePrbFiles` 接受前端预分配的 inner + outer[6] 路径数组，
  取代后端多选对话框 + 后端 basename 路由的旧实现，
  与 wind-daq traversal-test slot-UI 模式对齐。

### CSV 导入重构

- `ImportSevenHoleCsvData` 重构为 `csvFieldSetter` 数据驱动模式，
  取代 9 个独立解析调用 + 9 路错误联合，降低维护成本。

## Fixes

- **文件对话框过滤器不再污染 CSV 导入**（80ed7c8）：
  `openFileDialog` 预设 PRB 过滤器，CSV 导入链式 `AddFilter` 只是追加而非替换，
  导致 CSV 对话框同时显示 PRB 文件类型。改为 `openFileDialog` 仅 `SetTitle`，
  各调用方按场景显式 `AddFilter`（PRB 加载加 `.prb`，CSV 导入加 `.csv/.txt/.dat`）。
- **GetHelpDocPath 在 Windows dev 模式下找不到 docs/**（80ed7c8）：
  补充 cwd 兜底及上 4 级目录查找，并校验命中是文件而非目录。
- **应用图标嵌入错误**（c162dcc）：
  `main.go` 的 `//go:embed` 由 `appicon.png` 改为 `app_icon.png`，
  对应图标文件重命名，避免编译时找不到 embed 文件。
- **NSIS installer 文件名缺前缀**（bdbed99）：
  本地 makensis 不经过 wails build，`wails_tools.nsh` 不会从 `wails.json` 回填
  `INFO_PROJECTNAME` 等变量，默认空字符串导致 installer 文件名变成
  `-<version>-amd64-installer.exe`。显式 `!define` 所有 INFO_* 变量修复。
- **build/config.yml 版本不同步**（本次 release）：
  `info.version` 历史一直是 wails 模板默认值 `0.0.1`，从未同步到实际版本。
  本次 release 修正为 `0.2.0`，后续 release 将随 VERSION 一并更新。

## Compatibility

- **PRB 文件格式**：完全兼容 0.1.0（5 孔 / 3 孔 / 7 孔）。
- **CSV 输入/输出格式**：完全兼容 0.1.0（5 孔 / 3 孔 含 PressureMode 列；7 孔 P1-P7 + Patm + Tatm）。
- **七孔 PRB 加载接口**：**Breaking**（仅对直接调用 Wails binding 的代码）。
  `LoadSevenHolePrbFiles` 从后端多选对话框模式改为前端预分配路径数组模式，
  前端适配层 `adapters/seven-hole.ts` 已同步更新，最终用户无感知。
- **七孔 CSV 校准数据导入**：0.2.0 新增能力，0.1.0 不具备。
- **帮助文档**：与 0.1.0 内容一致（5/3/7 孔各一份 HTML）。

## Install / Upgrade

- **从 0.1.0 升级**：直接运行 `probe-interpolator-0.2.0-amd64-installer.exe`，
  安装程序会覆盖旧版本（相同安装路径）。用户数据不存储在安装目录，升级无数据丢失风险。
- **全新安装**：运行 `probe-interpolator-0.2.0-amd64-installer.exe`。
- **与旧独立程序共存**：5 孔 / 3 孔独立程序可与之共存（但建议迁移后卸载）。
