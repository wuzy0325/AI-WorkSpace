# Wind-DAQ v0.15.3

Release date: 2026-08-14
Package: wind-daq-0.15.3-amd64-installer.exe

## Summary

修复 WTN-PXI 球罐数据采集设备数据帧解码错误（按 LabVIEW double[] 大端格式解析，而非旧 float32 小端假设），并新增 WTN-PXI 通讯协议调试工具、NSIS WebView2 下载修复、DAQ-T-1602 采样率配置及七孔探针校准相关调整。

## User-visible Changes

- 新增 WTN-PXI 通讯协议调试工具：`wtnpxi-diag`（CLI）/ `wtnpxi-gui`（GUI），可直连设备查看 12 路通道实时值、逐帧 hex 详情、保存原始字节。
- DAQ-T-1602 支持设备专属采样率配置（SampleRateHz）。

## Fixes

- **WTN-PXI 数据帧解码**：真实设备帧为 `2 字节前缀 + 4 字节大端数组长度 + N × double（大端）`。原实现按 float32 小端解析导致通道显示 -6.055e+31 等天文数字。驱动与调试工具均已修正，12 路通道正常显示压力值。
- **WTN-PXI 设备信息帧**：连接后首个 20B 帧（含 "crio" 设备名）不再被误当通道值，日志显示 `[设备信息]`。
- **NSIS WebView2**：runtime 已存在时跳过下载；下载失败改为警告不中断安装。

## Compatibility

- 设备协议行为：WTN-PXI 解码逻辑变更（修正为真实格式）。配置文件/数据文件格式无变化。
- 存储与配置兼容 0.15.2；可直接覆盖安装。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `wind-daq-0.15.3-amd64-installer.exe` → 启动确认 GUI 正常出现。
- 若连接 WTN-PXI 设备，建议现场验证 12 路通道数值为合理量级。

## Known Issues

- 已知限制同 0.15.2：T 型量程下限恰为 0℃ 时真实 0℃ 与未接入不可区分；UI 修改热电偶类型保存后不会立即下发到已连接设备。

## Rollback

- 可直接卸载后重装 0.15.2；无配置或数据格式变化。WTN-PXI 解码修正无法回退到 0.15.2 的错误行为。
