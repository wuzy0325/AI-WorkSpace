# Wind-DAQ v0.6.0

Release date: 2026-07-14
Package: wind-daq-0.6.0-amd64-installer.exe

## Summary

设备类型扩展（DAQ-P-1603 / DAQ-T-1603），默认配置迁移，DAQ-P-1603/设备管理 UI 改进，安装程序响应优化。

## User-visible Changes

- DAQ-P-1603 配置面板 UI 改进。
- 设备管理抽屉 UI 优化。
- 安装程序：选完语言后立即弹出欢迎页；WebView2 在正式安装阶段优先使用同目录离线包，不存在时在线下载。
- i18n 补充覆盖新增设备类型。

## Fixes

- DAQ-P-1603 已关闭“校零应用”的通道不再参与单通道或全部校零，用户使能设置不会被校零操作覆盖。
- 所有压力通道均关闭“校零应用”时，设备级校零按钮正确禁用。

## Internal

- 设备类型枚举扩展（DeviceTypeDAQP1603 / DeviceTypeDAQT1603）。
- 默认配置迁移逻辑，支持旧配置文件自动升级。
- 94 行新增测试覆盖默认配置和迁移。

## Compatibility

- 配置文件格式：兼容，旧配置自动迁移到新版本。
- 数据文件格式：兼容。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。

## Verification

- `go test ./...`
- `npm run typecheck`
- `npm run build`
- `go build -tags production -trimpath -buildvcs=false -ldflags="-w -s -H windowsgui"`
- `makensis` 构建安装包
- GUI 启动检查：进程未出现 Wails 构建标签错误，但在自动检查窗口内以代码 0 自行退出，未完成交互式冒烟测试。

## Known Issues

- DAQ-P-1604 设备固件时间戳 bug 仍存在，CSV 时间戳已统一截断到秒级规避。

## Rollback

- 可直接回退到 0.5.4，配置兼容。
