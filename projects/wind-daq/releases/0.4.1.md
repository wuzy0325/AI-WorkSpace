# Wind-DAQ v0.4.1

Release date: 2026-07-10
Package: wind-daq-0.4.1-amd64-installer.exe

## Summary

遍历测试 UI 样式优化：画布增强、顶栏极简化、整体视觉更轻盈。

## User-visible Changes

- PointsPreview 布点画布增强：渐变背景、轨迹线渲染、立体点视觉效果。
- TraversalWorkspaceArea 顶栏极简化：去掉着色装饰条，标题+Tab 同排自然分隔。
- TraversalTopBar 状态指示改进：彩色徽章改为圆点+文字，进度条颜色对齐主题色，间距紧凑化。

## Internal

- 3 个 Vue 组件纯前端样式调整，无逻辑或接口变更。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。

## Verification

- `npm run typecheck`
- `npm run build`
- `go build -tags production -trimpath -buildvcs=false -ldflags="-w -s -H windowsgui"`
- `makensis` 构建安装包

## Known Issues

- DAQ-P-1604 设备固件时间戳 bug 仍存在，CSV 时间戳已统一截断到秒级规避。

## Rollback

- 可直接回退到 0.4.0，配置兼容。
