# Wind-DAQ v0.12.3

Release date: 2026-08-04
Package: wind-daq-0.12.3-amd64-installer.exe

## Summary

本版本无 Wind-DAQ 自有代码变更，仅因共享 device-sdk 的 T1603 通道掩码覆盖缺陷修复（`shared/device-sdk` `daq_t1603.go`，与 daq-t1603 0.6.8 同源）而重新打包。

## User-visible Changes

- 修复 T1603 设备连接后启动采集可能变为零通道的问题：连接同步阶段设备端持久化的历史通道掩码（如出厂遗留 `0000`）不再覆盖应用配置。此前设备端掩码非 `FFFF` 时，启动采集会发出 `@f0 0000 2`，导致无数据帧且停止采集报 `invalid Stop response boundary`。现在启动命令恢复为应用配置的 `@f0 FFFF 2`（全通道启用）。

## Fixes

- **设备端 MCH 覆盖应用通道掩码**（同 daq-t1603 0.6.8）：`readAllConfig` 中 `@fd MCH` 的读回值不再写回 `cfg.ChannelMask`，应用配置/profile 才是权威；mask 为空时仍回退 `FFFF`。`@fd MCH` 命令本身仍被读取以维持协议响应边界与后续命令时序。

## Compatibility

- 配置文件格式：兼容（`ChannelMask` 字段语义不变，仍是应用侧权威配置）。
- 数据文件格式：兼容。
- 设备协议命令链：不变（`@fd MCH` 仍会读取，仅不再回写应用配置）。
- API 契约：兼容。

## Install / Upgrade

- 可直接覆盖安装 0.12.2，无需卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本 Wind-DAQ。
- 运行 `wind-daq-0.12.3-amd64-installer.exe`，安装后启动应用确认主窗口正常出现、设备扫描与采集功能可用。

- 安装包未进行 Authenticode 数字签名，Windows 可能显示"未知发布者"提示，可点击"仍要运行"继续安装。

## Rollback

- 可直接回退到 0.12.2：通过"控制面板 → 程序和功能"卸载 0.12.3，再运行 `wind-daq-0.12.2-amd64-installer.exe`。
- 配置与数据文件回退前后兼容，无需额外迁移。
- 回退后 T1603 掩码覆盖缺陷复现（连接后若设备端 MCH 非 FFFF，启动命令可能再次变成 `@f0 0000 2`）。
