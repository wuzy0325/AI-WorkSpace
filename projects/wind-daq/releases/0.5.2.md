# Wind-DAQ v0.5.2

Release date: 2026-07-13
Package: wind-daq-0.5.2-amd64-installer.exe

## Summary

新增校准授权对话框、前端 i18n 补充、遍历/Motion/Dashboard UI 改进。修复安装程序中文乱码、DAO-P-1604 校零限制、遍历前置检查。

## User-visible Changes

- 校准授权对话框：首次进入校准功能时展示授权信息。
- 前端 i18n 补充 36 条翻译。
- 遍历步骤面板 UI 改进（对齐新配置步骤顺序）。
- MotionView 控制器配置 UI 优化。
- MainDashboardView 布局调整。
- 安装程序语言选择对话框中文正确显示（此前为乱码）。
- DAQ-P-1604 大气压/温度辅助通道禁止校零。
- 遍历前置检查纳入运动控制器连接态，避免"已装配但全离线"假绿。
- 遍历配置步骤顺序调整为 Hardware → Probe → Layout → Review。

## Internal

- 五孔探针 PRB 插值算法精简约 160 行。
- 更新 NSIS project.nsi 中文编码处理规则。

## Behavior Changes

- 五孔探针 PRB 插值器：超范围输入（压力系数落在 ±30° 校准网格凸包外）不再钳位到角点 (±30, ±30)；
  改为返回 `IsValid=false` 并附 Warning `"压力系数超出PRB校准网格，旧算法不支持外推"`。
  依赖原钳位行为的下游消费者需显式检查 `IsValid=false` 路径。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。

## Verification

- `go test ./...`
- `npm run typecheck`
- `npm run build`
- `go build -tags production -trimpath -buildvcs=false -ldflags="-w -s -H windowsgui"`
- `makensis` 构建安装包

## Known Issues

- DAQ-P-1604 设备固件时间戳 bug 仍存在，CSV 时间戳已统一截断到秒级规避。

## Rollback

- 可直接回退到 0.5.1，配置兼容。
