## Summary

Win7 LTS 维护版本，自 0.10.0-win7.1 以来同步 master 0.11.0~0.12.2 全部业务修复与功能扩展：双探针遍历工作流、七孔区域归属改用预设配置替代压力判定、设备网络操作防本机卡死（LSP 环境加固）、双探针恢复映射索引-文件 taskID 不一致自愈、merge 0.12.2 后测试代码对齐与 shutdown 字段补全、下线遍历测试 checkpoint 恢复能力并发布 0.12.2。所有变更通过 master→lts/win7 cherry-pick 同步，业务层零代码差异。

## Changes vs 0.10.0-win7.1

### Added

- **双探针遍历工作流**（同步 master 0.11.x）：dual traversal registry + ADR-009 net watchdog + i18n；dashboard device stream 跨双探针页面保持活跃；dual traversal realtime 结果独占从 DAQ snapshots 获取。
- **七孔区域归属改用预设配置**（同步 master 0.12.0）：七孔区域归属改用预设配置替代压力判定，避免压力阈值漂移导致的误判。
- **设备网络操作防本机卡死**（同步 master 0.12.1 LSP 环境加固）：在 LSP（Layered Service Provider）环境下设备网络操作不再卡死本机。

### Changed

- **下线遍历测试 checkpoint 恢复能力**（同步 master 0.12.2，Breaking）：停止遍历测试现在表示操作员作出最终决定，临时 checkpoint 被清理，不再作为未完成任务提供恢复入口。
  - 后端删除 HTTP 端点：`loadCheckpoint`、`resumeFromCheckpoint`、`clearCheckpoint`。
  - 后端删除 `TraversalManager.LoadCheckpoint` / `ResumeFromCheckpoint` / `resumeInternal` 等恢复相关方法。
  - 前端删除单探针/双探针界面的"未完成任务检测"、"继续测试"、"放弃任务"入口与 `TraversalCheckpointBanner.vue` 组件。

### Fixed

- **双探针恢复映射索引-文件 taskID 不一致自愈**（同步 master 0.12.x）：双探针恢复时映射索引与文件 taskID 不一致自动修复。
- **merge 0.12.2 后测试代码对齐与 shutdown 字段补全**（同步 master 0.12.2）：测试代码对齐 + shutdown 字段补全。

## Compatibility

- 配置文件格式：与 0.10.0-win7.1 兼容（注意 0.12.2 Breaking：遍历测试 checkpoint 恢复能力下线，旧 checkpoint 无法继续测试）。
- CSV 文件名格式：与 0.10.0-win7.1 一致。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 0.10.0-win7.1 安装包可覆盖升级。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `Wind-DAQ-Win7-Setup-0.10.1-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接设备，确认采集、CSV 录制、运动控制、双探针遍历、七孔校准正常；停止遍历测试后确认不再提示恢复入口。
- 安装目录默认 `%LOCALAPPDATA%\Programs\wind-daq-win7\`。

## Known Issues

- 360 安全卫士主动防御（ZhuDongFangYu）可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录，或改用 `--config.directories.output=dist2` 绕过。
- Electron 22.3.27 (Chromium 108) 不支持 `color-mix()` CSS 函数。仅 DeviceSidebar 设备项关键样式加了 rgba fallback（保证设备列表视觉隔离），其他文件的装饰性 color-mix() 作为已知视觉退化，缺失 fallback 时对应样式声明被浏览器丢弃，仅影响细微视觉效果，不影响功能。
- shared/device-sdk/go/pkg/slog 为 Go 1.20 兼容 polyfill，与标准库 log/slog API 完全兼容，但缺少 NewJSONHandler 等部分高级特性。当前代码未使用这些特性。
- math/rand/v2 (Go 1.22+) 已降级为 math/rand，模拟器随机性可能与 master 略有差异（不影响功能）。

## Rollback

- 可回退到 0.10.0-win7.1（功能差异：缺少 master 0.11.0~0.12.2 同步的功能，包括双探针遍历工作流、七孔区域归属预设、LSP 卡死修复等）。
- 卸载 0.10.1-win7.1 后安装 0.10.0-win7.1 即可，两者注册表项独立。
- 注意：0.10.0-win7.1 仍保留遍历测试 checkpoint 恢复能力；若已使用 0.10.1-win7.1 停止遍历任务，回退到 0.10.0-win7.1 后旧 checkpoint 仍无法继续（因 0.10.1 已清理）。
