## Summary

wind-daq 首个 Win7 LTS 版本，主版本号与 master 0.10.0 对齐。从 master 全量同步功能代码到 lts/win7 分支，并补齐 Win7/Electron 22.3.27 (Chromium 108) + Go 1.20.14 兼容性补丁。共享模块 (device-sdk/algorithms/motion-control) 同步升级到 master 0.10.0，daq-p1604 / daq-t1603 验证未受影响。

## User-visible Changes

- 版本号从 0.3.5-win7 直接对齐到 master 0.10.0-win7.1，跳过中间版本号以保持与 master 一致。
- 引入 master 0.10.0 全部功能：七孔探针校准、遍历测试 (Traversal)、运动控制独立窗口、日志查看器、存储管理、报告生成、设备管理抽屉等。
- 设备列表 UI 加 rgba fallback，确保 Electron 22.3.27 下设备项背景色隔离可见。
- MotionView 独立窗口走 Electron IPC，不再依赖 Wails runtime。
- **修复运动控制独立窗口显示主界面的问题**：BrowserWindow 加载 `/#/motion` hash 路由，而非根路径（根路径默认进 dashboard）。
- **新增 wind-daq 专属应用图标**：蓝绿渐变圆角方形 + "WD" 字样（PIL 生成，6 尺寸 ICO），替换默认 Electron 原子图标。

## Compatibility

- 配置文件格式：与 master 0.10.0 一致。
- CSV 文件名格式：与 master 0.10.0 一致。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 0.3.5-win7 安装包可覆盖升级（但配置文件格式可能不兼容，建议先备份）。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `Wind-DAQ-Win7-Setup-0.10.0-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接设备，确认采集、CSV 录制、运动控制正常。
- 安装目录默认 `%LOCALAPPDATA%\Programs\wind-daq-win7\`。

## Known Issues

- 360 安全卫士主动防御（ZhuDongFangYu）可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录，或改用 `--config.directories.output=dist2` 绕过。
- Electron 22.3.27 (Chromium 108) 不支持 `color-mix()` CSS 函数。仅 DeviceSidebar 设备项关键样式加了 rgba fallback（保证设备列表视觉隔离），其他 43 个文件的装饰性 color-mix() 作为已知视觉退化，缺失 fallback 时对应样式声明被浏览器丢弃，仅影响细微视觉效果，不影响功能。后续 0.10.0-win7.2 修复。
- shared/device-sdk/go/pkg/slog 为 Go 1.20 兼容 polyfill，与标准库 log/slog API 完全兼容，但缺少 NewJSONHandler 等部分高级特性。当前代码未使用这些特性。
- math/rand/v2 (Go 1.22+) 已降级为 math/rand，模拟器随机性可能与 master 略有差异（不影响功能）。
