# Wind-DAQ v0.3.2

Release date: 2026-07-03
Package: wind-daq-0.3.2-amd64-installer.exe

## Summary

修复 T1603 设备停止采集后配置参数报错的问题。根因是停止采集后 TCP 缓冲区残留采集数据帧，后续 ApplyDaqT1603Config 的 sendCommand 把残留当作命令响应读出，导致配置命令失败。修复点位于 shared/device-sdk 共享代码，wind-daq 的 T1603 设备适配器自动受益。

## User-visible Changes

- 无新增功能，仅缺陷修复。

## Fixes

- 修复 T1603 设备停止采集后立即配置参数时命令响应乱码或失败的问题。通过 shared/device-sdk/go/daq/hardware/daq_t1603.go 的修复，在 stopAcquisitionLocked 停止命令后增加 drainConnection 排空 TCP 缓冲区残留数据；在 ApplyDaqT1603Config 调用 applyHardwareConfig 前增加 drainConnection。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：兼容，CSV 格式无变化。
- 设备协议行为：无变化，仅在配置命令前增加缓冲区排空。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.3.2-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
