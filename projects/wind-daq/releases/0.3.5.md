# Wind-DAQ v0.3.5

Release date: 2026-07-06
Package: wind-daq-0.3.5-amd64-installer.exe

## Summary

校准算法重构：统一"来流为正"方向约定，CSV 模式配置重构，暂停/恢复逻辑优化。

## User-visible Changes

- 三孔/五孔/总压/总温校准方向统一为"来流为正"，消除各算法间符号不一致的问题。
- CSV 模式配置重构：校准选项仅在 CSV 模式下可配置。
- 校准暂停/恢复时自动保存和恢复中间状态。

## Internal

- 校准核心类型定义重构，预定义通道改为运行时初始化。
- CSV 格式定义重构，统一表头生成。
- 前端校准工作流 composable 重构。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：CSV 格式有调整，旧文件仍可读取。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.3.5-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
