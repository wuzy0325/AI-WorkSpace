# Wind-DAQ v0.14.0

Release date: 2026-08-12
Package: wind-daq-0.14.0-amd64-installer.exe

## Summary

遍历测试设备采集异常（主动停采、意外掉线、未连接）统一为"类暂停"的无限期等待，不再自动判失败；等待期间前端显示等待横幅（设备名、根因、已等待时长），并按根因给出"重启采集"或"重新连接并启动采集"的针对性指引。同时修复重连后时间戳基线重建的多处缺陷（旧缓存帧锁死新帧、reconnect→stopped 恢复路径丢失重连语义、暂停时横幅未隐藏等）。

## User-visible Changes

- 运行中任一设备停采/掉线时，遍历无限期等待设备恢复，不再 60s / 立即判失败终止整场测试。
- 等待期间顶部/双探针行内显示横幅：设备名 + 原因（停采 vs 掉线）+ 已等待时长 + 等 N 台设备。
- 暂停遍历时等待横幅被暂停 UI 取代（不显示等待累计）。
- 设备恢复后正常继续当前点位采样，恢复后首个样本不再混入等待前的旧数据。

## Fixes

- 重连恢复忽略 hub 残留旧连接缓存帧：时间戳归零/回绕的新帧不再被旧基线判为"同一帧"而误触发 10s 停滞。
- 设备经历 reconnect_required → stopped → acquiring 时保留"曾重连"信息并重建时间戳基线。
- 等待恢复后清空全部设备（含正常设备）已就绪的旧采样帧。
- 等待横幅主导设备按 reconnect_required > stopped 优先级展示。
- 移除语义不正确的设备级 `sinceMs`（无消费者；保留总等待时长 `WaitingForAcquisitionSinceMs`）。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容。
- API 契约：`AcquisitionDeviceStatus` 移除 `sinceMs` 字段（无消费者）；`Status` 新增 `waitingForAcquisition` / `waitingDevices` / `waitingForAcquisitionSinceMs`。
- 设备协议行为：无变化。
- 遍历测试行为：设备异常从"自动失败"改为"无限期等待"，不改变点位表、通道绑定与输出格式。

## Install / Upgrade

- 可直接覆盖安装 0.13.x / 0.12.x，无需卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本 Wind-DAQ。
- 运行 `wind-daq-0.14.0-amd64-installer.exe`，安装后启动应用确认主窗口正常出现、设备扫描与采集功能可用。
