# Wind-DAQ v0.3.0

Release date: 2026-07-02
Package: wind-daq-0.3.0-amd64-installer.exe (rebuild 2026-07-02)

## Summary

CSV 存储按设备切文件、DAQ-P-1604 硬件时间戳开关、T1603 硬件时间戳修复、编码器补偿 UI。

## User-visible Changes

- CSV sink 按设备切文件：DAQ-P-1604 采用 18 通道宽格式，其余设备长格式。
- DAQ-P-1604 硬件时间戳开关：三态配置（开启/关闭/默认开启）。
- B140 编码器补偿编辑器 UI（预设/自定义参数、实时校验）。
- T1603 硬件时间戳开关现在真正生效。

## Fixes

- 修复 wind-daq T1603Adapter.Connect() 自死锁。
- 修复 T1603 硬件时间戳开关不生效（驱动层不下发 @fe TIME 的问题）。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容（CSV 文件名变更为 `prefix-deviceId-YYYYMMDD-HHMMSS-NNN.csv`，旧文件仍可正常读取）。
- 设备协议行为：无变化。

## Install / Upgrade

- 如果已安装 v0.2.0，支持覆盖安装。
- 安装步骤：
  1. 关闭正在运行的旧版本。
  2. 如需，先通过"控制面板 → 卸载"卸载旧版本。
  3. 运行 wind-daq-0.3.0-amd64-installer.exe。
  4. 启动后确认 GUI 正常出现。
