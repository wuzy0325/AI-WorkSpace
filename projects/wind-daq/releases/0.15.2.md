# Wind-DAQ v0.15.2

Release date: 2026-08-13
Package: wind-daq-0.15.2-amd64-installer.exe

## Summary

修正 DAQ-T-1602 未接入热电偶通道的显示：raw 寄存器值为 0 表示未接入（非 0℃），通道卡片显示 "--"、波形图留空。除该修复外与 0.15.1（MC4 启动崩溃修复）/ 0.15.0（DAQ-T-1602 支持）相同。

## Fixes

- **T1602 未接入通道显示**：raw=0 为设备开路输出（未接热电偶），原显示 0.0℃ 具有误导性。现驱动输出 NaN → SSE 序列化为 null → 通道卡片 "--"、波形图空点、tooltip "-"。
- **SSE NaN 非法 JSON 隐患**：手写 payload 编码器原会把 NaN 输出为 `NaN` 字符串（非法 JSON，前端整帧 parse 失败），现 NaN/Inf 统一输出 null。

## Compatibility

- 配置/数据文件格式：无变化。SSE 数据流中 channels 数组元素可能为 null（此前恒为数字）——仅 0.15.2 起的前端正确处理，旧前端遇 null 会显示异常但不崩溃（仅当连接 T1602 且有未接入通道时出现）。
- 存储 CSV 中未接入通道写为 `NaN` 文本（与本工作区解析器"NaN=未设置"约定一致）。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `wind-daq-0.15.2-amd64-installer.exe` → 启动确认 GUI 正常。

## Known Issues

- T 型量程下限恰为 0℃，T 型通道真实 0℃ 测量与未接入不可区分（已与用户确认可接受）。
- UI 修改热电偶类型保存后仅持久化到 profile，不会立即下发到已连接设备（与 DAQ-T-1603 现状一致）。

## Rollback

- 可直接卸载后重装 0.15.1 / 0.15.0 / 0.14.1；无配置或数据格式变化。回退即恢复未接入通道显示 0℃ 的问题。
