# Wind-DAQ v0.3.5-win7 (Windows 7 LTS)

Release date: 2026-07-24
Package: Wind-DAQ-Win7-Setup-0.3.5-x64.exe
SHA-256: D7909E2CA0BEC366D688D464BC6EADC282E64B5F54569CB4C2CB48B0D353DF67

## Summary

Windows 7 LTS 首个可交付版本。基于 Electron 22.3.27（Chromium 108，最后兼容 Win7 的 Electron 主版本）承载 Vue 3 前端，Go 后端改为 `net/http` server 监听 `127.0.0.1:8900`（开发模式 `8901`），前端通过 HTTP fetch + WebSocket 与后端通信。同步 cherry-pick master 上 wind-daq 相关提交（WTNMC4A 默认微步 4、模拟控制器默认轴速 4 等）。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:8900`（开发模式 `8901`） |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket |

## User-visible Changes

- 与 master 0.3.5 功能对齐：风速采集、遍历测试、运动控制集成、波形图显示等核心功能完整迁移。
- Win7 专属：WTNMC4A 创建运动轴时默认微步设为 4（与 master cherry-pick 同步）。
- Win7 专属：模拟控制器创建运动轴时默认轴速设为 4（与 master cherry-pick 同步）。
- Win7 专属：所有 Wails v3 IPC 调用改为 HTTP fetch，前端 `bridge/` 层重新实现。

## Compatibility

- 配置文件格式：与 master 0.3.5 兼容。
- 遍历测试配置：与 master 0.3.5 一致。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 master 安装包不可共存：两者注册表项、安装目录独立，但同名快捷方式可能冲突，建议二选一。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `Wind-DAQ-Win7-Setup-0.3.5-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表和运动轴能加载。
  4. （可选）实机验证：连接风速采集设备，确认采集、校零、CSV 录制、运动控制正常。
- 安装目录默认 `%LOCALAPPDATA%\Programs\wind-daq-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- 波形图性能优化（2000 点/1000 点卡顿问题）在 Win7 版与 master 行为一致，根本修复仍在跟进。
- `VERSION` 文件为 `0.3.5`，与 `desktop-electron/package.json` 一致（无 `-win7.1` 后缀），与 daq-p1604/motion-controller/probe-interpolator 的版本号策略不统一。后续版本应统一。

## Rollback

- 可回退到 master 0.3.5（Wails 版）。配置文件格式兼容。
- 卸载 Win7 版后安装 master 版即可，两者注册表项独立。
