# Wind-DAQ v0.9.0

Release date: 2026-07-22
Package: wind-daq-0.9.0-amd64-installer.exe

## Summary

新增七孔探针校准及七孔/五孔遍历配置能力，自定义布点支持逐点参数覆盖；同时完成全量代码审查整改，并修复设备临时停采后遍历和校准无法可靠恢复的问题。

## User-visible Changes

- 新增七孔探针校准工作流，包含设置、分区采样、实时图表、系数计算和不确定度分析。
- 遍历支持七孔探针和五孔 PRB 配置、插值器加载及实时结果展示。
- 自定义布点可按测点覆盖运动位置与采集参数。
- 校准与遍历的运动安全设置统一使用产品默认值。
- 探针校准速度精度统一为 3 位小数。

## Fixes

- 用户临时停止设备采集后，恢复采集即可继续当前遍历或校准测点，不再直接判定任务失败。
- 停采期间不再消耗等待新帧的超时预算，避免恢复后首帧稍晚到达时被误判超时。
- 桌面端、内部 API 和独立 API 三条生产装配路径统一注入校准采集状态控制器。
- 前端 Wails runtime 恢复为 Go Wails `alpha2.106` 官方捆绑的 `3.0.0-alpha.94`，避免协议版本不一致。
- 完成校准生命周期、并发访问、输入校验、错误传播和数据持久化相关代码审查整改。

## Compatibility

- 配置文件格式：兼容；新增七孔与逐点配置字段均为可选字段，旧配置继续使用默认值。
- 数据文件格式：兼容；新增七孔校准输出不改变既有校准和遍历文件格式。
- 设备协议行为：无不兼容变化。

## Install / Upgrade

- 支持从 0.8.0 覆盖安装，无需先卸载旧版本。
- 无需清理用户配置、历史数据、WebView2 缓存或注册表残留。
- 推荐安装步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.9.0-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
  4. 使用七孔校准或遍历前，检查探针配置和插值文件是否正确。
