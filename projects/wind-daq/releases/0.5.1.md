# Wind-DAQ v0.5.1

Release date: 2026-07-13
Package: wind-daq-0.5.1-amd64-installer.exe

## Summary

修复 DAQ-P-1604 辅助通道校零限制、遍历前置检查改进、配置步骤顺序调整。

## User-visible Changes

- DAQ-P-1604 大气压/温度辅助通道禁止校零，防止误操作。
- 遍历前置检查纳入运动控制器连接态，避免"已装配但全离线"假绿。
- 遍历配置步骤顺序调整为 Hardware → Probe → Layout → Review。

## Internal

无接口或数据结构变更。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。

## Verification

- `go test ./...`
- `npm run typecheck`
- `npm run build`
- `go build -tags production -trimpath -buildvcs=false -ldflags="-w -s -H windowsgui"`
- `makensis` 构建安装包

## Known Issues

- DAQ-P-1604 设备固件时间戳 bug 仍存在，CSV 时间戳已统一截断到秒级规避。

## Rollback

- 可直接回退到 0.5.0，配置兼容。
