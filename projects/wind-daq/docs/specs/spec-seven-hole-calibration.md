# 七孔探针校准流程规范（Spec）

> 文档目的：定义七孔气动探针自动化校准系统的业务流程、算法公式、数据模型与落地架构，作为开发与验收的依据。
> 适用范围：wind-daq 项目七孔探针校准模块（前后端全栈）。
> 参考实现：五孔探针校准模块（`services/api-go/internal/core/calibration/five_hole.go` 等）。
> 数据集验证：`projects/wind-daq/docs/W532.202608.P.7H.1-01/`（85 m/s，Ma≈0.242，481 个点位）。

---

## 1. 文档范围与术语

### 1.1 与五孔模块的关系

七孔校准的状态机、运动安全、球罐门控、CSV 写入、状态推送等**通用流程完全复用**五孔模块的 `automatic_calibration.go` 模板方法；本规范仅定义七孔特有的部分：

- 孔位布局与角度坐标系
- 流场分区判定算法（内区 + 6 外区）
- 系数计算公式（内区 4 个 + 外区 4×6 个）
- 不确定度评定算法（A 类 + B 类合成）
- CSV 表头规范（内区 / 外区两套）
- 6 类特性曲线图

### 1.2 术语约定

| 术语 | 含义 |
|---|---|
| 内区（7 区） | 来流方向接近中心孔，中心孔 P7 为最大压力孔的区域，θ ≤ 30° |
| 外区（1-6 区） | 来流方向偏离中心孔，外围某孔 Pn 为最大压力孔的区域，θ ≥ 30° |
| 扇区编号 n | 外区最大压力孔编号，n ∈ {1, 2, 3, 4, 5, 6} |
| 环形取模 | n+1 顺时针相邻，n-1 逆时针相邻；n=1 时 n-1=6，n=6 时 n+1=1 |
| 灵敏系数 cᵢ | 不确定度传播律中，输出量对输入量的偏导数 |

## 2. 数据模型与变量定义

### 2.1 物理量与单位

> **压力基准三分离声明**（解决"绝压/表压混用导致大气压重复叠加"问题）：
>
> 本规范涉及三个压力基准，**各压力基准职责单一，禁止跨边界混用**：
>
> | 基准 | 数据流位置 | 物理意义 | 转换关系 | 范围示例 |
> |---|---|---|---|---|
> | **A. 通道原始值** | 设备读取 → 软件 | **表压**（相对环境大气压，可正可负） | `rawValue = deviceRead()` | p_t≈4073, p_s≈-33（数据集实测值） |
> | **B. 系数计算值** | 系数公式（4.1/4.2 节） | **表压**（与 A 同基准，因为系数是压差比，基准抵消） | `B = A`（直接使用，不转换） | 同 A |
> | **C. 大气计算值** | 马赫数/速度公式（4.4 节） | **绝压**（相对真空零点） | `C = A + 大气压力` | p_t_abs≈102957, p_s_abs≈98851 |
>
> **关键规则**：
> 1. **A → B 不转换**：系数公式中 P1~P7、p_t、p_s 全部使用表压（通道原始值）。因为 Kα/Kβ/K0/Ks 等系数都是压力差的比值，分子分母同基准时表压和绝压等价，无需转换。
> 2. **A → C 只转换一次**：仅在马赫数计算入口（4.4 节）将 p_t、p_s 转换为绝压，转换公式为 `p_abs = p_gauge + 大气压力`。**禁止在系数计算阶段提前转绝压**，否则会导致大气压被重复叠加。
> 3. **CSV 落盘基准**：CSV 中的压力列记录**表压**（与通道原始值一致），便于追溯设备读数；马赫数列记录无量纲值，不涉及基准问题。
>
> **数据集验证**（中心点 α=0°, β=0°）：
> - 通道原始值（表压）：p_t=4073.07 Pa, p_s=-32.7 Pa, 大气压力=98880 Pa
> - 系数计算（用表压）：K0 = (P7 - p_t)/(p_t - p_s) = (4075.35 - 4073.07)/(4073.07 - (-32.7)) = 0.00056 ✓
> - 马赫数计算（转绝压）：p_t_abs = 4073.07 + 98880 = 102953.07 Pa, p_s_abs = -32.7 + 98880 = 98847.3 Pa
> - Ma = √(5×((p_t_abs/p_s_abs)^0.2857 - 1)) = √(5×(1.04165^0.2857 - 1)) = √(5×0.01171) = 0.242 ✓
>
> 参考依据：《JJF(军工)19-2012 七孔探针校准规范》"本规范中所有压力均指的是绝对压力"——本规范为兼容现有 AtmosphericDataCalculator（输入表压、内部转绝压）和数据集（记录表压），采用**通道原始值=表压**的契约，在马赫数计算边界统一转绝压，等价于 JJF 的"全绝压"约定。

| 变量 | 物理意义 | 单位 | 基准 | 备注 |

**符号命名规则**（解决大小写混用歧义，与 JJF 规范保持一致）：

| 符号风格 | 含义 | 示例 |
|---|---|---|
| 大写 `P` + 数字/字母 | **探针测压孔**测量压力（被校准对象） | P1, P2, ..., P7, P̄ |

### 2.3 孔位布局

6 个外围孔按 60° 等分环形分布在探针头部锥面上，P1 为方位基准（安装时由机械定位确定），按从探针尾部向头部方向看（即正对探针头部看来流）的顺时针方向编号 P2~P6。

**坐标系约定**（与运动控制器的 α-β 坐标系一致）：
- 来流方向为 +Z 轴
- α+ 方向来流 = 来流偏向 +X 方向（侧滑角正向）
- β+ 方向来流 = 来流偏向 +Y 方向（迎角正向）
- 方位角从 +Y 轴起算，从探针尾部看（-Z 方向）顺时针递增

```
                +Y
                 ↑
            P1 (0°)  ← β+ 方向来流时 P1 最大
           /        \
      P2 (60°)    P6 (300°)
       /              \
  -X ←------- P7 (中心) ------→ +X
       \              /
      P3 (120°)   P5 (240°)
           \        /
            P4 (180°)  ← β- 方向来流时 P4 最大
                 ↓
                -Y
```

**孔位与方位角对应表**（从探针尾部看，方位角从 +Y 顺时针递增）：

| 孔位 | 方位角 | 物理位置 | 来流偏转时压力最大的方向 |
|---|---|---|---|
| P1 | 0° | 正上方（+Y） | β+ 方向来流（α≈0, β>0） |
| P2 | 60° | +Y 偏 -X | β+ 偏 α- 方向来流 |
| P3 | 120° | -X 偏 -Y | α- 方向来流（α<0, β≈0） |
| P4 | 180° | 正下方（-Y） | β- 方向来流（α≈0, β<0） |
| P5 | 240° | -Y 偏 +X | α+ 方向来流（α>0, β≈0） |
| P6 | 300° | +X 偏 +Y | α+ 偏 β+ 方向来流 |
| P7 | - | 中心孔 | 来流接近正对探针（θ≤30°） |

> **说明**：方位角是探针孔位的几何位置坐标，与来流偏转方向（α/β）相关但不等同。α/β 是来流相对探针轴的偏转角，用于内区；θ/φ 是来流相对探针轴的俯仰/滚转角，用于外区。

> **数据集验证**（小角度区内区数据）：
> - α=0°, β=+5°：来流偏向 +Y，实测 P1=1192.6 最大 ✓
> - α=+5°, β=0°：来流偏向 +X（方位角 270°），实测 P5=1090.4 最大、P6=941.7 次大（距离 270° 都是 30°）✓
> - α=0°, β=-5°：来流偏向 -Y，实测 P4=1188.6 最大 ✓
> - α=-5°, β=0°：来流偏向 -X（方位角 90°），实测 P3=922.0 最大、P2=895.2 次大 ✓

> **外区验证**（大角度 1 区首点 φ=330°, θ=30°，P1 最大）：
> - 来流方位角约 330°（φ 直接对应方位角，从 +Y 顺时针 330°，即 +Y 偏 +X 附近）
> - 距离 P1(0°) 是 30°，距离 P6(300°) 是 30°
> - 实测 P1=3260.2 最大、P6=2973.9 次大 ✓（P1 略大于 P6，符合 φ=330° 略偏向 P1）

## 3. 流场分区判定算法

### 3.1 分区命名规则

根据 7 个压力孔的压力最大值，将流动区域划分为 7 个区，以最大压力孔的编号命名：

| 区号 | 命名 | 区域类型 | 判定条件 | 物理含义 |
|---|---|---|---|---|
| 7 区 | 内区 | inner | P7 为最大压力孔 | 来流接近正对探针（θ ≤ 30°） |
| 1 区 | 外区 1 | outer, n=1 | P1 为最大压力孔 | 来流偏向 P1 方位（β+ 附近），θ ≥ 30° |
| 2 区 | 外区 2 | outer, n=2 | P2 为最大压力孔 | 来流偏向 P2 方位 |
| 3 区 | 外区 3 | outer, n=3 | P3 为最大压力孔 | 来流偏向 P3 方位（α- 附近） |
| 4 区 | 外区 4 | outer, n=4 | P4 为最大压力孔 | 来流偏向 P4 方位（β- 附近） |
| 5 区 | 外区 5 | outer, n=5 | P5 为最大压力孔 | 来流偏向 P5 方位（α+ 附近） |
| 6 区 | 外区 6 | outer, n=6 | P6 为最大压力孔 | 来流偏向 P6 方位 |

**外区均分 6 个扇形区域**：每个扇形滚转角 φ 跨度为 60°，以 Pn 方位为中心。即：
- 外区 1（P1 最大）：φ ∈ [-30°, +30°]（绕 0° 中心）
- 外区 2（P2 最大）：φ ∈ [+30°, +90°]（绕 60° 中心）
- 外区 3（P3 最大）：φ ∈ [+90°, +150°]（绕 120° 中心）
- 外区 4（P4 最大）：φ ∈ [+150°, +210°]（绕 180° 中心）
- 外区 5（P5 最大）：φ ∈ [+210°, +270°]（绕 240° 中心）
- 外区 6（P6 最大）：φ ∈ [+270°, +330°]（绕 300° 中心）

> φ 起始与终止可按 P1 方位基准调整（约定 P1 方位为 φ=0°，φ 顺时针递增）。

### 3.2 判定逻辑

> **确定性 tie-break 规则**（解决"最大压力相等时没有可执行的确定性分区规则"问题）：
>
> 当多个压力孔并列最大时，必须按以下优先级**确定性**地选择一个区域，保证相同输入永远落入同一分区：
>
> 1. **P7 优先规则**：若 P7 与外围任一孔并列最大（差值 < `TIE_BREAK_TOLERANCE`，默认 5 Pa），**无条件判定为内区**（n=7）。理由：内区是几何中心区域，边界处 P7 与外围孔竞争时，优先归入内区可避免 Kφ 边界符号反转导致的分区抖动。
> 2. **外围孔编号小优先规则**：若多个外围孔并列最大（P7 非最大），选择编号最小的孔作为扇区编号 n。例如 P1=P2=Pmax 时选 n=1。
> 3. **滞回机制**：若上一时刻分区为 `outer/n`，当前时刻 `Pn` 与 `P(n+1)`（或 `P(n-1)`）并列最大且差值 < `TIE_BREAK_TOLERANCE`，**保持上一时刻分区** `outer/n`，避免相邻扇区边界处分区来回切换。
> 4. **首点无前序时**：若当前点是校准的第一个点（无上一时刻分区），跳过滞回规则，仅按规则 1、2 判定。

```
输入: P1, P2, P3, P4, P5, P6, P7, prevRegion (上一时刻分区，可为空)
输出: region ∈ {"inner", "outer"}, n ∈ {1..7}

const TIE_BREAK_TOLERANCE = 5.0  // Pa，并列判定容差

Pmax = max(P1, P2, P3, P4, P5, P6, P7)

// 规则 1：P7 优先（P7 与 Pmax 差值 < 容差时判定内区）
if |P7 - Pmax| < TIE_BREAK_TOLERANCE:
    region = "inner"
    n = 7
    return

// 规则 2 + 3：外围孔并列时，先尝试滞回，再按编号小优先
outerMax = max(P1, P2, P3, P4, P5, P6)
candidates = [i for i in 1..6 if |Pi - outerMax| < TIE_BREAK_TOLERANCE]  // 并列最大的孔编号列表

// 规则 3：滞回——上一时刻分区在外围且其编号在 candidates 中，则保持
if prevRegion == "outer" and prevN in candidates:
    region = "outer"
    n = prevN
    return

// 规则 2：编号小优先
region = "outer"
n = min(candidates)
```

> **边界点标记**：当 `len(candidates) > 1`（存在并列）或 `|P7 - Pmax| < TIE_BREAK_TOLERANCE` 时，CSV 中追加 `boundary_flag` 列记录"边界点"标记（值为 "P7-Pn" 或 "Pn-Pm" 表示并列孔对），便于后处理时审查。`boundary_flag` 不影响系数计算，仅用于数据质量追溯。

> **滞回机制的范围限制**：滞回仅在相邻扇区边界处生效（如 1↔2、2↔3、...、6↔1）。若上一时刻分区为 `outer/1`，当前时刻 candidates={3,4}（跨度大），不触发滞回，按规则 2 选 n=3。这避免跨大跨度跳转时被滞回错误地拉回旧分区。

> **TIE_BREAK_TOLERANCE 配置**：默认 5 Pa，依据扫描阀精度（u1≈20 Pa）和数据集边界点压力差（数据集 1 区 φ=30° 处 P1-P2≈74 Pa >> 5 Pa）综合确定。用户可在配置向导中调整，但不得低于 1 Pa（避免浮点噪声误触发）或高于 50 Pa（避免合法分区被误判为边界点）。

### 3.3 角度坐标系与分区阈值

**两套角度坐标系的几何关系**：

七孔探针采用两套角度坐标系描述来流方向，二者通过球坐标 ↔ 直角坐标的几何关系相互转换：

- **内区坐标系 (α, β)**：直角坐标系下的来流偏转角
  - α = 侧滑角（来流速度在 X 轴的分量对应的偏转角，vx>0 时 α>0，即来流偏 +X 时 α>0）
  - β = 迎角（来流速度在 Y 轴的分量对应的偏转角，vy>0 时 β>0，即来流偏 +Y 时 β>0）
  - 适用于来流接近正对探针（低迎角）的内区
- **外区坐标系 (θ, φ)**：球坐标系下的来流偏转角
  - θ = 俯仰角（来流方向与探针轴线 Z 的夹角，恒正，范围 [0°, 90°]）
  - φ = 滚转角（来流方向在 X-Y 平面的投影方位，**从 +Y 轴起算，从探针尾部看（-Z 方向看向 +Z）顺时针递增**，范围 [0°, 360°)）
  - 适用于来流大幅偏离探针轴（高迎角）的外区

**方位角 φ 与孔位、来流方位的对应关系**（与 2.3 节孔位表一致）：

| φ | 方位 | 迎流最大孔 | 来流偏转方向 | α 符号 | β 符号 |
|---|---|---|---|---|---|
| 0° | +Y | P1 | 来流偏 +Y（β+） | α=0 | β>0 |
| 60° | +Y 偏 -X | P2 | 来流偏 +Y 偏 -X | α<0 | β>0 |
| 90° | -X | P2/P3 | 来流偏 -X（α-） | α<0 | β=0 |
| 120° | -X 偏 -Y | P3 | 来流偏 -X 偏 -Y | α<0 | β<0 |
| 180° | -Y | P4 | 来流偏 -Y（β-） | α=0 | β<0 |
| 240° | -Y 偏 +X | P5 | 来流偏 -Y 偏 +X | α>0 | β<0 |
| 270° | +X | P5/P6 | 来流偏 +X（α+） | α>0 | β=0 |
| 300° | +X 偏 +Y | P6 | 来流偏 +X 偏 +Y | α>0 | β>0 |
| 330° | +Y 偏 +X | P1/P6 | 来流偏 +Y 偏 +X | α>0 | β>0 |

> **观察方向约定**：本规范所有方位角均"**从探针尾部看（-Z 方向看向 +Z）顺时针递增**"。此约定与孔位表（2.3 节）一致：P1(0°)、P2(60°)、P3(120°)、P4(180°)、P5(240°)、P6(300°)。注意"从探针尾部看顺时针"等价于"从探针头部看（+Z 方向看 -Z）逆时针"，与标准数学极坐标方向相反，因此坐标转换公式中 α 分量需带负号修正。

**分区阈值**（内/外区切换边界）：

| 边界条件 | 区域判定 | 说明 |
|---|---|---|
| θ < 30° | 内区（7 区） | 来流接近正对探针，P7 必为最大压力孔 |
| θ > 30° | 外区（1-6 区） | 来流大幅偏离探针轴，外围某孔 Pn 为最大压力孔 |
| θ = 30° | **按最大压力孔判定** | 边界点：P7 最大 → 内区；Pn（n=1..6）最大 → 外区 |

> **边界连续性说明**：θ=30° 是内/外区的几何边界。理论上 θ=30° 时既可能 P7 最大（来流仍偏向中心孔），也可能 Pn 最大（来流已偏向外围孔）。软件采用**数据驱动的分区判定**（见 3.2 节），不依赖角度阈值预设分区，保证边界附近数据后处理的连续性。

**坐标转换公式**（α, β ↔ θ, φ 双向换算）：

> **推导**：来流方向单位向量 v=(vx,vy,vz)，vz=cosθ，|v_xy|=sinθ。按 φ"从探针尾部看顺时针递增"约定：
> - vy = sinθ·cosφ（φ=0° 时 vy=sinθ 对应 +Y ✓）
> - vx = -sinθ·sinφ（φ=270° 时 vx=+sinθ 对应 +X ✓；负号源于 φ 方向与标准极角相反）
>
> 由 tanα=vx/vz、tanβ=vy/vz 得出以下公式。

**正向（外区 θ,φ → 内区 α,β）**——用于外区遍历时下发运动控制器：

```
β = arctan(tan θ × cos φ)
α = -arctan(tan θ × sin φ)        // 负号必须保留：φ 从探针尾部看顺时针递增，与标准极角方向相反
```

**反向（内区 α,β → 外区 θ,φ）**——用于内区数据回算到 θ-φ 平面或结果统一展示：

```
θ = arctan( √(tan²α + tan²β) )
φ = atan2(-tan α, tan β)          // atan2(y, x) 参数顺序：y=-tanα，x=tanβ；负号与正向公式对称
```

> **关键约束**：α 公式中的负号是 φ 方向约定的数学结果，**不得删除**。若删除负号，会导致外区运动控制器下发的 X 轴方向相反，来流偏 +X 时探针反而向 -X 运动。

**黄金用例**（必须通过的单位测试，覆盖 φ=0°/90°/180°/270° 四个主轴方位 + 一个数据集验证点）：

| 用例 ID | 输入 (θ, φ) | 正向输出 (α, β) | 反向回算 (θ, φ) | 期望最大孔 | 数据集验证 |
|---|---|---|---|---|---|
| G1 | θ=30°, φ=0° | α=0°, β=+30° | (30°, 0°) ✓ | P1 | 内区 α=0°,β=+5°→P1 最大 ✓ |
| G2 | θ=30°, φ=90° | α=-30°, β=0° | (30°, 90°) ✓ | P2/P3 | 内区 α=-5°,β=0°→P3 最大 ✓ |
| G3 | θ=30°, φ=180° | α=0°, β=-30° | (30°, 180°) ✓ | P4 | 内区 α=0°,β=-5°→P4 最大 ✓ |
| G4 | θ=30°, φ=270° | α=+30°, β=0° | (30°, 270°) ✓ | P5/P6 | 内区 α=+5°,β=0°→P5 最大 ✓ |
| G5 | θ=30°, φ=330° | α=+16.1°, β=+26.6° | (30°, 330°) ✓ | P1 | 外区 1 区首点 P1=3260 最大 ✓ |

> **G2 符号说明**：φ=90°（-X 方位）时 α=-30°（来流偏 -X），符合"α<0 → 来流偏 -X"的定义。G4 同理：φ=270°（+X 方位）时 α=+30°（来流偏 +X）。这两个用例验证了 α 公式中负号的正确性——若误删负号，G2 会给出 α=+30°（来流偏 +X），与 φ=90°（-X 方位）矛盾，可被测试捕获。

### 3.4 逻辑坐标与运动坐标（解决"逻辑点位和物理运动指令模型未统一"问题）

**双坐标模型声明**：

七孔校准的所有点位必须同时维护两套坐标，**职责严格分离，禁止混用**：

| 坐标类型 | 字段名 | 含义 | 适用阶段 | 内区表示 | 外区表示 |
|---|---|---|---|---|---|
| **逻辑坐标** `logicalCoordinates` | 用户配置与 CSV 落盘的角度 | 描述来流方向的物理角度，是业务语义坐标 | 配置生成、CSV 记录、系数计算、图表绘制 | `(α, β)` | `(θ, φ)` |
| **运动坐标** `motionCoordinates` | 运动控制器实际下发的目标角度 | 位移机构执行的物理目标，统一为 α-β 双轴 | 运动控制、到位判定、安全保护 | `(α, β)`（与逻辑坐标相同） | `(α', β')`（由 θ/φ 按 3.3 节正向公式换算） |

**数据结构定义**（Go Core 层）：

```go
// CalPoint 扩展字段（与五孔兼容，新增 MotionCoordinates）
type CalPoint struct {
    Coordinates          map[string]float64 // 逻辑坐标（业务语义，CSV 落盘用）
    MotionCoordinates    map[string]float64 // 运动坐标（运动控制器下发用，统一为 α-β）
    Region               string             // "inner" / "outer"
    Sector               int                // 外区扇区编号 1~6；内区固定 7
}
```

**换算时机与责任主体**：

1. **点位生成阶段**（`GenerateSevenHolePoints`，Go Core 层）：
   - 内区点：`MotionCoordinates = {"α": α, "β": β}`（与逻辑坐标相同）
   - 外区点：`logicalCoordinates = {"θ": θ, "φ": φ}` → 按正向公式换算 → `MotionCoordinates = {"α": α', "β": β'}`
   - **换算在点位生成时一次性完成**，运动执行阶段不再换算，避免运行时重复计算和潜在错误
2. **运动执行阶段**（`moveToPoint`）：只读 `MotionCoordinates`，按 `["α", "β"]` 严格顺序下发位移机构
3. **结果展示阶段**：CSV 保留原始 `logicalCoordinates`（θ, φ）便于追溯；前端图表按需用反向公式换算为 (α, β) 与内区数据合并

**运动顺序约束**（解决 `automatic_calibration.go:276` map 遍历顺序不稳定问题）：

> **七孔必须显式重写 `moveToPoint`，强制按 `["α", "β"]` 顺序下发运动控制器**，不得复用 `AutomaticCalibration` 的默认实现（默认实现遍历 `point.Coordinates` map，顺序不稳定）。
>
> 参考五孔模板：`automatic_calibration.go:278` 的 `MoveToPointWithOrder(point, []string{"α", "β"})`。七孔实现完全一致，仅类型判断从 `TypeFiveHole` 扩展为 `TypeFiveHole || TypeSevenHole`。

```go
// 七孔 moveToPoint 实现（必须重写，不得复用默认 map 遍历）
func (a *AutomaticCalibration) moveToPoint(point CalPoint, algorithm Algorithm) error {
    if algorithm != nil && algorithm.Type() == TypeSevenHole {
        return a.MoveToPointWithOrder(point, []string{"α", "β"}) // 严格 α→β 顺序
    }
    // ... 其他类型走默认逻辑
}
```

> **重要约束**：
> 1. 换算后的运动坐标 `(α', β')` 仅用于运动控制与结果统一展示，**不影响系数计算**。外区系数仍使用原始 (θ, φ) 坐标系下的压力数据计算。
> 2. `MotionCoordinates` 字段对五孔等已有模块保持向后兼容（五孔可不填，默认走 `Coordinates`）。七孔模块必须在点位生成时同时填两个字段。
> 3. 状态机特化点不得使用"外区先 θ 后 φ"等逻辑坐标描述运动顺序，运动顺序一律以 `MotionCoordinates` 的 α→β 为准。

## 4. 核心系数计算公式

### 4.1 内区公式（P7 为最大压力孔时）

**中间压力系数**：

```
P̄ = (P1 + P2 + P3 + P4 + P5 + P6) / 6                              ...(4)

Cpa = (P4 - P1) / (P7 - P̄)                                          ...(1)
Cpb = (P5 - P2) / (P7 - P̄)                                          ...(2)
Cpc = (P6 - P3) / (P7 - P̄)                                          ...(3)
```

**目标系数**：

```
Kβ = -(2·Cpa + Cpb - Cpc) / 3                                       ...(5)
Kα = (Cpb + Cpc) / √3                                               ...(6)
K0 = (P7 - p_t) / (p_t - p_s)                                       ...(7)
Ks = (p_s - P̄) / (p_t - p_s)                                        ...(8)
```

> **数据集验证**（中心点 α=0°, β=0°）：
> - P1..P7 = 537.18, 282.78, 313.98, 519.90, 573.97, 294.97, 4075.35
> - p_t = 4073.07, p_s = -32.7, P̄ = 420.46
> - 计算得 Kα=0.043, Kβ=-0.025, K0=0.00056, Ks=-0.110
> - CSV 实测值：Kα=0.043, Kβ=-0.025, K0=0.001, Ks=-0.11 ✓

### 4.2 外区公式（Pn 为最大压力孔时，n ∈ {1..6}）

**环形取模**：n+1 顺时针相邻，n-1 逆时针相邻。n=1 时 n-1=6；n=6 时 n+1=1。

```
Kθ[n] = (Pn - P7) / (Pn - (Pn+1 + Pn-1)/2)                          ...(9)
Kφ[n] = (Pn-1 - Pn+1) / (Pn - (Pn+1 + Pn-1)/2)                      ...(10)
K0[n] = (Pn - p_t) / (p_t - p_s)                                     ...(11)
Ks[n] = (p_s - (Pn+1 + Pn-1)/2) / (p_t - p_s)                        ...(12)
```

> **数据集验证**（大角度 1 区首点 φ=330°, θ=30°，P1 最大）：
> - P1=3260.217, P2=-874.900, P6=2973.950, P7=2168.100
> - p_t=4117.517, p_s=-30.133
> - n=1，n+1=2，n-1=6
> - 计算得 Kθ[1]=0.494, Kφ[1]=1.741, K0[1]=-0.207, Ks[1]=-0.260
> - CSV 实测值：0.494, 1.741, -0.207, -0.260 ✓

### 4.3 外区扇区边界连续性

**边界场景**：在相邻两个外区的 φ 边界处（如 φ=30° 是 1 区与 2 区的分界），相邻两孔压力相等，理论上可归入任一相邻区域。以 φ=30°（1 区与 2 区边界）为例，此时 P1 = P2 = Pmax，且由对称性 P3 = P6。

**各系数在边界处的连续性**：

| 系数 | 1 区计算（n=1） | 2 区计算（n=2） | 边界连续性 |
|---|---|---|---|
| Kθ[n] | (P1-P7)/(P1-(P2+P6)/2) | (P2-P7)/(P2-(P3+P1)/2) | **连续**：P1=P2 且 P3=P6，两式完全相等 |
| K0[n] | (P1-p_t)/(p_t-p_s) | (P2-p_t)/(p_t-p_s) | **连续**：仅取决于 Pn，P1=P2 故相等 |
| Ks[n] | (p_s-(P2+P6)/2)/(p_t-p_s) | (p_s-(P3+P1)/2)/(p_t-p_s) | **连续**：取决于相邻两孔均值，(P2+P6)/2=(P3+P1)/2 |
| Kφ[n] | (P6-P2)/(P1-(P2+P6)/2) = -2 | (P1-P3)/(P2-(P3+P1)/2) = +2 | **不连续**：符号反转，绝对值相同 |

**Kφ 边界符号反转的物理解释**：

不同区域的 Kφ[n] 定义中分子所用的相邻孔顺序不同（1 区用 Pn-1-Pn+1 = P6-P2，2 区用 Pn-1-Pn+1 = P1-P3）。在边界处 P1=P2=Pmax 且 P3=P6，代入后两式的分子绝对值相同但符号相反，导致 Kφ 在 ±2 之间跳变。

**软件处理规则**：

1. **边界点区域判定**：严格按 3.2 节的 tie-break 规则判定所属区域（P7 优先 + 编号小优先 + 滞回），保证相同输入永远落入同一分区。当 `len(candidates) > 1` 或 `|P7-Pmax| < 5 Pa` 时，CSV 追加 `boundary_flag` 列记录并列孔对（如 "P1-P2"），便于后处理审查。
2. **Kθ、K0、Ks 跨边界一致**：无论判定到哪个相邻区域，这三个系数的计算结果相同，可直接使用。
3. **Kφ 边界点特殊处理**：
   - 校准阶段：按实际判定的区域记录 Kφ[n]，**保留符号**（不取绝对值），CSV 中同时记录扇区编号 n 和 `boundary_flag`
   - 应用阶段（实测反算）：边界附近需结合上一时刻 Kφ 的符号连续性选择正确扇区，避免角度解算跳变；若实测压力两孔差 < 阈值，应标记为"边界不确定区"，输出双解（n 与 n+1 两个候选）供下游处理

> **重要**：Kφ 的边界符号反转是七孔探针算法的固有特性，**不是 bug**。开发时不得通过强制取绝对值等方式"消除"此现象，否则会破坏 Kφ-φ 曲线的单调性，导致实测反算时角度解算错误。

> **数据集验证**（φ=30° 边界点，1 区 → 2 区切换）：
> - 大角度 1 区 φ=30°, θ=30°：P1=3210.8, P2=3137.1（P1 略大），Kφ[1]=-1.933
> - 大角度 2 区 φ=30° 等效点（若存在）：应满足 Kφ[2]≈+1.933（理论对称）
> - 实测 1 区 Kφ 从 φ=330° 的 +1.741 单调递减到 φ=30° 的 -1.933，过零点在 φ=0° 附近，符合 Kφ-φ 单调性 ✓

### 4.4 马赫数与速度公式（与五孔一致，复用 `AtmosphericDataCalculator`）

```
p_t_abs = p_t + 大气压力
p_s_abs = p_s + 大气压力
Ma = √( (2/(γ-1)) × ((p_t_abs / p_s_abs)^((γ-1)/γ) - 1) )          γ = 1.4

SAT = TAT / (1 + 0.2 × r × Ma²)                                     r = 0.9 恢复系数
V = Ma × 20.047 × √SAT                                              20.047 = 声速系数
```

- TAT 选取优先级：风洞温度 TTunnel > 大气温度 TAtm
- 参考实现：`services/api-go/internal/core/calibration/atmospheric_data.go`

> **数据集验证**（中心点）：Ma = 0.242 ✓，V ≈ 83.7 m/s ≈ 标称 85 m/s ✓

## 5. 不确定度评定算法

### 5.1 基础不确定度分量

| 分量 | 类型 | 来源 | 公式 | 数值 |
|---|---|---|---|---|
| u1 | B 类（均匀分布） | 压力扫描阀误差（量程 ±35 kPa） | 70000 × 0.05% / √3 | 20.2 Pa |
| u2 | B 类（均匀分布） | 风洞气流总压脉动 | p_t × 0.1% / √3 | 随 p_t 变化 |
| u3 | B 类（均匀分布） | 位移机构运动误差引起压力变化 | 5 / √3 | 3 Pa |
| u4 | B 类（均匀分布） | 静压测量扫描阀误差（量程 ±10 kPa） | 20000 × 0.05% / √3 | 5.8 Pa |
| u(A) | A 类 | 测量重复性 | S(x) / √n | 随测量值变化 |

**u(A) 的精确定义**（解决"u(A) 是输入标准差还是输出标准差"歧义）：

- **u(A) 是每个压力输入量的 A 类不确定度**，不是系数最终结果的 A 类不确定度
- 对于每个压力输入 P ∈ {P1, P2, ..., P7, p_t, p_s}，单点采集 N 次（N ≥ 3，默认 5），计算样本标准差 S(P) 和均值的标准差 u(A, P) = S(P) / √N
- 每个压力输入有独立的 u(A, P)，代入传播律时按对应输入的 cᵢ 使用
- 示例：K0 = (P7 - p_t) / (p_t - p_s)，u(A) 项为：
  ```
  u_A(K0) = √( c(P7)²·u(A,P7)² + c(p_t)²·u(A,p_t)² + c(p_s)²·u(A,p_s)² )
  ```
  其中 c(P7)、c(p_t)、c(p_s) 见 5.3 节灵敏系数

### 5.2 合成标准不确定度（传播律，各分量相关系数取 1）

**通用传播律公式**：

```
u_c(y) = √( Σᵢ cᵢ²·uᵢ²  +  2·Σᵢ<ⱼ ρᵢⱼ·cᵢ·cⱼ·uᵢ·uⱼ )
```

其中 ρᵢⱼ 为输入 i 与输入 j 的相关系数。

**相关系数取 1 时的正确简化**（修正原"Σ|cᵢ|uᵢ"错误）：

当所有输入两两完全正相关（ρᵢⱼ = 1）时：

```
u_c²(y) = Σᵢ cᵢ²·uᵢ²  +  2·Σᵢ<ⱼ cᵢ·cⱼ·uᵢ·uⱼ
        = (Σᵢ cᵢ·uᵢ)²
```

故：

```
u_c(y) = | Σᵢ cᵢ·uᵢ |                  // 注意：是和的绝对值，不是绝对值的和
```

> **关键区别**：
> - ✅ 正确（ρ=1）：`u_c = |c₁u₁ + c₂u₂ + c₃u₃ + ...|`（保留符号求和后取绝对值）
> - ❌ 错误：`u_c = |c₁|u₁ + |c₂|u₂ + |c₃|u₃ + ...`（绝对值的和，隐含 ρᵢⱼ = sign(cᵢcⱼ)）
>
> 后者隐含"灵敏系数同号时正相关、异号时负相关"，是一种保守估计，但**不是 ρ=1 的标准结果**。当灵敏系数有正有负时（如 Ks 中 c(P1..P6) = -1/(6·(p_t-p_s)) 为负、c(p_t) 为正），两种公式结果不同。
>
> **采用正确公式 `|Σ cᵢuᵢ|`**：当灵敏系数异号时，正负项部分抵消，反映 ρ=1 时误差同向传播的真实物理意义。

**各分量相关性依据**：
- u1、u2、u3、u4 来自同一压力扫描阀和同一风洞，**完全正相关**（ρ=1）
- u(A, Pi) 与 u(A, Pj) 来自同一组采样，**部分相关**（ρ=1，因为同一组 N 次采样的随机误差来源相同）
- u(A) 与 u1/u2/u3/u4 来源不同（采样随机性 vs 系统误差），**相互独立**（ρ=0）

**合成公式（B 类相关 + A 类独立）**：

```
u_c(y) = √( |Σᵢ cᵢ·u_B,i|²  +  Σᵢ cᵢ²·u(A,i)² )
                ↑                  ↑
            B 类完全正相关       A 类各输入独立
            （取和的绝对值）     （平方和开方）
```

其中 u_B,i ∈ {u1, u2, u3, u4}，u(A,i) 为每个压力输入的 A 类不确定度。

### 5.3 灵敏系数定义

**内区 K0 = (P7 - p_t) / (p_t - p_s)** 的灵敏系数：

```
C(P7)  =  1 / (p_t - p_s)
C(p_t) =  (p_s - P7) / (p_t - p_s)²
C(p_s) =  (P7 - p_t) / (p_t - p_s)²
```

**内区 Ks = (p_s - P̄) / (p_t - p_s)** 的灵敏系数（P̄ = (P1+...+P6)/6）：

```
C(P1..P6) = -1 / (6·(p_t - p_s))
C(p_t)    = (P1+P2+P3+P4+P5+P6 - 6·p_s) / (6·(p_t - p_s)²)
C(p_s)    = (6·p_t - P1-P2-P3-P4-P5-P6) / (6·(p_t - p_s)²)
```

**内区 Kα、Kβ** 的灵敏系数：由 Cpa、Cpb、Cpc 复合而成，需链式求导。

**外区 K0[n]、Ks[n]、Kθ[n]、Kφ[n]** 的灵敏系数推导同理（详见附录 A.6~A.9）。

### 5.4 扩展不确定度

```
U = k × u_c        k = 2（默认，95% 置信区间）
```

**目标参考值**（验收阈值，含绝对容差，解决"≈ 不可自动判定"问题）：

| 系数 | 扩展不确定度 U (k=2) 目标值 | 容差范围 | 判定方式 |
|---|---|---|---|
| U(Kα), U(Kβ), U(Kθ), U(Kφ) | 0.010 | [0.008, 0.012] | 中心点算例结果落在容差范围内即通过 |
| U(K0), U(K0[n]) | 0.006 | [0.004, 0.008] | 同上 |
| U(Ks), U(Ks[n]) | 0.06 | [0.04, 0.08] | 同上 |

### 5.5 中心点完整算例（可复算验证）

以数据集中心点（α=0°, β=0°）为例，演示 K0 不确定度的完整计算流程：

**输入数据**（通道原始值/表压，单位 Pa）：
- P7 = 4075.35, p_t = 4073.07, p_s = -32.7, 大气压力 = 98880
- 假设单点采样 N=5 次，样本标准差 S(P7) = 2.0 Pa, S(p_t) = 3.0 Pa, S(p_s) = 1.5 Pa

**第 1 步：B 类不确定度（按误差源分组）**

| 输入 | 受影响误差源 | u_B,i (Pa) |
|---|---|---|
| P7 | u1（扫描阀）+ u3（运动） | √(20.2² + 3²) = 20.42 |
| p_t | u2（总压脉动, p_t×0.1%/√3 = 4073×0.001/√3 = 2.35）+ u3 | √(2.35² + 3²) = 3.81 |
| p_s | u4（静压扫描阀）+ u3 | √(5.8² + 3²) = 6.53 |

> 注：本算例假设 u1~u4 对各输入的影响按误差源物理归属分组，u3（运动误差）对所有压力输入都影响。详细分组依据见实现时的 `UncertaintyCalculator` 设计。

**第 2 步：A 类不确定度（各输入独立，N=5）**

| 输入 | u(A,i) = S/√N (Pa) |
|---|---|
| P7 | 2.0 / √5 = 0.894 |
| p_t | 3.0 / √5 = 1.342 |
| p_s | 1.5 / √5 = 0.671 |

**第 3 步：K0 灵敏系数**（见 5.3 节）

K0 = (P7 - p_t) / (p_t - p_s) = (4075.35 - 4073.07) / (4073.07 - (-32.7)) = 2.28 / 4105.77 = 0.000555

```
c(P7)  =  1 / (p_t - p_s)         = 1 / 4105.77 = 2.436e-4
c(p_t) =  (p_s - P7) / (p_t - p_s)² = (-4108.05) / 4105.77² = -2.437e-4
c(p_s) =  (P7 - p_t) / (p_t - p_s)² = 2.28 / 4105.77² = 1.352e-7
```

**第 4 步：B 类合成（ρ=1，取和的绝对值）**

```
Σ cᵢ·u_B,i = c(P7)·u_B(P7) + c(p_t)·u_B(p_t) + c(p_s)·u_B(p_s)
           = 2.436e-4 × 20.42 + (-2.437e-4) × 3.81 + 1.352e-7 × 6.53
           = 4.974e-3 + (-9.285e-4) + 8.83e-7
           = 4.046e-3

|Σ cᵢ·u_B,i| = 4.046e-3
```

> **注意**：c(P7) 与 c(p_t) 符号相反，正负项部分抵消。若误用"Σ|cᵢ|uᵢ"会得到 4.974e-3 + 9.285e-4 + 8.83e-7 = 5.903e-3，**高估 46%**。

**第 5 步：A 类合成（ρ=0，平方和开方）**

```
√(Σ cᵢ²·u(A,i)²) = √( (2.436e-4 × 0.894)² + (-2.437e-4 × 1.342)² + (1.352e-7 × 0.671)² )
                 = √( 4.748e-8 + 1.068e-7 + 8.22e-15 )
                 = √1.543e-7
                 = 3.928e-4
```

**第 6 步：合成标准不确定度**

```
u_c(K0) = √( |Σ cᵢ·u_B,i|² + Σ cᵢ²·u(A,i)² )
        = √( (4.046e-3)² + (3.928e-4)² )
        = √( 1.637e-5 + 1.543e-7 )
        = √1.652e-5
        = 4.065e-3
```

**第 7 步：扩展不确定度（k=2）**

```
U(K0) = 2 × 4.065e-3 = 8.13e-3 ≈ 0.008
```

> **结果对比**：目标值 0.006，容差 [0.004, 0.008]，算例结果 0.008 **刚好在容差上限**。说明本算例的假设参数（样本标准差）略偏大，实际校准时若采样 10 次以上（u(A) 减半），U(K0) 可降至 0.006 以内。
>
> **算例可复算性**：以上所有数值可用 Python/Go 代码逐行复算，作为 `UncertaintyCalculator` 的单元测试基准。

### 6.2 角度遍历策略

> **校准模式声明**（解决"默认点位、数据集、验收标准三个产品不一致"问题）：
>
> 本规范定义两种校准模式，**产品默认采用完整模式，数据集模式仅用于算法验证**：
>
> | 模式 | 内区点数 | 外区点数 | 总点数 | 用途 | 配置 |
> |---|---|---|---|---|---|
> | **完整模式**（产品默认） | 169（α∈[-30°,30°], β∈[-30°,30°], 步长 5°） | 504（θ∈[30°,60°], φ∈[0°,355°], 步长 5°） | **673** | 实际生产校准 | 用户可配置范围与步长 |
> | **数据集模式**（验证基准） | 169（同上） | 312（θ∈{30°,35°,40°,45°}, φ 跨 6 个 60° 扇区, 步长 5°, 每扇区 13 点） | **481** | 算法正确性验证、回归测试 | 固定不可配置，硬编码在测试代码中 |
>
> **模式选择规则**：
> - 生产环境启动校准时：默认完整模式（673 点），用户可在配置向导中切换为"快速模式"（减小 θ 上限或 φ 范围）
> - 算法验证/回归测试时：强制使用数据集模式（481 点），与 `W532.202608.P.7H.1-01` 数据集逐一对照
> - 验收标准 11.1 算法正确性验收使用数据集模式（481 点），11.2 流程完整性验收使用完整模式（673 点）

> **推荐工况声明**：以下角度范围与步长为 JJF(军工)19-2012 推荐的默认校准工况，适用于一般风洞七孔探针校准场景。用户可在配置向导中根据实际使用要求自定义校准工况（如缩小范围只校准某一扇区、提高分辨率采用 2°/1° 步长、或扩展 θ 上限至 60°+ 等）。

**所有角度范围与步长均可在配置向导中设置**，以下为推荐默认值（完整模式）。

**内区遍历**（α-β 网格）：
- α 范围：推荐 [-30°, 30°]，步长推荐 5°（可配置）
- β 范围：推荐 [-30°, 30°]，步长推荐 5°（可配置）
- 默认总点数：13×13 = 169
- 走位策略：蛇形（β 固定时 α 递增/递减交替），减少运动行程
- 运动控制器下发：直接下发 (α, β)

**外区遍历**（θ-φ 网格）：
- θ 范围：推荐 [30°, 60°]，步长推荐 5°（可配置）
- **φ 范围：推荐 [0°, 355°]，可配置**（如只需校准某几个扇区可缩小范围）
- **φ 步长：推荐 5°，可配置**（如需更高分辨率可设 2°/1°，需快速校准可设 10°）
- 默认总点数：7×72 = 504
- 走位策略：按 θ 分组，每个 θ 下 φ 从 0° 扫到 355°，减少位移机构旋转累计误差
- **运动控制器下发：将 (θ, φ) 换算为 (α, β) 后下发**（见 3.3 节换算公式）

> **数据集模式外区点数说明**：数据集 W532.202608.P.7H.1-01 的外区每区 52 点（13×4），6 个区共 312 点。其 θ 仅取 {30°,35°,40°,45°}（4 个值），φ 按扇区跨 60° 每步 5° 取 13 个点。这是数据集采集时的简化配置，**不作为产品默认**，仅用于算法验证。

> **自定义工况约束**：
> - θ 下限不得低于 30°（内/外区几何边界，见 3.3 节分区阈值）
> - θ 步长不得小于 1°（位移机构分辨率限制）
> - φ 步长推荐取 360° 的整数约数（1°/2°/3°/4°/5°/6°/10°/12°/15°/20°/30°），保证均匀覆盖
> - 校准总点数硬上限：1000 点（防止极端配置导致磁盘/时间消耗过大）
> - **扇区边界点去重规则**：相邻扇区共享的 φ 边界点（如 φ=30° 同时属于 1 区和 2 区）只采集一次，按最大压力孔判定归属一个扇区，CSV 中记录实际判定的扇区编号 n。完整模式 φ∈[0°,355°] 步长 5° 共 72 点（无重复），数据集模式每扇区独立采集不共享。

**遍历顺序**：
1. 先完成内区遍历（θ ≤ 30°）
2. 再按 θ 升序进入外区遍历（θ = 30°, 35°, 40°, 45°, 50°, 55°, 60°）
3. 每个 θ 下按 φ 递增遍历（覆盖 6 个扇区）

> **分区切换与扇区遍历**：外区遍历过程中，每个点位根据压力数据动态判定属于哪个扇区（1-6 区），软件无需预先按扇区分组点位。分区切换由数据驱动，软件在分区变化时推送 `OnRegionChanged` 事件便于 UI 显示。

### 6.3 单点采集流程

> **双坐标模型说明**：本流程所有"下发运动控制器"步骤均使用 `CalPoint.MotionCoordinates`（统一 α-β 双轴），逻辑坐标 `CalPoint.Coordinates` 仅用于 CSV 落盘与系数计算。详见 3.4 节。

```
1. 点位生成器（GenerateSevenHolePoints，Go Core 层）输出 CalPoint：
   - 内区点：Coordinates={α,β}, MotionCoordinates={α,β}（与逻辑坐标相同）
   - 外区点：Coordinates={θ,φ}, MotionCoordinates={α',β'}（按 3.3 节正向公式换算）
   - 换算在点位生成阶段一次性完成，运行时不再换算
2. moveToPoint 读取 MotionCoordinates，按 ["α","β"] 严格顺序下发位移机构
3. 等待位移机构到位（容差区内判定到位，超时由看门狗保护）
4. 等待驻留时间（DwellTimeMs，默认值待定）
5. 等待气流稳定（球罐门控判定，超时 300s）
6. 单点重复采集 N 组数据（N ≥ 3，默认 5）：
   for sampleIdx in [1..N]:
     waitForFreshData（5s 超时，10ms 轮询）
     读取 P1..P7, p_t, p_s, 大气压力, 大气温度
     累加求和（用于平均值）
     计算样本标准差（用于 A 类不确定度）
     onRealtime（100ms 节流推送实时压力到前端）
7. 计算平均值（P1_avg..P7_avg, pt_avg, ps_avg 等）
8. 流场分区判定（P7 最大 → 内区；否则外区，n = argmax(P1..P6)，含 3.2 节 tie-break 规则）
9. 按分区调用对应公式计算系数：
   - 内区：CalculateSevenHoleInnerCoefficients（公式 1-8）
   - 外区：CalculateSevenHoleOuterCoefficients（公式 9-12，含环形取模）
10. 计算不确定度（UncertaintyCalculator，公式见第 5 节）
11. CSV 追加写入（立即 Flush，崩溃不丢点，落盘用逻辑坐标 Coordinates）
12. 推送进度事件到前端（OnProgress）
```

### 6.4 状态机

复用五孔模块的 `automatic_calibration.go` 模板方法，状态枚举：

- `StateIdle`：空闲
- `Running`：运行中
- `Paused`：暂停（立即 StopMotion，阻塞主循环）
- `Stopped`：已停止
- `Error`：错误（运动故障、球罐超时等）
- `Completed`：完成

**七孔特化点**：
- `moveToPoint`：**内区与外区统一按 `["α","β"]` 顺序下发运动控制器**（详见 3.4 节双坐标模型）。外区点在点位生成阶段已完成 (θ,φ)→(α',β') 换算，运动执行阶段只读 `MotionCoordinates`，不再区分内/外区。**禁止使用"外区先 θ 后 φ"等逻辑坐标描述运动顺序**——逻辑坐标仅用于 CSV 落盘与系数计算。
- `AcquireDataWithChannels`：调用七孔算法（含分区判定）
- 分区切换时推送 `OnRegionChanged` 事件（**必需事件**，详见 8.1 节事件契约；UI 顶部状态栏必须显示当前区域）

### 6.5 运动安全多层保护（复用五孔模块）

| 保护机制 | 触发条件 | 处理动作 |
|---|---|---|
| 到位容差 | 实际位置与目标位置偏差 > 容差 | 等待到位或超时 |
| 严重偏离 | 实际位置与目标位置偏差 > 严重偏离阈值 | 急停 + 标记 Error |
| 看门狗 | 到位等待超时 | 急停 + 标记 Error |
| 急停 | 用户点击急停按钮或硬件急停信号 | 立即停止所有运动 |

参考实现：`services/api-go/internal/core/calibration/automatic_calibration.go` 的 `waitMotionCompleteOrAbort` 方法。

### 6.6 球罐门控（复用五孔模块）

判定条件：监控通道（通常 p_t）在 `WaitTimeSec`（默认 300s）内波动 ≤ `Tolerance`。

## 8. 状态推送与 UI 交互

### 8.1 后端事件推送（复用五孔模块）

> **事件契约约束**（解决"OnRegionChanged 在状态机中标为可选，却在事件契约和验收中成为必需"问题）：
>
> 七孔校准的所有事件均为**必需事件**，不存在"可选"事件。`OnRegionChanged` 是七孔相对五孔的新增必需事件，必须在分区切换（inner↔outer、outer/n→outer/m）时立即推送，UI 顶部状态栏据此显示当前区域。

| 事件 | 必需性 | 触发时机 | 用途 |
|---|---|---|---|
| `OnProgress` | 必需 | 每个点完成时 | 推送进度（当前点/总点数） |
| `OnRealtime` | 必需 | 单点采集期间 100ms 节流 | 推送实时压力值 |
| `OnSampleProgress` | 必需 | 每次子采样完成 | 推送子采样进度（当前/N） |
| `OnComplete` | 必需 | 所有点完成 | 推送完成事件 |
| `OnRegionChanged`（七孔新增） | **必需** | 分区切换时（inner↔outer、outer/n→outer/m） | 推送当前区域（内区/外区 N 区）+ `boundary_flag`（若触发 tie-break） |

**`OnRegionChanged` 事件 payload 规范**：

```json
{
  "region": "outer",         // "inner" 或 "outer"
  "sector": 3,               // 外区扇区编号 1~6；内区固定 7
  "prevRegion": "inner",     // 上一时刻分区（首点为 null）
  "prevSector": 7,           // 上一时刻扇区（首点为 null）
  "boundaryFlag": null,      // 触发 tie-break 时为 "P1-P2" 等并列孔对标识，否则 null
  "pointIndex": 170,         // 当前点位索引（0-based）
  "totalPoints": 673
}
```

> **实现要求**：
> 1. 分区判定逻辑必须维护 `prevRegion`/`prevSector` 状态（在 `AutomaticCalibration` 子类中作为字段保存），每个点位判定后与上一时刻比较，不同则推送 `OnRegionChanged`。
> 2. 首个点位（`pointIndex == 0`）无论判定结果如何都必须推送一次 `OnRegionChanged`，`prevRegion` 为 null，便于 UI 初始化区域显示。
> 3. 事件推送失败不得阻塞主循环（参考 `EventPublisher` 的非阻塞推送机制）。

参考实现：`services/api-go/internal/usecase/calibration.go` 的 `EventPublisher`。

### 11.1 算法正确性验收

| 验收项 | 验收方式 | 通过标准 |
|---|---|---|
| 内区公式 | 用数据集中心点（α=0,β=0）和 α=±5,β=±5 共 5 个点验证 | 计算值与 CSV 实测值误差 ≤ 0.001 |

| 不确定度（Ks） | 用中心点数据验证 | U(Ks) ∈ [0.04, 0.08] |

## 12. 关键约束与注意事项

1. **CSV 表头命名必须修正**：大角度区前 2 列应为"滚转角 φ, 俯仰角 θ"（不是"侧滑角 α, 迎角 β"）；后 4 列系数应为 Kθ[n]、Kφ[n]、K0[n]、Ks[n]（不是 Kα、Kβ、K0、Ks）。当前数据集存在历史遗留命名错误，开发时必须按本规范命名。

2. **角度定义明确标注**：UI 必须区分"内区 α/β"和"外区 θ/φ"，避免与五孔的"α=攻角, β=侧滑角"混淆。建议在配置向导和主画面显眼位置标注。

3. **流场分区判定是七孔的核心复杂度**：每个采集点必须先判定内区/外区，再调用对应公式。建议在 `CalculateSevenHoleCoefficients` 入口处统一判定，返回带 `region` 和 `n` 字段的结果结构。

4. **外区系数需带扇区编号 n**：6 个外区的同名系数（如 Kθ[1]~Kθ[6]）物理含义相同但数值不可比，CSV 写入和图表绘制必须按 n 分组。

5. **不确定度评定是规范强制要求**：当前五孔模块没有不确定度计算，七孔模块必须新增。建议封装为 `UncertaintyCalculator` 独立组件，便于后续复用到其他校准类型。

6. **K0/Ks 分母差异**：五孔用 `qRef = P2 - pSide`（参考动压），七孔用 `p_t - p_s`（来流总静压差）。这是公式定义差异，不能混用。

7. **外区点位生成需支持分区重叠**：当前数据集每个分区包含 13 个 φ 点（边界点重复），点位生成器需支持"按扇区生成 + 边界点去重或保留"两种模式。

8. **角度转换公式用于结果统一**：校准完成后外区数据需转换为 α-β 坐标，便于与内区数据合并绘制完整校准曲面。但 CSV 中仍保留原始 θ-φ 值便于追溯。

9. **依据 `project_memory.md §38`**：所有 API 出口必须共用一个 sanitize/DTO 层，未配置轴的坐标（NaN 哨兵）必须走 `sanitizePointForJSON` 清洗，禁止领域结构原样塞进 `map[string]any` 序列化。

10. **依据 `project_memory.md §4`**：分区切换用 Info 级别日志，单点采集进度用 Debug 级别；硬件通信日志默认显示，普通 Info 日志默认关闭，前端独立开关控制。
