# Wind-DAQ Structure

This project has been reset for a clean rebuild.

## Directories

- `apps/desktop-wails/frontend`: Vue 3 Wails frontend.
- `apps/desktop-wails/backend`: Wails Go host and thin bindings.
- `services/api-go`: Go backend using core/usecase/ports/adapters layering.
- `contracts`: API and protocol contracts.
- `config`: project configuration templates.
- `deploy`: environment deployment assets.
- `tests`: integration and hardware-in-loop tests.
- `docs/migration`: migration analysis from the TS/Electron reference.
