# wista 桌面应用 — 人工功能测试用例

> **版本**: 0.1.0  
> **日期**: 2026-06-02  
> **测试环境**: Windows 11 + WISTA 硬件设备（IP: 192.168.3.x, 端口: 9000）  
> **测试类型**: 黑盒功能测试（人工执行）

---

## 测试准备

### 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 11 |
| WISTA 设备 | 1台或多台，已配置好网络（IP 可达） |
| 网络环境 | 设备与 PC 在同一网段，ping 通 |
| 应用版本 | 最新构建的 Wails 桌面应用 |

### 测试数据准备

- 设备 IP 地址清单（至少 1 台真实设备）
- 热电偶类型：K 型（默认）
- 预期温度范围：室温 ~ 200°C（可用热水/冰块验证）
