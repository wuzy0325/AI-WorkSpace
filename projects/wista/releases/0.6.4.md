# DAQ-T-1603 v0.6.4

Release date: 2026-07-31
Package: daq-t1603-0.6.4-amd64-installer.exe

## Summary

修复两个影响现场稳定性的关键问题:(1) 设备固件在 `@f0` 后并行发送 ACK 与数据流时序竞争导致约 10~15% 概率出现采集启动卡死或 Stop 收集窗口错位;(2) Windows 故障机器 UDP discovery 的 `SO_RCVTIMEO` / `SO_SNDTIMEO` 在 kernel IOCP deadline 失效时永久阻塞(ADR-009 R0-8/R0-9 兜底)。同时补齐适配器生命周期与 probe 调试工具链。

## User-visible Changes

- 启动采集成功率提升至实机 90+ 轮 0 警告 0 错误(此前约 10~15% 启动失败概率)。
- UDP 设备扫描在 ADR-009 故障 Windows 机器上不再永久卡死,扫描失败时返回明确错误并废弃 socket。
- 新增 `stopstartprobe` CLI 调试工具,用于排查快速启停采集时 TCP socket 残留帧问题。

## Fixes

- **FrameReader 容忍迟到 Start ACK**(`shared/device-sdk/go/protocol/daq_t1603_frame.go`):Start 端不再要求首字节必须为 `'A'`,用偏移 0/偏移 1 帧合法性对齐真实边界;正常采集路径支持丢弃 1 个前导字节自愈(迟到 ACK/残杂字节);Stop 采用 150ms 静默窗口确认 `N×64+ACK`,`finalize` 容忍 1 个前导残杂 `'A'`。设备固件在 `@f0` 后并行发送 ACK 与数据流,发送顺序不保证(约 85% ACK 首字节;约 10~15% 数据帧先到或带 1 个前导残杂字节;迟到的 Start ACK 还可能落在 Stop 收集窗口,实机 `raw=41 41`)。
- **适配器 StopAcquisition 防 `close of closed channel` panic**(`adapters/hardware/t1603_adapter.go`):持锁期间原子移除 `stopChs`/`channels` 再锁外关闭,避免 `OnReadLoopExit` 回调对同一 channel 二次 close 触发 panic。
- **UDP discovery Send/Receive watchdog 兜底**(`adapters/hardware/discovery_socket.go`,跨平台):新增 `discoverySendTimeout=2s` 常量;`Send` 加 `SetWriteDeadline` + watchdog 双兜底(ADR-009 R0-9),原 `WriteTo` 在 Windows 故障机器 kernel IOCP deadline 失效时永久阻塞;`Receive` 加 `SetReadDeadline` + watchdog 双兜底(ADR-009 R0-8),原 `ReadFrom` 同根问题。触发后 socket 废弃,调用方不得复用。
- **Windows discovery socket watchdog 修复**(`adapters/hardware/discovery_socket_windows.go`):新增 `soSNDTIMEO=0x1005`(golang.org/x/sys/windows v0.43/0.47 未导出 `SO_SNDTIMEO`,Winsock2.h 定义稳定);`winsockDiscoverySocket` 加 `handleMu sync.Mutex` 保护 handle;新增 `closeHandleLocked`(原子取走 handle + `Closesocket`,多次调用安全);新增 `startWatchdog` 返回 stop-and-join 函数(ADR-009 finding 5 修复):`time.AfterFunc.Stop` 返回 false 仅表示已 fire,不保证 callback 已完成,通过 `sync.WaitGroup` 确保 callback 完全退出后才返回,避免 callback 在 `Send`/`Receive` 返回后才执行 `Closesocket` 误关已复用的 socket 数值。
- **scanner 适配新 discoverySocket 接口**(`adapters/hardware/t1603_scanner.go`):适配新的 `discoverySocket` 接口,新增 watchdog 触发 / 多目标扫描测试。
- **适配器适配新 SDK 接口**(`adapters/hardware/t1603_adapter.go`):适配 `shared/device-sdk` 新的 `sendCommand` A/E 严格校验,适配新的 `invalidateConnection` / `resyncHardwareConfigMode` 接口。
- **probe 工具适配**(`cmd/frameprobe/main.go` / `cmd/freqprobe/main.go`):适配新的 frame reader 接口,命令行输出格式调整便于调试。

## Install / Upgrade

- 兼容覆盖安装,**无需卸载旧版本**。
- 推荐的安装步骤:
  1. 关闭正在运行的旧版本 DAQ-T-1603。
  2. 双击 `daq-t1603-0.6.4-amd64-installer.exe` 进行覆盖安装。
  3. 启动新版本,连接设备验证连续启停采集(Start→20ms→Stop)≥ 30 轮无错误。
- 如需卸载旧版本残留:通过"控制面板 → 卸载"或安装目录下的 `Uninstall.exe` 完成。
