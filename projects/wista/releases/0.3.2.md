# DAQ-T-1603 v0.3.2

Release date: 2026-07-03
Package: daq-t1603-0.3.2-amd64-installer.exe

## Summary

跨项目对齐 CSV 时间戳格式，统一秒级精度。

## Fixed

- CSV Timestamp 列从带毫秒（`'YYYY-MM-DD HH:MM:SS.mmm`）改为秒级（`'YYYY-MM-DD HH:MM:SS`）。
  - 跨项目对齐 daq-p1604 / wind-daq 时间戳格式变更（daq-t1603 本身无固件 bug，被动对齐以保持数据格式一致性）。
  - 高频采集下毫秒精度时间戳不可靠（DAQ-P-1604 设备固件 bug 详见 daq-p1604 v0.2.2 release note）。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：CSV Timestamp 列精度从毫秒降为秒级。1000Hz 采集下，1 秒内所有帧共享同一时间戳。

## Install / Upgrade

- 可直接覆盖安装 v0.3.1 或更早版本。
- 安装步骤：
  1. 关闭正在运行的 DAQ-T-1603。
  2. 运行 daq-t1603-0.3.2-amd64-installer.exe。
  3. 启动后确认 GUI 正常出现。
