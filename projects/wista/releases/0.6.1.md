# DAQ-T-1603 v0.6.1

Release date: 2026-07-28
Package: daq-t1603-0.6.1-amd64-installer.exe

## Summary

本版本修复特定 Windows 环境中 UDP 设备扫描不返回的问题，并增加应用退出确认保护。

## User-visible Changes

- 设备扫描会在固定时间内返回已发现设备，不再依赖 Go IOCP deadline 取消行为。
- 点击窗口关闭按钮时需要确认退出。

## Fixes

- Windows 扫描使用同步 Winsock `Recvfrom` 和 `SO_RCVTIMEO`，规避异步读取取消卡死。

## Compatibility

- 配置文件格式兼容。
- CSV 数据格式不变。
- 设备发现命令和响应协议不变。

## Install / Upgrade

- 可覆盖安装 0.6.0，无需先卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本。
- 运行 `daq-t1603-0.6.1-amd64-installer.exe`，安装后启动应用确认主窗口正常出现。
