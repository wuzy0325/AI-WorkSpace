# DAQ-T-1603 v0.2.0

Release date: 2026-07-01
Package: daq-t1603-0.2.0-amd64-installer.exe

## Summary

录制系统重构：新增背压处理、文件滚动、后端服务拆分，提升高并发场景稳定性。

## Added

- 新增录制背压处理系统（BackpressureEvent），队列饱和时非阻塞通知并丢帧计数。
- 新增 SetFatalErrorHandler，不可恢复 I/O 错误时通知前端。
- RecordingSession 新增 DroppedCount 字段。

## Changed

- CSV 录制器重写：多设备独立写入、非阻塞异步队列、文件滚动支持。
- 后端重构：删除 monolithic app.go，拆分 relayStream 到 DeviceService。
- RecordingService 注入背压和 fatal 错误回调，限频 1Hz。
- 前端适配新的录制状态和背压事件。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容。
