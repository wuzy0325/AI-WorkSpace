# DAQ-T-1603 v0.3.0

Release date: 2026-07-02
Package: daq-t1603-0.3.0-amd64-installer.exe

## Summary

新增硬件通信日志，前端可查看驱动层完整的命令交互流程，便于现场调试与问题排查。

## Added

- 硬件通信日志：驱动层 hardware-send/hardware-recv 日志提升为 info 级别，前端通信分组可查看 TCP 连接/断开、@fd/@fe/@f0 等命令的发送与响应。采集期间的二进制数据帧不打印，避免高频刷屏。
