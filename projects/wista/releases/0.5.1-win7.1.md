## Summary

Win7 LTS 维护版本，自 0.5.0-win7.1 以来同步 master 0.6.0~0.6.4 全部业务修复：ADR-009 网络看门狗、UDP discovery 加固、TCP connection watchdog fallback、delayed Start ACK 容忍与 Stop 边界可靠化、设备连接错误日志、应用内退出按钮替换为窗口 X 确认、中英文切换、桌面控件改进。所有变更通过 master→lts/win7 cherry-pick 同步，业务层零代码差异，仅 Win7 平台壳保持 Electron 22.3.27 + Go 1.20.14。

## Changes vs 0.5.0-win7.1

### Added

- **中英文界面切换**（同步 master 0.6.0）：独立应用新增中英文界面切换，并保持语言偏好。
- **桌面控件改进与共享 UI**（同步 master 0.6.0）：MonitorView 控件与共享 UI 优化，提升现场操作可读性。

### Changed

- **应用内退出按钮替换为窗口 X 确认**（同步 master）：daq-p1604 / daq-t1603 移除应用内退出按钮，统一走窗口关闭按钮 + 确认对话框，避免误触。

### Fixed

- **设备连接失败错误日志**（同步 master 0.6.0）：连接失败写入明确错误日志，便于现场定位地址、网络和协议问题。
- **共享 SDK 连续静默窗口排空逻辑**（同步 master 0.6.0）：降低快速启停后的残留帧尾感染风险。
- **Winsock watchdog fallback**（同步 master 0.6.2）：Windows Winsock 在 deadline 触发后偶发不返回的问题，watchdog 强制 Close 后返回 double 连接，保护 handshake/discovery/command-response/stop/disconnect 路径。
- **TCP connection watchdog fallback**（同步 master 0.6.3）：TCP 连接层补充 watchdog 兜底，避免阻塞 goroutine。
- **ADR-009 UDP discovery watchdog + adapter lifecycle**（同步 master 0.6.3）：UDP discovery 增加 watchdog + 并发扫描保护 + adapter 生命周期清理；probe tools 同步更新。
- **tolerate delayed Start ACK + reliable Stop boundary**（同步 master 0.6.4）：容忍 Start ACK 延迟到达，Stop 边界可靠化，避免快速启停后命令响应乱码。
- **设备网络操作防本机卡死**（同步 master 0.12.1 LSP 环境加固）：在 LSP（Layered Service Provider）环境下设备网络操作不再卡死本机。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:18181` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket + `recover` 防 shutdown panic |

## Compatibility

- 配置文件格式：与 0.5.0-win7.1 兼容。
- CSV 文件格式：与 0.5.0-win7.1 一致（18 列 `Timestamp,Unit,CH01..CH16`）。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 0.5.0-win7.1 安装包可覆盖升级。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `DAQ-T-1603-Win7-Setup-0.5.1-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接 DAQ-T-1603，确认热电偶类型配置、采集、CSV 录制正常；快速启停采集后立即下发配置参数验证命令响应不再乱码；切换中英文界面验证 i18n 偏好持久化。
- 安装目录默认 `%LOCALAPPDATA%\Programs\daq-t1603-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- `daq-t1603` 仍使用单模块布局（`apps/desktop-wails/{core,ports,usecase,adapters}`），与 split-layout 项目（daq-p1604）目录结构不同。
- `frontend/bindings/` 目录保留 master 上的 Wails v3 .ts binding 文件，但 `frontend/src/` 已无引用（lts/win7 用 fetch + WebSocket 替代）。这些文件作为历史遗留保留，不影响构建。

## Rollback

- 可回退到 0.5.0-win7.1（功能差异：缺少 master 0.6.0~0.6.4 同步的业务修复，包括 watchdog fallback、i18n、delayed Start ACK 容忍等）。配置文件格式兼容；CSV 列数一致。
- 卸载 0.5.1-win7.1 后安装 0.5.0-win7.1 即可，两者注册表项独立。
