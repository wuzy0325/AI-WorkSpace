# DAQ-T-1603 v0.6.9

Release date: 2026-08-05
Package: daq-t1603-0.6.9-amd64-installer.exe

## Summary

修复连接成功后界面显示的采样频率等参数始终是本地 profile 配置值、而非设备端实际值的问题。连接阶段配置同步现在会从设备读回实际 SPS/AVG/TNUM 并覆盖本地配置，界面显示的频率与机器实际一致。

## User-visible Changes

- 连接设备成功后，配置面板/监测界面显示的采样频率、平均次数、触发次数更新为设备端实际存储值（此前显示的是本地保存的 profile 值，可能与设备不一致）。

## Fixes

- **连接后频率未更新为设备实际值**：连接阶段 `readAllConfig` 出于 ADR-009 Windows deadline 失效顾虑不查询 `@fd SPS/AVG/TNUM`（响应无分隔符且长度可变），导致 `SamplingRate` 一直保留本地 profile 值。修复：socket deadline 生效机器上按 30ms 静默窗口读回设备实际 SPS/AVG/TNUM 并覆盖本地配置；deadline 失效机器保留旧行为（不查询、保留已保存值），避免静默窗口永不触发导致连接被 watchdog 毒化。

## Compatibility

- 配置文件格式兼容（`samplingRate` 语义不变，仍是应用侧配置；连接成功后会被设备实际值刷新）。
- CSV 数据格式不变。
- 设备协议命令链有变化：连接同步阶段在 deadline 生效机器上新增 `@fd SPS` / `@fd AVG` / `@fd TNUM` 三条查询命令（读操作，不影响设备状态）。

## Install / Upgrade

- 可覆盖安装 0.6.7 / 0.6.8，无需先卸载或清理用户配置（0.6.5 含槽位泄漏 bug 请勿使用）。
- 安装前先关闭正在运行的旧版本。
- 运行 `daq-t1603-0.6.9-amd64-installer.exe`，安装后启动应用确认主窗口正常出现。
