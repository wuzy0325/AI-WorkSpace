# WISPA v0.7.6

Release date: 2026-08-27
Package: wispa-0.7.6-amd64-installer.exe

## Summary

修复品牌命名一致性问题：应用顶栏标题统一为 WISPA、添加/扫描入口文案统一为"压力扫描阀"、内嵌 exe 版本资源 ProductName 替换为真实产品名；同时修复固定尺寸窗口启动时可能超出主屏工作区的问题。

## User-visible Changes

- 顶栏品牌标题由旧名称统一为 WISPA。
- 侧栏"添加设备"与"扫描设备"入口文案统一为"压力扫描阀"。
- 固定尺寸窗口启动时按主屏工作区钳制，避免窗口超出可见区域。

## Fixes

- 修复内嵌 exe 的 Windows 版本资源 ProductName 仍为旧项目名的问题，替换为真实产品名 WISPA。
- 修复固定尺寸窗口在屏幕分辨率/缩放较小环境下可能超出工作区的问题。

## Compatibility

- 配置文件格式：兼容，无变化。
- CSV 数据文件格式：兼容，无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 可覆盖安装 0.7.5 / 0.7.4 / 0.7.3，无需先卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本。
- 运行 `wispa-0.7.6-amd64-installer.exe`，安装后启动应用确认主窗口正常出现。

## Verification

- `npm run typecheck` (vue-tsc): passed.
- `npm run test` (vitest): passed.
- `npm run build`: passed.
- `$env:GOWORK="off"; go test ./... -count=1 -timeout 120s`: passed.
- `task release`: passed.

## Known Issues

- 现场故障电脑（SetReadDeadline 失效）的 discovery 与 Stop 路径 watchdog 兜底需实测验证（继承自 0.7.3）。
- 内嵌 exe 的 ProductVersion 资源为空字符串是 wails3 v3.0.0-alpha2.106 已知限制，NSIS installer 壳版本显示正常（0.7.6）。

## Rollback

- 可直接回退到 0.7.5，配置与 CSV 数据无需迁移；回退后顶栏/入口文案回到旧命名，窗口钳制行为不生效。
