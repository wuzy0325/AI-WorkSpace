# DAQ-P-1604 v0.2.4

Release date: 2026-07-03
Package: daq-p1604-0.2.4-amd64-installer.exe

## Summary

增强物理拔网线场景下的断连检测能力：在原有 TCP keepalive 基础上新增应用层连续超时计数器，5 秒内无任何数据帧即判定连接断开。同时将 keepalive 探测间隔从 10s 缩短到 3s，整体断连检测延迟从 ~110s 降低到 5s（采集期）/ ~33s（非采集期）。

## User-visible Changes

- 设备断网检测更快：采集期间 5 秒内无数据即标记为断连（此前依赖 TCP keepalive，需 ~110 秒）。
- 通道选择器文本不再被截断，CH17/CH18 大气通道默认不勾选到实时图表。

## Fixes

- 修复通道选择器组件文本溢出截断的问题（v0.2.3 遗漏未发布）。
- 修复 CH17/CH18 大气通道默认被勾选进实时图表的问题，新建设备时不再预选这两个大气通道。

## Internal

- `p1604_adapter.go` 新增 `p1604ConsecutiveTimeoutThreshold` 常量（25 次 × 200ms = 5s），`readLoop` 在连续超时达到阈值时调用 `handleConnectionLost` 主动判定断连。
- `p1604KeepAlivePeriod` 从 `10 * time.Second` 调整为 `3 * time.Second`，Windows ~33s / Linux ~12s 兜底。
- 同步更新 `enableTCPKeepalive` 设计注释、`Connect` keepalive 启用块注释、`p1604ConsecutiveTimeoutThreshold` 双保险说明，修正与新版 keepalive 数值矛盾的过期描述。
- 同步 6 个版本号文件到 0.2.4：`VERSION`、`apps/desktop-wails/wails.json`、`apps/desktop-wails/frontend/package.json`、`apps/desktop-wails/frontend/package-lock.json`、`apps/desktop-wails/build/config.yml`、`apps/desktop-wails/build/windows/installer/project.nsi`。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：兼容，CSV 格式无变化。
- 设备协议行为：无变化，仅 readLoop 内部断连判定逻辑增强。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `daq-p1604-0.2.4-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
  4. （可选）实机验证：采集期间拔网线，5 秒内设备状态应变为「错误」并显示"连接断开: read timeout for 25 consecutive attempts"。

## Known Issues

- DAQ-P-1604 设备固件时间戳 bug 仍存在（fractional 字段以 ~4348Hz 递增），CSV 时间戳已统一截断到秒级规避。根本修复需联系硬件厂商。
- 非采集期间（仅连接无采集）无周期性 I/O 触发 keepalive 失败上报，断连检测仍依赖下一次命令调用。本次未在范围内，后续可考虑加 ping goroutine。
