# DAQ-P-1604 v0.2.2

Release date: 2026-07-03
Package: daq-p1604-0.2.2-amd64-installer.exe

## Summary

修复 CSV 录制时间戳错误：1000Hz 采集下 1 毫秒内出现多帧时间戳，根因是设备硬件时间戳固件 bug 与系统毫秒精度不足，统一截断到秒级。

## Fixed

- CSV Timestamp 列从带毫秒（`'YYYY-MM-DD HH:MM:SS.mmm`）改为秒级（`'YYYY-MM-DD HH:MM:SS`）。
  - 实测发现设备硬件时间戳 fractional 字段以 ~4348Hz 速率递增（应为 1000Hz），每累积约 232ms 跳跃 768ms 校正，导致时间戳在 1 毫秒内出现多帧。
  - 系统毫秒时间戳在 1000Hz 下精度不足（Windows ~1ms）。
  - 统一秒级避免展示错误的时间细分。
- 修复 `CSVRecorder.Stop()` 缺少 `return nil` 的预存编译错误。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：CSV Timestamp 列精度从毫秒降为秒级。依赖毫秒精度的下游分析脚本需调整。1000Hz 采集下，1 秒内所有帧共享同一时间戳。

## Known Issues

- 设备硬件时间戳固件 bug 未修复。已确认非应用层解析错误：
  - 字节序：BigEndian（LittleEndian 解析得到 1987 年，明显错误）。
  - 解析公式：标准 NTP fractional 转换 `fractional / 2^32 × 1e9`，验证正确。
  - 1000 帧 wall clock 实测：设备时间戳跨度 999.755ms，但 wall clock 跨度 801ms，比率 1.25×，且时间戳在每 232ms 处跳跃 768ms。
  - 已整理报告待反馈给硬件工程师。
