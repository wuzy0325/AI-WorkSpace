# DAQ-P-1604 v0.2.1

Release date: 2026-07-02
Package: daq-p1604-0.2.1-amd64-installer.exe

## Summary

扫描批量添加设备能力上线，硬件通信日志补齐，提升首次装机效率与调试可观测性。

## Added

- 新增扫描弹窗多选 + 内联改名 + 批量添加设备，支持首次装机一次勾选多台设备一键落库。
- 新增硬件通信 hardware-send/hardware-recv 分类日志，前端通信分组可见完整命令交互流程。

## Changed

- 扫描弹窗放大至 44rem x 80vh，已添加设备置灰不可重加，未添加设备默认预勾选（尊重用户主动取消）。
- 添加后立即触发新设备并发连接，不再需要重启应用。
