# DAQ-P-1604 v0.6.0

Release date: 2026-07-27
Package: daq-p1604-0.6.0-amd64-installer.exe

## Summary

本版本新增 DAQ-P-1604 设备校零功能。操作员可从顶栏对当前选中的已连接设备执行全压力通道校零，采集过程中无需停止数据流。

## User-visible Changes

- 顶栏右侧配置图标替换为校零按钮。
- 当前设备处于“已连接”或“采集中”状态时可以执行校零。
- 校零期间按钮自动锁定，未连接、采集启停切换或校零进行中时禁止重复操作。
- 设备详情区继续保留配置按钮，原有设备配置入口不受影响。

## Compatibility

- 配置文件格式：兼容，无需迁移现有设备 profile。
- 数据文件格式：兼容，CSV 格式无变化。
- 设备协议行为：新增发送设备原生 `h` 全通道零点校准命令；现有连接和采集命令不变。

## Install / Upgrade

- 无需先卸载旧版本，兼容覆盖安装。
- 无需清理用户数据目录、WebView2 缓存或注册表残留。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `daq-p1604-0.6.0-amd64-installer.exe`。
  3. 启动新版本，连接设备并确认顶栏校零按钮可用。
  4. 在压力通道处于零压条件下执行校零，并观察后续采集值。
