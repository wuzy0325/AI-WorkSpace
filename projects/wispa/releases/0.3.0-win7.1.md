# DAQ-P-1604 v0.3.0-win7.1 (Windows 7 LTS)

Release date: 2026-07-24

## Summary

Windows 7 LTS 首个可交付版本。基于 Electron 22.3.27（Chromium 108，最后兼容 Win7 的 Electron 主版本）承载 Vue 3 前端，Go 后端改为 `net/http` server 监听 `127.0.0.1:18182`，前端通过 HTTP fetch + WebSocket 与后端通信。同步 cherry-pick master 上 8 个近期提交（CSV 每设备一文件、idle keepalive、连接重置硬错误处理等）。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:18182` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket |

## User-visible Changes

- 与 master 0.3.0 功能对齐：CSV 录制改为每设备一个文件（文件名含 deviceSlug）。
- Win7 专属：连接设备后硬件单位与 profile 不一致时以硬件为准同步更新，避免数值与单位不匹配。
- Win7 专属：`ApplyConfig` 写 v01101 单位系数时若设备 FIN/RST，触发 `handleConnectionLost` 清理 driver，避免后续 StartAcquisition 爆 WSAECONNABORTED 假象。
- Win7 专属：非采集期间 idleReadLoop + TCP keepalive 双保险检测拔网线（CONN-008 用例，30~40 秒内状态自动变 Error）。

## Compatibility

- 配置文件格式：与 master 0.3.0 兼容。
- CSV 文件名格式：与 master 0.3.0 一致（`<prefix>-<deviceSlug>-YYYYMMDD-HHMMSS-NNN.csv`）。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 master 安装包不可共存：两者注册表项、安装目录独立，但同名快捷方式可能冲突，建议二选一。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `DAQ-P-1604-Win7-Setup-0.3.0-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接 DAQ-P-1604，确认单位同步、采集、CSV 录制正常。
- 安装目录默认 `%LOCALAPPDATA%\Programs\daq-p1604-win7\`。

## Known Issues

- 360 安全卫士主动防御（ZhuDongFangYu）可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录，或改用 `--config.directories.output=dist2` 绕过。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master（Wails v3/Edge）可能有细微差异，已用 rgba fallback 规避。
- DAQ-P-1604 设备固件时间戳 bug 仍存在（fractional 字段以 ~4348Hz 递增），CSV 时间戳已统一截断到秒级规避。

## Rollback

- 可回退到 master 0.3.0（Wails 版）。配置文件格式兼容；CSV 文件名格式一致。
- 卸载 Win7 版后安装 master 版即可，两者注册表项独立。
