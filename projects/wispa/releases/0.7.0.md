# DAQ-P-1604 v0.7.0

Release date: 2026-07-27
Package: daq-p1604-0.7.0-amd64-installer.exe

## Summary

本版本集中加固设备连接、握手、协议帧恢复和并发操作安全，并支持多网卡工位绑定本地 IP。

## User-visible Changes

- 添加设备时可填写可选的本地 IP，用于指定通信网卡。
- 留空时保持系统自动路由，不影响现有配置。

## Fixes

- 跳过并消费 `00 00` 空响应，防止帧错位。
- 握手超时后强制关闭 socket，避免连接永久等待。
- 串行化断开、配置、采集启停和校零，避免并发 panic 或响应串线。

## Compatibility

- `localAddress` 为可选字段，旧 profile 无需迁移。
- CSV 数据格式不变。

## Install / Upgrade

- 可覆盖安装 0.6.0，无需先卸载或清理用户配置。
- 安装前先关闭旧版本。
