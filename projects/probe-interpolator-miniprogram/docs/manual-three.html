三孔探针插值 · 使用说明

3 孔压 + 大气参数 · 1~10 个 .prb 跨马赫数档 · 一维角度求解

多 PRB 一维角度 离线运行

1. 概述

三孔探针插值用于风洞试验中一维角度（侧滑角 α）的求解。基于校准曲线对孔压差进行迭代插值，输出偏角、马赫数、总压与静压。

  • 校准数据：每个 .prb 文件首行内嵌一个校准马赫数；可一次加载 1~10 个文件跨马赫数档迭代插值。多文件约束：各档 Nalpha 与 Alpha 网格必须完全一致，每档 Kb 严格单调递增，违规文件会被拒绝加载。
  • 输入：3 个孔压 P1/P2/P3（Pa，表压）+ 大气压 Patm + 大气温度 Tatm（℃）。
  • 输出：偏角 α（deg）、马赫数 Ma、总压 P0、静压 Ps。
  • 数值校验：JS 端口与 Go 原版逐位一致，容差 1e-9（50 用例全 PASS）。
小程序版本与桌面端 probe-interpolator 共享同一套 Go 算法核心，结果数值完全一致。

打开小程序后，首页（探针选择页）会列出三种探针瓦片。点击「三孔探针」进入工作区。

图 2-1 首页探针选择瓦片

3. 校准文件加载

三孔探针需加载 .prb 校准文件后才能计算。校准文件由桌面端校准软件导出，首行内嵌校准马赫数。

3.1 操作步骤

  1. 把 .prb 发到微信聊天或「文件传输助手」（PC 端微信发给手机微信即可）。
  2. 在小程序「校准文件」卡片点「选择 .prb」按钮。
  3. 从微信会话文件列表中选择对应 .prb，加载完成后会显示文件名。
  4. 支持加载多份不同马赫档的 .prb，计算时按马赫自动插值。
提示：PC 微信客户端兼容性较差，wx.chooseMessageFile 在 PC 上可能无法列出文件。建议用手机微信扫码预览小程序，再从手机会话中选文件。

6. CSV 批量导入/导出

切到「CSV 批量」Tab，可一次性灌入多组孔压，结果回写为 CSV。

图 6-1 CSV 批量结果（截图以五孔为例，三孔结构相同）

6.1 导入（计算）

  • 点「导入 CSV 并计算」，从微信会话选 .csv。
  • 必需列：P1, P2, P3（单位 Pa）。
  • 可选列：Patm / TAtm（缺省回退到页面当前大气输入）。
  • 表头容错：支持 P1 (Pa)、大气压、气温(℃)、Patm、TAtm 等写法（忽略空格/括号/单位/中文）。
  • 解析按 RFC4180 风格：支持引号、"" 转义、引号内逗号/换行、UTF-8 BOM 剥离。

6.2 输出列

表头固定为：P1, P2, P3, Patm, TAtm, alpha, machNumber, P0, Ps, isValid, warning

  • isValid = 1/0：1 表示有效；0 表示超范围（仍输出参考值）。
  • 解析或计算失败的行：isValid = ERROR，warning 列写明原因（缺列、非法数值、内部异常）。

6.3 导出（分享）

点「导出结果」按钮，把全部结果行写成 probe_batch_three_<时间戳>.csv。

  • 优先调起 wx.shareFileMessage 分享到会话（可直接发回聊天或文件传输助手）。
  • PC 端不可用时回退到 wx.saveFileToDisk 存盘。
  • 用户取消分享面板时显示中性提示「已取消分享，未导出」。
CSV 解析与批量逻辑在 utils/csv-batch.js 中与 wx 解耦，可在 Node 端用 verify/verify_csv.js 直接校验。

7. 单位切换

工作区顶部「显示单位」卡片可分别切换四类单位，只作用于结果展示与 CSV 导出结果列，输入固定国际单位。

类型可切换单位影响范围
压力Pa / kPa / MPaP0、Ps、动压 q

  • 单位偏好存入 app.js 的 globalData.units，跨三/五/七孔页面共享。

8. 复制与分享卡片

8.1 复制结果

结果卡片右上角「复制」按钮 → 制表符分隔文本，格式如下：

字段1\t字段2\t字段3\t...
α (deg)\tMa\tP0 (kPa)\tPs (kPa)
0.000\t0.8012\t49.987\t-2.209

8.2 分享卡片

结果卡片右上角「分享卡片」按钮 → 把当前结果（含输入摘要、按显示单位的结果、有效性、警告、生成时间）绘制成一张图片。

  • 卡片数据模型由 utils/share-card.js 的 buildCardModel 构建（纯 JS，可 Node 校验）。
  • 真正的 Canvas 绘制在 utils/share-canvas.js，仅在真机/开发者工具运行时执行。
  • 导出与分享走三级回退：wx.shareFileMessage → wx.saveImageToPhotosAlbum → wx.previewImage。

9. 结果状态语义

结果卡片顶部的状态胶囊有三档，对齐桌面端 0.2.1「参考」语义：

状态颜色含义
参考绿色已计算且在校准范围内
参考: 原因琥珀色超出校准范围，结果仅供参考（CSV 同步输出「参考: 原因」）
计算失败: 原因红色输入非法或无法收敛，结果值显示为「-」
三孔插值结果状态统一显示「参考」：已计算行一律标注「参考」并展示数值；超范围行琥珀色 + 悬停 Warning。

10. 常见问题

Q1：为什么 PC 微信打不开文件选择器？

PC 微信的 wx.chooseMessageFile 兼容性较差，建议用手机微信扫码预览小程序，再从手机会话中选文件。

Q2：CSV 导入报「缺列 ERROR」怎么办？

检查 CSV 表头是否包含 P1, P2, P3（不区分大小写，忽略空格/括号/单位）。中文表头需为「大气压」「气温」或类似容错写法。

Q3：导出 CSV 时点了「取消分享」没生成文件？

取消分享面板会显示「已取消分享，未导出」，结果数据仍保留在小程序内存中，可重新点「导出结果」再次调起分享面板。

Q4：结果状态显示「参考: 超范围」是什么意思？

输入的孔压组合对应的 α 角度超出了 .prb 校准网格覆盖范围，结果仅供参考（仍输出数值，但置信度低）。CSV 同步输出「参考: 原因」。

Q5：三孔结果为什么没有速度 V？

三孔探针只求解一维角度（α），不输出速度分量、CAS、SAT 等。如需二维角度与速度，请使用五孔或七孔探针。
