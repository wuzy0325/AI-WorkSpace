CONN-001
P1604 设备连接（真实模式）
前置条件
01一台 DAQ-P-1604 设备已上电，并通过网线接入与电脑相同的局域网
02已知设备 IP 地址（如 192.168.3.101），默认端口 9000
03应用处于"真实设备"运行模式
测试步骤
01启动应用
02点击顶栏右侧「+」按钮
03在弹窗中填写设备名称（如"1号压"）、IP 地址、端口（默认 9000），点击「确认」
04设备出现在左侧侧边栏，点击选中该设备
05点击详情面板头部的「连接」按钮
06等待 1~5 秒
期待结果
01点击「连接」后按钮显示加载动画，状态变为「连接中」
02连接成功后，侧边栏状态标签变为「已连接」（绿色）
03详情面板头部显示设备名称和"已连接"徽章
04底部状态栏"在线"计数 +1
05日志面板"通信"分组出现设备连接相关的通信记录
06若硬件当前压力单位与配置不一致，配置面板和配置文件中的压力单位会自动更新为硬件实际单位
