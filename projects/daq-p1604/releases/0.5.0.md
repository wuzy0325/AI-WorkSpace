# DAQ-P-1604 v0.5.0

Release date: 2026-07-25
Package: daq-p1604-0.5.0-amd64-installer.exe

## Summary

本版本与 daq-t1603 v0.5.0 版本号同步发布。本版本 daq-p1604 无独立功能改动：最近共享 SDK 改动（drainConnection 连续静默窗口语义）仅影响 T1603 设备，P1604 使用 w1601 长度前缀协议且 ReadLoop 路径不同，不受影响。本次发布主要同步版本号、回归验证当前主干可正常构建打包。

## User-visible Changes

- 无。

## Fixes

- 无。

## Compatibility

- 配置文件格式：兼容。JSON profile 字段无破坏性变更。
- 数据文件格式：兼容。CSV 仍为 0.4.0 引入的禁用通道空列结构。
- 设备协议行为：无变化，仍使用自定义 TCP 二进制协议（w1601 长度前缀）。

## Install / Upgrade

- 覆盖安装兼容：直接运行 `daq-p1604-0.5.0-amd64-installer.exe` 覆盖旧版本即可，无需先卸载。
- 安装前请先关闭正在运行的旧版本（托盘退出或任务管理器结束 `DAQ-P-1604.exe`）。
- 推荐步骤：
  1. 关闭旧版本。
  2. 运行 `daq-p1604-0.5.0-amd64-installer.exe`。
  3. 启动新版本，确认 GUI 正常出现、设备可连接与采集。
