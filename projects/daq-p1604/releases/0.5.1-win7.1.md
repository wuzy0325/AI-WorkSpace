## Summary

Win7 LTS 维护版本，自 0.5.0-win7.1 以来同步 master 0.6.0~0.7.3 全部业务修复：ADR-009 网络看门狗 + adapter IO 加固、UDP discovery 加固、握手失败提示重启设备、StartAcquisition 识别 WSAECONNABORTED 清理死连接、设备名编辑支持（含唯一性校验）、校零死连接判定口径与状态迁移统一、设备名校验仅在校验改动时触发、采样频率下限从 1000 Hz 降到 500 Hz、设备生命周期与校准加固、16-coefficient 响应识别、应用内退出按钮替换为窗口 X 确认、中英文切换。所有变更通过 master→lts/win7 cherry-pick 同步，业务层零代码差异。

## Changes vs 0.5.0-win7.1

### Added

- **中英文界面切换**（同步 master 0.6.0）：独立应用新增中英文界面切换，并保持语言偏好。
- **设备名编辑支持（含唯一性校验）**（同步 master 0.7.x）：用户可重命名设备，前端实时校验唯一性并阻塞重名保存。
- **设备生命周期与校准加固**（同步 master 0.6.0）：连接握手、状态迁移、校零触发的边界条件统一加固。

### Changed

- **应用内退出按钮替换为窗口 X 确认**（同步 master）：daq-p1604 / daq-t1603 移除应用内退出按钮，统一走窗口关闭按钮 + 确认对话框，避免误触。
- **采样频率下限从 1000 Hz 降到 500 Hz**（同步 master 0.6.x）：放宽下限以适配低速场景。

### Fixed

- **16-coefficient 响应识别**（同步 master 0.7.x）：设备 `h` 命令返回 16 个系数时正确解析，不再误判协议错误。
- **idleReadLoop 与 ApplyConfig 竞争**（同步 master）：操作 conn 前显式 stopIdleLoop + join，避免 v01101 响应被污染为乱码。
- **拔网线重连时 u01101/v01101 阶段对端 FIN 被当作软错误吞掉导致半死连接**（同步 master）：新增 `sharedproto.IsConnResetByPeer` 判定对端 FIN/RST 确认，与 `IsConnectionFault`（日志降级用）语义分离；ApplyConfig v01101 失败且命中时复用 handleConnectionLost 清理 driver + conn + status。
- **UDP discovery 加固**（同步 master）：UDP discovery 增加 timeout fallback + 并发扫描保护。
- **network timeout cancellation**（同步 master）：网络超时取消机制加固。
- **设备连接失败错误日志**（同步 master 0.6.0）：连接失败写入明确错误日志。
- **握手失败提示重启设备 + StartAcquisition 识别 WSAECONNABORTED 清理死连接**（同步 master 0.7.x）：握手失败时明确提示用户重启设备；StartAcquisition 时识别 WSAECONNABORTED 并清理死连接，避免后续命令误判。
- **watchdog 与 residual frame skipping**（同步 master 0.7.2）：watchdog + 残留帧跳过。
- **ADR-009 discovery watchdog + adapter IO hardening + stop transaction remediation**（同步 master 0.7.3）：discovery watchdog + adapter IO 加固 + stop 事务补救。
- **rollback/校零死连接判定口径与状态迁移统一**（同步 master 0.12.x）：rollback 与校零的死连接判定口径与状态迁移统一。
- **设备名校验仅在校验改动时触发并回写规范化名字**（同步 master 0.12.x）：设备名校验逻辑收窄，避免无意义重复校验。
- **设备网络操作防本机卡死**（同步 master 0.12.1 LSP 环境加固）：在 LSP 环境下设备网络操作不再卡死本机。

## Compatibility

- 配置文件格式：与 0.5.0-win7.1 兼容。
- CSV 文件名格式：与 0.5.0-win7.1 一致（`<prefix>-<deviceSlug>-YYYYMMDD-HHMMSS-NNN.csv`）。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 0.5.0-win7.1 安装包可覆盖升级。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `DAQ-P-1604-Win7-Setup-0.5.1-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接 DAQ-P-1604，确认单位同步、采集、CSV 录制正常；测试设备重命名、校零、握手失败提示。
- 安装目录默认 `%LOCALAPPDATA%\Programs\daq-p1604-win7\`。

## Known Issues

- 360 安全卫士主动防御（ZhuDongFangYu）可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录，或改用 `--config.directories.output=dist2` 绕过。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master（Wails v3/Edge）可能有细微差异，已用 rgba fallback 规避。
- DAQ-P-1604 设备固件时间戳 bug 仍存在（fractional 字段以 ~4348Hz 递增），CSV 时间戳已统一截断到秒级规避。
