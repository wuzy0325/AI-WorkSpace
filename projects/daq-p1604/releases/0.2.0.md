# DAQ-P-1604 v0.2.0

Release date: 2026-07-01
Package: daq-p1604-0.2.0-amd64-installer.exe

## Summary

录制系统全面升级，支持 1000Hz 采集、文件滚动和自动停止条件。CSV 录制器重构为异步 writer 架构。

## Added

- 新增 FileRotation 文件滚动配置（按大小/时长/记录数自动切文件）。
- 新增 StopConditions 录制自动停止条件（时长/总大小/总记录数）。
- 新增 RecordingStopping 状态和 DroppedCount 丢帧计数，前端可显示数据完整性指标。
- 新增 Taskfile.yml 构建任务定义。

## Changed

- RecordingPort.Start 接口迁移到 RecordingConfig 结构体，配置更灵活。
- RecordingSession 新增 Format/DroppedCount/FileCount/CurrentFile/LastError 字段。
- CSV 录制器重构为异步 writer 架构，支持多设备并发和文件滚动。
- CSV Timestamp 列改为带毫秒的单列格式（`'YYYY-MM-DD HH:MM:SS.mmm`），前缀单引号强制 Excel 文本模式，秒和毫秒均完整可见。
- 硬件适配器和前端绑定层适配新录制模型。

## Removed

- **移除 v0.1.x 实验性 Binary 录制格式**：无读端、孤儿格式，维护成本高。CSV 已能满足 1000Hz 采集需求。
- **Breaking**：v0.1.x 录制的 Binary 文件无法在本版本读取（无读端实现）。

## Compatibility

- 配置文件格式：兼容，新增字段为可选。
- 数据文件格式：CSV 格式有调整（Timestamp 列合并秒+毫秒），旧 CSV 仍可读。
- **Breaking**：v0.1.x 录制的 Binary 文件无法在本版本读取。

## Install / Upgrade

- 如果安装过 v0.1.1，可直接覆盖安装。
- 安装步骤：
  1. 关闭正在运行的 DAQ-P-1604。
  2. 运行 daq-p1604-0.2.0-amd64-installer.exe。
  3. 启动后确认 GUI 正常出现。
