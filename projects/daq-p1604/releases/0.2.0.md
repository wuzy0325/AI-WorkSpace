# DAQ-P-1604 v0.2.0

Release date: 2026-07-01
Package: daq-p1604-0.2.0-amd64-installer.exe

## Summary

新增 Binary 高吞吐录制格式、文件滚动和自动停止条件，录制系统全面升级。

## Added

- 新增 Binary 录制格式（二进制定长头 + LE 编码），高吞吐场景空间节省约 50%。
- 新增 FileRotation 文件滚动配置（按大小/时长/记录数自动切文件）。
- 新增 StopConditions 录制自动停止条件（时长/总大小/总记录数）。
- 新增 RecordingStopping 状态和 DroppedCount 丢帧计数。
- 新增 RecorderFactory 工厂模式，支持动态切换 CSV/Binary。

## Changed

- RecordingPort.Start 接口迁移到 RecordingConfig 结构体，配置更灵活。
- CSV 录制器重构，支持多设备并发和文件滚动。
- 硬件适配器和前端绑定层适配新录制模型。

## Compatibility

- 配置文件格式：兼容，新增字段为可选。
- 数据文件格式：兼容，新增 Binary 格式为可选。

## Install / Upgrade

- 如果安装过 v0.1.1，可直接覆盖安装。
- 安装步骤：
  1. 关闭正在运行的 DAQ-P-1604。
  2. 运行 daq-p1604-0.2.0-amd64-installer.exe。
  3. 启动后确认 GUI 正常出现。
