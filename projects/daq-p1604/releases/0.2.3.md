# DAQ-P-1604 v0.2.3

Release date: 2026-07-03
Package: daq-p1604-0.2.3-amd64-installer.exe

## Summary

修复停止采集后配置单位报错的问题。根因是停止采集后 TCP 缓冲区残留采集数据帧，后续 v01101 命令的 ReadFrame 把残留当作响应读出，导致 "unexpected v01101 response" 错误。

## User-visible Changes

- 无新增功能，仅缺陷修复。

## Fixes

- 修复停止采集后立即配置单位时返回 "unexpected v01101 response" 错误的问题。在 ApplyConfig 发送 v01101 前增加 frameReader.Reset + DrainConnection 排空 TCP 缓冲区残留数据帧。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：兼容，CSV 格式无变化。
- 设备协议行为：无变化，仅在配置命令前增加缓冲区排空。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `daq-p1604-0.2.3-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
