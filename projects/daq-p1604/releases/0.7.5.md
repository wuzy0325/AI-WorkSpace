# DAQ-P-1604 v0.7.5

Release date: 2026-08-13
Package: daq-p1604-0.7.5-amd64-installer.exe

## Summary

统一 18 通道默认波形配色，旧版默认色自动迁移到新配色，波形线与通道卡片颜色保持一致；"添加设备"与"校零"入口从顶栏移到更贴近操作上下文的位置（侧栏头部 / 监控页设备操作栏）；移除设备列表侧栏的"搜索设备"过滤框。

## User-visible Changes

- "添加设备"入口从顶栏移到侧栏头部（+ 图标），与扫描按钮并列。
- "校零"按钮从顶栏移到监控页设备操作栏（连接/断开按钮旁），仅设备处于已连接/采集中时可用，未连接时显示"请先连接设备再校零"提示。
- 18 通道默认波形配色统一：剔除易与"告警/异常"混淆的琥珀/橙黄色，改用高区分度冷色系（相邻通道色相不同），CH17 大气压力 / CH18 大气温度用中性灰；通道卡片圆点与波形线颜色一致。
- 已有设备若通道颜色为旧版默认色，启动时自动迁移到新配色（用户自定义颜色不受影响）。
- 移除设备列表侧栏的"搜索设备"过滤框，设备列表直接展示全部已配置设备。
- 安装包（NSIS）在检测到本机已安装 WebView2 Runtime 时跳过下载/静默安装步骤，离线电脑不再干等网络超时；未安装时仍联网下载并静默安装。

## Fixes

- 修复旧版默认色迁移的类型错误：`LEGACY_CHANNEL_COLORS` 改为多代色板数组后，迁移逻辑按各代色板逐一比对对应索引默认色，消除 vue-tsc "types 'string' and 'string[]' have no overlap" 构建阻断错误。

## Compatibility

- 配置文件格式兼容：`channels[].color` 仍为可选字段，空串由渲染器按通道索引回退默认色板；旧版默认色在加载时被识别并置空迁移，用户自定义颜色原样保留。
- CSV 数据格式不变。
- 设备协议命令链不变。

## Install / Upgrade

- 可覆盖安装 0.7.4 / 0.7.3 / 0.7.2 / 0.7.1 / 0.7.0，无需先卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本。
- 运行 `daq-p1604-0.7.5-amd64-installer.exe`，安装后启动应用确认主窗口正常出现。
