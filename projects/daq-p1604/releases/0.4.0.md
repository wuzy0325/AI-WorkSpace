# DAQ-P-1604 v0.4.0

Release date: 2026-07-24
Package: daq-p1604-0.4.0-amd64-installer.exe

## Summary

本版本聚焦连接健壮性、CSV 录制一致性与现场可排查性：新增空闲连接 keepalive 失效检测与对端断连（FIN/RST）的硬清理，修复配置写单位时的连接竞争与单位显示不一致；CSV 录制对禁用通道输出空列保持列对齐；日志面板支持搜索与轮转；设备状态改为异步推送提升 UI 响应。

## User-visible Changes

- 空闲连接保活失效检测：连接但空闲时也能快速感知对端掉线。
- 禁用通道在 CSV 中输出空列（列顺序/表头不变）。
- 日志面板支持关键字搜索，后端日志按大小轮转。
- 设备状态异步推送，UI 状态更新更及时。
- 通道卡片数值不再闪烁，颜色始终跟随通道色。

## Fixes

- 修复停止采集后配置单位（v01101）响应被残留采集帧污染为乱码。
- 修复拔网线重连后半死连接导致后续采集启动触发 WSAECONNABORTED。
- 修复硬件单位与 profile 不一致时通道卡片显示陈旧单位。

## Compatibility

- 配置文件格式：兼容。JSON profile 字段无破坏性变更，`DeviceNames` 为录制内部字段，对既有 profile 透明。
- 数据文件格式：注意变更。CSV 现在对禁用通道输出空列（此前禁用通道整列省略）；按固定列位置解析的旧脚本需确认仍能对齐，建议按表头列名解析。
- 设备协议行为：无变化，仍使用自定义 TCP 二进制协议。

## Install / Upgrade

- 覆盖安装兼容：直接运行 `daq-p1604-0.4.0-amd64-installer.exe` 覆盖旧版本即可，无需先卸载。
- 安装前请先关闭正在运行的旧版本（托盘退出或任务管理器结束 `DAQ-P-1604.exe`）。
- 推荐步骤：
  1. 关闭旧版本。
  2. 运行 `daq-p1604-0.4.0-amd64-installer.exe`。
  3. 启动新版本，确认 GUI 正常出现、设备可连接与采集。
