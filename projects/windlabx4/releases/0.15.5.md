# Wind-DAQ v0.15.5

Release date: 2026-08-17
Package: wind-daq-0.15.5-amd64-installer.exe

## Summary

补齐双探针模式点位预览的阶段图例（运动中/稳定中/采集中/已完成/未测试），并使双探针开始按钮的禁用条件与单探针一致（采集设备未开始采集时禁用并提示原因）。

## User-visible Changes

- 双探针模式每个 row 的「点位预览」标题右侧显示阶段图例，颜色与单探针模式完全一致。
- 双探针开始按钮在运动器未连接 / 采集设备未连接 / 未开始采集 / 未配置时禁用，鼠标悬停显示具体原因。

## Fixes

- **双探针点位预览阶段图例缺失**：图例此前只在单探针工作区渲染，双探针点位预览画布仅有颜色变化无图例对照。
- **双探针启动门禁缺失**：采集设备未开始采集时仍可点击开始，现与单探针 `TraversalMain.startDisabledReason` 同源判定，提前禁用并提示。

## Compatibility

- 无配置、数据文件、设备协议变化；与 0.15.4 完全兼容，可直接覆盖安装。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `wind-daq-0.15.5-amd64-installer.exe` → 启动确认 GUI 正常出现。

## Verification

- `npm run typecheck`（frontend）: passed
- `npm run test`（frontend，vitest）: passed
- 生产构建 + NSIS 打包 + 冒烟启动: passed

## Rollback
