# Wind-DAQ v0.2.0

Release date: 2026-06-30
Package: wind-daq-0.2.0-amd64-installer.exe

## Summary

新增运行时遥测系统、设备协议模拟器框架、二进制存储引擎，大幅提升采集链路稳定性和可观测性。

## User-visible Changes

- 运行时遥测系统：实时采集性能监控与状态上报。
- 遥测 UI：设备详情面板增加实时数据流可视化，管理抽屉增加遥测面板。
- 全局设置弹窗增强。
- 设备卡与管理抽屉布局优化。
- 前端 Log SSE 客户端增强。

## Fixes

- DataStreamRelay 测试稳定性提升。
- 模拟器中 acceptLoop 区正常退出与异常退出。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容（新增二进制格式，CSV 格式不变）。
- 设备协议行为：无变化。

## Install / Upgrade

- 如果已安装 v0.1.1，支持覆盖安装。
- 如需全新安装：
  1. 关闭正在运行的旧版本。
  2. 如需，先通过"控制面板 → 卸载"卸载旧版本。
  3. 运行 wind-daq-0.2.0-amd64-installer.exe。
  4. 启动后确认 GUI 正常出现。
