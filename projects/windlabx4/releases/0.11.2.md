# Wind-DAQ v0.11.2

Release date: 2026-07-29
Package: `wind-daq-0.11.2-amd64-installer.exe`

## Summary

本版本是 bug 修复与稳定性加固版本，承接 0.11.1 的 ADR-009 网络可靠性整改。主要修复双探针遍历测试开始后实时值冻结、总压校准实时画面马赫数/速度不刷新、双探针遍历模式三个交互问题与实时压力精度未生效问题，并完成 ADR-009 整改剩余项（DAQ-T-1603 TCP Dial watchdog、诊断工具硬 watchdog、simulator goroutine 管理、协议层一致性整改）。

## User-visible Changes

- 双探针遍历测试开始后实时压力值与插值结果不再冻结。此前点击"开始测试"后界面冻结在上一个测点或空值，直到下一个测点保存才更新；现在 `onSnapshot` 在所有状态下持续更新 `realtimePressures`，测点完成时由 `onProgress.latestData` 提供权威插值结果覆盖。
- 总压校准概览页"系数卡片"内的马赫数/速度现在实时刷新（5Hz），与侧边栏"关键数据"卡片行为一致；此前停留在上一点采集完成时的快照值，两点之间不刷新。
- 双探针遍历模式：
  - 运动控制器紧急停止接触后状态会立即刷新（新增快速轮询），不再一直显示急停。
  - 允许配置同一控制器的不同轴（如 X 轴 + Y 轴挂同一 B140），仅 `(controllerID, axis)` 元组粒度判定冲突。
  - 修复误判不同控制器为冲突的问题（前端改用 ID 比较而非引用比较）。
  - 实时压力卡片现按用户在硬件配置步骤逐通道设置的精度小数位显示，不再硬编码 3 位。
- 遍历视图插值状态栏不再因 `interpStatus` 切换产生高度跳变。

## Fixes

- 双探针遍历：撤销 C6 修复中 `onSnapshot` 在运行态直接 return 的抑制逻辑。`latestData` 实际来自已保存测点的平均值（历史值，非实时值），抑制后导致开始测试后界面冻结；现 `onSnapshot` 在所有状态下持续更新 `realtimePressures`，`onProgress.latestData` 仅在测点完成时提供权威插值结果覆盖。
- 总压校准实时画面 Ma/V 数据源从 `latestCoefficients` 切到 `physics`（后端 `livePhysics` 5Hz 推送）。
- 双探针遍历：紧急停止状态刷新、同控制器不同轴配置、不同控制器误判冲突、实时压力精度未生效。
- DAQ-T-1603 TCP Dial 路径新增 goroutine + `time.After` 软超时兜底，防止 Windows 下 `SetReadDeadline` 失效导致 Dial 永不返回；同时修复 T1603 自死锁、`drainConnection` watchdog 触发后未清理连接状态。
- DAQ-P-1064Pre `sendCommand` 在 Write/Read 失败且 watchdog 触发时调用 `invalidateConnection()` 清空 `d.conn`，确保上层重连。
- UDP 设备发现新增 Windows 分平台实现（`discovery_socket_windows.go`），使用原生 socket + 软超时兜底；并发扫描保护避免多 goroutine 冲突。
- 网络协议层：sendCommandACK 循环跳过非 ASCII 帧（压力帧）直到读到 'A'/'Nxx' 或达 20 帧上限；StopAcquisition/Disconnect 调用 sendCommandACK 前 `frameReader.Reset()` 清空残留。
- 诊断工具（p1604-unit-diag、p1604-ts-diag、freqprobe、frameprobe）新增 5 分钟进程级硬 watchdog，超时 `conn.Close()` + `os.Exit(2)`。
- `simulator.go`：`Start(ctx)` 监听 `ctx.Done()` 自动 Close；所有 goroutine 纳入 `sync.WaitGroup`；`cmdLoopIdle` 内层循环仅设置一次 idle deadline。
- 协议层一致性：`IsWatchdogTriggered` 改用 sentinel error + `errors.Is`；`WatchdogClose` 入口防御性检查；`DialTCP` timeout 分支关闭 conn 防 FD 泄漏；`dsa3217.readLoop` 防双重 onError；`daq_t1603.Disconnect` 保留 Error 状态不掩盖 invalidate。
- 静态分析集成：`scripts/validate-structure.ps1` pre-submit 新增 `staticcheck -checks U1000`；清理 33 处预存 dead code。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：兼容，无需迁移。
- 设备协议行为：无变化，仅加固超时与 watchdog 兜底，对正常通信无影响。

## Install / Upgrade

- 兼容覆盖安装，无需先卸载旧版本。
- 推荐安装步骤：
  1. 关闭正在运行的旧版本 Wind-DAQ。
  2. 运行 `wind-daq-0.11.2-amd64-installer.exe`，选择安装语言（中文/英文）。
  3. 按向导完成安装，安装程序会自动检测并安装 WebView2 Runtime（如未安装）。
  4. 启动 Wind-DAQ，确认 GUI 正常出现，进入总压校准/双探针遍历页面验证修复效果。
