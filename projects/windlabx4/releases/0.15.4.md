# Wind-DAQ v0.15.4

Release date: 2026-08-14
Package: wind-daq-0.15.4-amd64-installer.exe

## Summary

修复 DAQ-T-1602 仪表盘通道卡片量程显示错误（此前固定显示 ±10，现按热电偶类型码显示真实量程），并移除配置面板中关于固件采集周期 ~100ms 的提示文案。

## User-visible Changes

- 无新增能力。

## Fixes

- **DAQ-T-1602 仪表盘卡片量程**：卡片底部 MIN/MAX 现按各通道热电偶类型码（J/K/T/E/R/S/B/N）显示固件量程表数值（如 T 型 `MIN: 0 / MAX: 1300`），不再固定显示 `-10 / 10`。设备总览面板的越限告警判定同步使用正确量程。
- **DAQ-T-1602 配置面板提示**：采样频率 hint 移除「设备固件采集周期固定 ~100ms」说明，文案简化为「范围 1~5 Hz，控制采集与保存频率」。

## Compatibility

- 无配置、数据文件、设备协议变化；与 0.15.3 完全兼容，可直接覆盖安装。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `wind-daq-0.15.4-amd64-installer.exe` → 启动确认 GUI 正常出现。
- 若使用 DAQ-T-1602，建议现场确认各通道卡片 MIN/MAX 与所选热电偶类型量程一致。

## Verification

- `npm run typecheck`（frontend）: passed
- `npm run build`（frontend）: passed
- `npx vitest run`（frontend）: passed（38 文件 / 366 用例，含新增 `t1602Range.test.ts`）
- 生产构建 + NSIS 打包 + 冒烟启动: passed

## Known Issues

- 已知限制同 0.15.3：T 型量程下限恰为 0℃ 时真实 0℃ 与未接入不可区分；UI 修改热电偶类型保存后不会立即下发到已连接设备。

## Rollback

- 可直接卸载后重装 0.15.3；无配置或数据格式变化。
