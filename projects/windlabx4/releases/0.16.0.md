# WindLabX4 v0.16.0

Release date: 2026-08-19
Package: windlabx4-0.16.0-amd64-installer.exe

## Summary

五孔探针校准新增自定义布点文件导入能力：操作员可导入包含 β/α 两列角度的布点文件，校准时严格按文件行序逐点执行，满足非规则网格的现场校准需求。

## User-visible Changes

- 五孔校准设置页新增「规则网格 / 文件导入」布点方式切换。
- 支持导入用户指定文件：第一列 β、第二列 α；支持 CSV / Tab / 空白分隔，可选 `beta,alpha`（含 `β,α`）表头；忽略空行。
- 导入成功后显示文件名、总点数与逐点顺序预览；校准按文件行序执行。
- 重复点保留，同一点出现几次就校准几次。
- 导入方案仅在当前软件进程内生效，关闭软件后不保留；再次启动回退到规则网格。
- 导入文件校验失败（列数错误、非数字、空文件、角度超出 ±30°）时拒绝整份文件并提示行号。

## Fixes

- 本版本无对既有已发布功能的缺陷修复。

## Compatibility

- 配置文件格式：兼容。`fiveHoleLayout` 语义不变，导入方案不写入持久化配置。
- 数据文件格式：兼容，无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `windlabx4-0.16.0-amd64-installer.exe` → 启动确认 GUI 正常出现。
- 无需清理用户数据目录或 WebView2 缓存。

## Known Issues

- 已知限制同 0.15.6：T 型量程下限恰为 0℃ 时真实 0℃ 测量与未接入不可区分；UI 修改热电偶类型保存后不会立即下发到已连接设备。
- 设备扫描对通过 USR-K7 串口服务器接入的 1604 设备可能误识别为 `DAQ-P-1604Pre`，需手动按实际类型添加。
- 导入布点方案不跨进程保存，重启软件后需重新导入。

## Rollback

- 可直接卸载后重装 0.15.6；无配置或数据格式变化。
