# WindLabX4 v0.18.0

Release date: 2026-08-27
Package: WindLabX4-0.18.0-amd64-installer.exe

## Summary

五孔探针校准新增"风洞总压范围判定"，确保采集时风洞总压处于指定范围；同时修复门控超时被误判为成功、接受过期缓存总压等可靠性问题。

## User-visible Changes

- 五孔校准设置新增「风洞总压范围判定」：使能开关、范围下限/上限（Pa）、判定超时（默认 300 秒）。
- 启用后，每个测点采集前判定 `fiveHole.pTotal` 当前值是否在范围内——范围内立即采集，否则等待直至进入范围或超时。
- 主界面左侧底部新增状态条：实时显示当前总压与配置范围，以及「范围内」（绿）/「等待进入范围」（黄）状态。
- 总压范围判定超时后校准停止，任务进入错误态（此前可能被误报为成功完成）。

## Fixes

- 修复门控超时在 `StopOnError=false` 下被当作成功完成（Manager 误标 Completed）的问题；球罐门控同类问题一并修复。
- 修复门控可能基于运动前缓存的过期总压值采集的问题（现要求读数来自本测点移动+驻留后的新采集周期）。
- 非法总压范围（NaN/Inf、`[0,0]`、`min>max`、缺失 pTotal 通道）改为在启动前校验拒绝，探针不再移动后才报错。

## Compatibility

- 配置文件格式：兼容。`tunnelTotalPressureGate` 为可选新增字段，旧配置不含该字段时按未启用处理。
- 数据文件格式：无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 兼容覆盖安装（同一安装路径），无需先卸载旧版本。
- 无需清理用户数据目录或 WebView2 缓存。
- 推荐安装步骤：
  1. 关闭正在运行的旧版本 WindLabX4。
  2. 运行 `WindLabX4-0.18.0-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
