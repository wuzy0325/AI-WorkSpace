# Wind-DAQ v0.3.3

Release date: 2026-07-03
Package: wind-daq-0.3.3-amd64-installer.exe

## Summary

修复 DAQ-P-1604 通道选择器 UI 显示问题及驱动层稳定性改进。自 v0.3.2 以来仅含 PATCH 级别修复和内部重构。

## User-visible Changes

- 修复 DAQ-P-1604 通道选择器中文本被截断的问题。
- 大气压通道从图表默认选择中排除，图表展示更聚焦测量通道。
- DAQ-P-1604 驱动增加应用层连续超时断连检测与 keepalive 调优，长时间采集更稳定。

## Fixes

- DAQ-P-1604 通道选择器文本截断修复。
- DAQ-P-1604 驱动层连续超时断连检测（v0.2.4），降低静默断连风险。

## Internal

- motion 重构：移除轴启用开关，强制所有轴始终启用，简化状态管理。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：兼容，CSV 格式无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.3.3-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
