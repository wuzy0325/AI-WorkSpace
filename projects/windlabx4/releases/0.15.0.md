# Wind-DAQ v0.15.0

Release date: 2026-08-13
Package: wind-daq-0.15.0-amd64-installer.exe

## Summary

新增 DAQ-T-1602 温度扫描阀（Modbus TCP，2 卡 × 8 通道 = 16 通道热电偶）设备支持，包含 workspace 首个纯手写 Modbus TCP 协议栈；量程表与换算公式已经真机验证（K 型通道室温 27.7℃ 吻合）。

## User-visible Changes

- 设备管理抽屉可添加 `DAQ-T-1602` 类型设备，默认地址 192.168.3.201:502。
- 连接后自动读回 16 通道热电偶类型并在配置面板展示；支持修改各通道类型（J/K/T/E/R/S/B/N）。
- 采集帧率 ~4.9 Hz（设备固件串行节流上限，2 请求/帧 × ~103ms）。

## Compatibility

- 配置文件格式：兼容。新增设备类型字段 `daqT1602Config`，旧 profile 文件可正常加载（缺省字段自动补默认值）。
- 数据文件格式：无变化。
- 设备协议行为：新增 Modbus TCP（端口 502）设备类型，不影响既有设备。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本，无需清理用户数据。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.15.0-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。

## Known Issues

- UI 修改热电偶类型保存后仅持久化到 profile，不会立即下发到已连接设备（与 DAQ-T-1603 现状一致）；设备下次连接时以设备实际值为准。
- **既有问题（非本版本引入）**：当 profile 中的 MC4 位移机构（192.168.3.141）不可达时，WTNMC4A FFI gate 在超时后调用失效的 DLL 函数指针导致进程崩溃（`wtnmc4a_motion.go:432`，Exception 0xc0000005）。0.14.1 与 0.15.0 该代码完全相同；冒烟 A/B 验证：MC4 可达时两版本均正常启动，MC4 不可达时均崩溃。建议后续版本单独修复。

## Rollback

- 可直接卸载后重装 0.14.1；配置与数据文件格式无变化，无需额外处理。
