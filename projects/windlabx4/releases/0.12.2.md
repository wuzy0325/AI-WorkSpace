# Wind-DAQ v0.12.2

Release date: 2026-08-03
Package: wind-daq-0.12.2-amd64-installer.exe

## Summary

本版本下线遍历测试的"停止后恢复"能力。停止遍历测试现在表示操作员作出最终决定，临时 checkpoint 会被清理，不再作为未完成任务提供恢复入口。

## User-visible Changes

- 移除单探针遍历测试界面的"未完成任务检测"、"继续测试"、"放弃任务"入口与顶部 checkpoint 提示横幅。
- 移除双探针遍历测试界面对应的恢复入口与提示横幅。
- 停止遍历测试后，临时 checkpoint 文件立即被清理；用户如需中断后续继续，需重新发起测试。

## Breaking Changes

- 删除遍历测试的 `loadCheckpoint`、`resumeFromCheckpoint`、`clearCheckpoint` HTTP 端点。
- 删除单探针与双探针界面的未完成任务检测、继续测试和放弃任务入口。
- 升级后无法从旧版本遗留的 traversal checkpoint 继续测试；如需保留测试结果，请在升级前完成当前遍历任务。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：兼容（已落盘的测试结果 CSV 不受影响）。
- 设备协议行为：无变化。
- API 契约：不兼容。依赖上述 checkpoint 端点的调用方必须移除对应调用。

## Install / Upgrade

- **从 0.12.0 / 0.12.1 升级**：直接运行 `wind-daq-0.12.2-amd64-installer.exe` 覆盖安装即可。用户数据不存储在安装目录，升级无数据丢失风险。
- **跨大版本升级（≤0.11.x）**：建议先通过"控制面板 → 卸载"卸载旧版本，再运行新安装包，避免旧版残留快捷方式与注册表项冲突。
- **旧 checkpoint 残留**：升级前若有未完成的遍历测试，请先在旧版本中完成或导出结果；升级后旧 checkpoint 文件不会被读取，可手动清理 `%APPDATA%\wind-daq\` 下的相关 json 文件。
- 推荐安装步骤：
  1. 关闭正在运行的旧版本 Wind-DAQ。
  2. 运行 `wind-daq-0.12.2-amd64-installer.exe`。
  3. 选择安装语言（简体中文 / English）。
  4. 选择安装目录（默认 `C:\Program Files\Wind-DAQ Team\Wind-DAQ`）。
  5. 安装完成后启动新版本，确认 GUI 正常出现、设备扫描与采集功能可用。

## Known Issues

- 安装包未进行 Authenticode 数字签名，Windows 可能显示"未知发布者"提示，可点击"仍要运行"继续安装。
- 旧版本（≤0.12.1）遗留的 traversal checkpoint 文件在升级后会保留在磁盘但不会被读取，可手动清理 `%APPDATA%\wind-daq\` 下的相关 json 文件。
- LSP / 安全软件拦截场景下的受控降级行为与 0.12.1 一致，无新增限制。

## Rollback

- 可直接回退到 0.12.1：通过"控制面板 → 程序和功能"卸载 0.12.2，再运行 `wind-daq-0.12.1-amd64-installer.exe`。
- 回退后旧 checkpoint 文件若仍保留在 `%APPDATA%\wind-daq\` 下，可被 0.12.1 重新识别。
- 配置与数据文件回退前后兼容，无需额外迁移。
