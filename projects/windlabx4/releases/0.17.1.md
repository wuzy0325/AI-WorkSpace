# WindLabX4 v0.17.1

Release date: 2026-08-20
Package: windlabx4-0.17.1-amd64-installer.exe

## Summary

采集数据时间戳精度提升：保存的 CSV 数据行时间戳由「秒级」扩展为「毫秒级」，格式由 `'YYYY-MM-DD HH:MM:SS` 变为 `'YYYY-MM-DD HH:MM:SS.mmm`，与 DAQ-P-1604 宽格式一致，便于高采样率下区分相邻样本。

## User-visible Changes

- 采集 CSV 数据行 `Timestamp` 列与遍历采集 CSV 的 `Timestamp` / `StartedAt` / `CompletedAt` 列均显示为毫秒精度（`'YYYY-MM-DD HH:MM:SS.mmm`）。
- 文件名保持 `run-<device>-YYYYMMDD-HHMMSS-NNN.csv`（秒级 + 序号），不影响多段数据区分。

## Fixes

- 无。

## Compatibility

- 配置文件格式：兼容，无变化。
- 数据文件格式：**向前兼容，向后不严格兼容**。新版可正确读取旧版秒级时间戳数据；旧版（≤0.17.0）按秒级格式解析新版毫秒时间戳可能错位，建议统一使用 0.17.1 打开数据。
- 设备协议行为：无变化。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `windlabx4-0.17.1-amd64-installer.exe` → 启动确认 GUI 正常出现。
- 无需清理用户数据目录或 WebView2 缓存。

## Known Issues

- 若上游时间戳源本身无毫秒精度（如部分设备固件 fractional 字段异常），毫秒位显示为 `000`，但格式上已统一保留三位毫秒。
- 在 1000Hz 采样下，系统毫秒时间戳精度有限，相邻样本毫秒位可能相同。

## Rollback

- 可直接卸载后重装 0.17.0；配置与数据格式无破坏性变化，但回滚后将丢失毫秒时间戳显示。
