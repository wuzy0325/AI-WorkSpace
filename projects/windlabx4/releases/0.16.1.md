# WindLabX4 v0.16.1

Release date: 2026-08-19
Package: windlabx4-0.16.1-amd64-installer.exe

## Summary

修复 0.16.0 中五孔探针布点文件导入角度范围过严的问题：允许范围从 ±30° 放宽到 ±60°，现场 α=34.921 的布点文件可正常导入。

## User-visible Changes

- 五孔布点文件导入允许角度范围由 `[-30, 30]` 放宽为 `[-60, 60]`（含边界）。

## Fixes

- **布点文件导入失败（超出允许范围）**：导入文件含 α/β 角度绝对值大于 30° 但不超过 60° 的点时（如 α=34.921），整份文件被拒绝。现范围放宽到 ±60°，仅在超出 ±60° 时拒绝并提示行号。

## Compatibility

- 数据文件格式：兼容，无变化。
- 设备协议行为：无变化。
