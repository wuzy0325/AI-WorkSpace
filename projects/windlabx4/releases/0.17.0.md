# WindLabX4 v0.17.0

Release date: 2026-08-19
Package: windlabx4-0.17.0-amd64-installer.exe

## Summary

新增 PACE1000 串口大气压力采集设备支持。操作员可在设备管理中添加 PACE1000，选择 COM 口后连接并采集一个固定「大气压力」通道（单位 Pa）。

## User-visible Changes

- 设备类型下拉新增 **PACE1000**。
- PACE1000 仅支持串口：选择 COM 口即可，其他串口参数固定 `9600-8-N-1`、无流控，不可修改。
- 连接并启动采集后实时显示「大气压力」通道（单位 Pa），默认采样频率 2Hz。
- 采集过程中持续发送 `:sens?\r` 查询，响应按 LabVIEW `%s%f` 语义解析，浮点字段 ×1000 转为 Pa。
- PACE1000 通道固定为单一大气压力，禁止校零；通道名称/单位/量程/精度为只读。

## Fixes

- 修复串口连接占用后无法可靠断开的问题：停止/断开现在可直接解除阻塞读取并释放 COM 口（`serialport` 锁范围修复）。

## Compatibility

- 配置文件格式：兼容，无变化。
- 数据文件格式：兼容，无变化。
- 设备协议行为：新增 PACE1000 设备类型，不影响既有设备。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `windlabx4-0.17.0-amd64-installer.exe` → 启动确认 GUI 正常出现。
- 无需清理用户数据目录或 WebView2 缓存。
