# WindLabX4 v0.15.6

Release date: 2026-08-19
Package: windlabx4-0.15.6-amd64-installer.exe

## Summary

修复 DAQ-P-1604 旧固件设备「能连接、能开始采集但无数据」问题，并修正新建设备的两个不合理默认值（默认单位 V、默认开启设备时间戳）。

## User-visible Changes

- 新建 `DAQ-P-1604` 设备默认单位为 `Pa`（此前切换类型时错误沿用模拟设备的 `V`）。
- 新建 `DAQ-P-1604` 设备默认使用主机时间，不再默认请求设备时间戳。

## Fixes

- **DAQ-P-1604 旧固件采集无数据**：旧固件 ACK 时间戳配置但仍返回 77 字节旧格式帧，导致所有帧解析失败、UI 无数据。驱动现自动回退为无时间戳格式解析，数据使用主机接收时间。
- **新建 DAQ-P-1604 默认单位错误**：切换设备类型后单位继承旧类型，现从新类型默认通道重新读取。

## Compatibility

- 配置文件格式：兼容。新增 `daqP1604UseDeviceTimestamp=false` 默认仅影响新建 profile；已有 profile 保存值不变。
- 数据文件格式：兼容，无变化。
- 设备协议行为：有向后兼容增强——请求时间戳的 1604 设备若返回旧格式帧不再丢弃；发送命令内容不变。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `windlabx4-0.15.6-amd64-installer.exe` → 启动确认 GUI 正常出现。
- 已存在的 `DAQ-P-1604` 设备若仍无数据，请在设备编辑页关闭「使用设备时间戳」后保存重连（或直接用本版本修复后的驱动采集）。

## Known Issues

- 已知限制同 0.15.5：T 型量程下限恰为 0℃ 时真实 0℃ 测量与未接入不可区分；UI 修改热电偶类型保存后不会立即下发到已连接设备。
- 设备扫描对通过 USR-K7 串口服务器接入的 1604 设备可能误识别为 `DAQ-P-1604Pre`，需手动按实际类型添加。

## Rollback

- 可直接卸载后重装 0.15.5；无配置或数据格式变化。
