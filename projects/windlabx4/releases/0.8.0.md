# Wind-DAQ v0.8.0

Release date: 2026-07-18
Package: wind-daq-0.8.0-amd64-installer.exe

## Summary

遍历采集支持多设备并行采集；CSV 计算结果新增单点起止时间戳列，可直接算出单点总耗时；自定义布点交互改造，运动轴绑定迁入布点步骤；实时刷新率统一到全局配置，消除压力卡片与插值卡片的刷新错位。

## User-visible Changes

- 遍历采集支持多设备并行采集，结果按设备/通道归并写入。
- 遍历 CSV 计算结果新增 `StartedAt` / `CompletedAt` 两列：单点采集真实起止时间戳（秒级，与 `Timestamp` 列格式一致），可直接用 `CompletedAt - StartedAt` 算出单点总耗时，不再依赖"点数×10ms"回填公式。
- 自定义布点步骤重排，运动轴绑定合并进布点步骤，配置流程更连贯。
- 实时插值卡片与实时压力卡片刷新同频（统一到全局刷新率，默认 5Hz），消除刷新节奏不一致的视觉错位。

## Fixes

- 无有效样本失败时记录设备应答与通道索引，便于现场定位问题通道。

## Compatibility

- 数据文件格式：兼容。CSV 仅新增可选列 `StartedAt` / `CompletedAt`，旧文件与旧解析逻辑仍可用；0 值单元格写空字符串，避免误显示 1970 时间。
- 配置文件格式：兼容。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐安装步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.8.0-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
