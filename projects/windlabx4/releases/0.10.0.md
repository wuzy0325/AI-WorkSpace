# Wind-DAQ v0.10.0

Release date: 2026-07-24
Package: wind-daq-0.10.0-amd64-installer.exe

## Summary

LogViewer 新增硬件收发命令日志（hardware-send / hardware-recv）可见化能力，便于现场排查设备通信帧；同时将多项缺陷修复与默认参数加固一并交付。

## User-visible Changes

- LogViewer 新增硬件收发命令日志可见化：新增 showHardware 开关，硬件命令收发帧默认在前端可见；抽取 LogEntryRow.vue 子组件重构日志视图，日志改为单行显示、按钮风格统一、标题栏新增中英文切换。
- 新建模拟控制器直线轴默认速度调整为 4；WTNMC4A 轴创建时默认微步设为 4，减少新建轴后的手工配置。

## Fixes

- 修复 NSIS 安装包中文文案乱码（mojibake → UTF-8），安装向导中文正常显示。
- 修复探针参考 β 角计算错误，提升校准与遍历插值精度。
- 修复 1000Hz 采集下高频硬件日志刷屏文件与终端的问题（新增 CategorySkipHandler 跳过高频类别，ring buffer 不受影响）。

## Compatibility

- 配置文件格式：兼容；本次变更无破坏兼容的字段变化。
- 数据文件格式：兼容；未改变既有校准/遍历文件格式。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持从 0.9.0 覆盖安装，无需先卸载旧版本。
- 无需清理用户配置、历史数据、WebView2 缓存或注册表残留。
- 推荐安装步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.10.0-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
  4. 在 LogViewer 中开启硬件命令日志开关以排查设备通信。
