# Wind-DAQ v0.13.1

Release date: 2026-08-10
Package: wind-daq-0.13.1-amd64-installer.exe

## Summary

修复遍历测试在双探针模式下概率性报"devices not acquiring for 1m0s; traversal aborted"的问题：设备未采集超时改为仅对"连续"未采集生效，短暂可恢复的停采不再跨段累计成误判；同时将遍历暂停语义修正为永久暂停（暂停期间不消耗稳定等待/采样时间预算，无限期等待恢复），并修复暂停后首个样本混入暂停前旧帧、暂停失败残留标志导致静默跳点两个问题。

## User-visible Changes

- 遍历测试暂停后可以无限期停留（不再受 60s 设备未采集保护影响），`Resume` 后从暂停处继续完成当前点位。
- 暂停/换探头/设备重连期间产生的短暂停采不再累计触发"设备未采集"失败。
- 恢复后首个采样样本不再包含暂停前采集的旧数据。

## Fixes

- 设备未采集超时语义修正（I-4）：`collectAveragedSamples` 的设备未采集累计值在设备恢复采集后清零，仅"连续"未采集超过 60s 才判失败。
- 稳定等待阶段响应暂停：`waitWhilePaused` / `sleepStabilizationInterval`，暂停不消耗 dwell / minWait / maxWait / 检查间隔的活跃时间预算。
- 暂停期间丢弃已就绪的旧采样帧（fresh/pending），恢复后从新帧重新起算。
- `Pause` 运动停止失败时清除 `isPaused` 标志并置错误状态，避免残留标志导致后续点位静默跳过。
