# Wind-DAQ v0.7.0

Release date: 2026-07-15
Package: wind-daq-0.7.0-amd64-installer.exe

## Summary

引入运动安全（Motion Safety）机制：遍历与校准运行过程中按轴实时监控目标-实际偏差、临界偏离、限位触发、卡死无进展等异常，触发即停止运动并快照现场，前端通过共享告警卡片展示。同步收敛 b140/wtnmc4a 控制器停止/急停逻辑。

## User-visible Changes

- 遍历运行实时监控侧边栏新增运动安全故障现场卡片（红色急停 / 橙色停止双色），展示控制器、轴、目标、实际、偏差、点号。
- 遍历设置面板新增运动安全配置区（到达容差、临界偏离限、无进展超时、进展阈值），支持全局与按轴覆盖。
- 五种校准类型（五孔 / 三孔 / 总压 / 总温 / 总压探针）的设置面板与主界面同步接入运动安全配置与告警展示。
- 运动控制面板状态显示同步更新。

## Fixes

- 修复校准运动等待竞态：运动安全机制接入后等待逻辑收敛到统一时序。
- WTNMC4A 急停标志位时序修正：先置位 EmergencyStopped 再调用停止，避免停止执行期间其他 goroutine 发起新运动命令的时间窗。

## Internal

- 后端：新增 `MotionSafetyConfig` / `MotionSafetyFailure` / `MotionSafetyVerdict` 类型体系；`traversal_motion_watchdog` 看门狗；`coalesceFloat64Ptr` / `coalesceIntPtr` 统一指针字段合并语义。
- 设备 SDK：b140 / wtnmc4a 控制器停止 / 急停逻辑收敛（`stopAllAxesLocked` 共享、`resolveStartMove` / `resolveStopAxis` 测试 seam 统一）。
- 前端：新增共享组件 `MotionSafetyAlertCard` 与 `MotionSafetyPanel`；`getMotionSafetyVerdictLabel` 共享函数消除两处独立 switch。
- 测试：新增 `traversal_motion_safety_test` / `calibration_motion_safety_test` 覆盖 verdict 判定、看门狗触发、急停锁存、按轴停止等关键路径（+2380 行测试）。
- 文档：新增 `spec-calibration-motion-safety.md`（449 行），与 `spec-traversal-motion-safety.md` 共同构成运动安全特性需求契约。

## Compatibility

- 配置文件格式：兼容。运动安全配置为可选字段，旧配置文件加载时使用默认值（到达容差 0.01mm、临界偏离 1mm、无进展超时 2s、进展阈值 0.001mm）。
- 数据文件格式：兼容。CSV / 校准数据格式无变化。
- 设备协议行为：无变化。运动安全仅监控运动过程，不改变下发到设备的指令序列。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐安装步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.7.0-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
  4. （可选）在遍历 / 校准设置面板检查运动安全配置默认值是否符合现场工艺要求。
