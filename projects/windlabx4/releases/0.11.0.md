# Wind-DAQ v0.11.0

Release date: 2026-07-27
Package: wind-daq-0.11.0-amd64-installer.exe

## Summary

本版本交付多设备遍历与七孔探针能力增强，并加固 DAQ-P-1604 在 Windows 多网卡和异常握手场景下的连接可靠性。

## User-visible Changes

- DAQ-P-1604 配置支持可选本地 IP 绑定。
- 七孔探针支持动态 PRB 角度数量和多设备采集。
- 遍历结果记录真实采样窗口起止时间。

## Fixes

- 空长度帧不再破坏后续 P1604 协议帧对齐。
- P1604 连接握手总超时后主动清理 socket。

## Compatibility

- 新配置字段均为可选字段，旧配置可继续使用。
- 既有 CSV 数据可继续读取。

## Install / Upgrade

- 可覆盖安装 0.10.0，无需先卸载。
- 安装前关闭正在运行的旧版本，然后运行安装包。
