# Wind-DAQ v0.5.0

Release date: 2026-07-13
Package: wind-daq-0.5.0-amd64-installer.exe

## Summary

遍历测试可靠性全面升级：跨平台原子文件操作、Point JSON NaN 序列化契约、崩溃恢复断点机制、593 行集成测试。前端 i18n 补充与设备面板优化。

## User-visible Changes

- 遍历测试崩溃恢复：断点/Sync 后崩溃可恢复，CSV 文件自动编号防覆盖，不再报错拒绝启动。
- 前端 i18n 补充：FiveHoleMain、探针校准入口、设备详情面板新增国际化支持。
- 设备面板 UI 优化：DeviceCard、ChartSelector、DeviceDetailPanel 改进。

## Internal

- 跨平台原子文件操作（atomic_replace）：Windows + Unix 各一套实现。
- Point JSON 序列化 NaN↔null 往返契约（line/rectangle/sector 模式运动恢复语义保留）。
- 遍历输出路径集中管理（ResolveOutputPath / ResolveResultLogPath）。
- 遍历 CSV writer 重构：v2 Open/Append/Sync/Close 端口、applyConfigLocked 共享列配置、表头 fsync 落盘、双重初始化防御。
- 遍历断点重构：Close + checkOpen 守卫、Factory.Create 接收 ctx。
- 活动索引安全加固：validatePath 防路径遍历、store-based read 防御。
- 编译期接口断言哨兵全覆盖（6 个 adapter 文件、7 个断言）。
- 593 行 v2 集成测试（Resume 截断、ValidateTail 抗损坏、列配置、旧格式兼容、NaN 往返）。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：遍历 CSV 兼容旧格式，checkpoint 兼容旧格式。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。

## Verification

- `go test ./...`
- `go build -buildvcs=false ./...`
- `npm run typecheck`
- `npm run build`
- `go build -tags production -trimpath -buildvcs=false -ldflags="-w -s -H windowsgui"`

## Known Issues

- DAQ-P-1604 设备固件时间戳 bug 仍存在，CSV 时间戳已统一截断到秒级规避。

## Rollback

- 可回退到 0.4.1。向前兼容：0.5.0 可读取 0.4.1 写入的 checkpoint（旧 Config []byte 字段忽略）。
- 注意：0.5.0 写入的 checkpoint 不再包含 `Config []byte` 字段（统一从 `Snapshot.Config` 读取），0.4.1 回退读取时该字段为 nil，已停止的遍历任务需重新启动，不影响数据文件完整性。
