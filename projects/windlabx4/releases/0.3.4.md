# Wind-DAQ v0.3.4

Release date: 2026-07-06
Package: wind-daq-0.3.4-amd64-installer.exe

## Summary

修复 motion 独立窗口 UI 错乱和 WTNMC4A 负方向移动失效问题。自 v0.3.3 以来仅含 PATCH 级别修复。

## User-visible Changes

- motion 独立窗口禁用缩放，避免用户拉小窗口导致 4 列轴卡片 UI 错乱。

## Fixes

- 修复 motion 独立窗口可被缩小到断点以下导致 UI 错乱的问题。
- 修复 WTNMC4A 运动控制器负方向移动（点动/定位）时位移台不移动的问题：`PLSLogLever` 与 `Direction` 不同步导致 CP 脉冲方向电平不翻转。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：兼容，CSV 格式无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.3.4-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
