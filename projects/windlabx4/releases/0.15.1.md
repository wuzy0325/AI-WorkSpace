# Wind-DAQ v0.15.1

Release date: 2026-08-13
Package: wind-daq-0.15.1-amd64-installer.exe

## Summary

修复 MC4 位移机构（WTNMC4A）不可达时应用启动即崩溃的既有缺陷（Exception 0xc0000005）。除该修复外与 0.15.0（新增 DAQ-T-1602 温度扫描阀支持）完全相同。

## Fixes

- **MC4 不可达启动崩溃**：ffiGate 调用侧超时（ErrFFIHang）返回后，worker goroutine 可能仍在 WTNMC4A DLL 内执行未返回的 FFI 调用（LSP/winsock 阻塞不可取消），清理路径随即 FreeLibrary 卸载 DLL，worker 返回时执行已卸载代码导致进程崩溃。修复：WTNMC4A_64.dll 进程级单例常驻加载、永不卸载；DLL 导出解析失败改为返回错误而非 panic。引入历史：`dll.Release` 自 88e5518（2026-06-08）存在，`ffiGate` 超时机制由 b8475f4 引入后崩溃才可触发。

## Compatibility

- 配置/数据文件格式：无变化，与 0.15.0 完全兼容。
- 设备协议行为：无变化（仅 DLL 生命周期管理改变）。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。
- 推荐步骤：关闭旧版本 → 运行 `wind-daq-0.15.1-amd64-installer.exe` → 启动确认 GUI 正常。

## Verification

- `go vet ./motion/... && go test ./motion/...`（shared/device-sdk）: passed
- 崩溃复现程序（Connect 不可达地址 192.0.2.1）：修复前首次超时后进程崩溃（exit 127），修复后连续 5 次干净返回错误、进程存活
- 生产构建 `scripts/build-release.ps1 -WithInstaller`: passed
- 冒烟启动：见提交记录（含 MC4 不可达场景）

## Known Issues

- UI 修改热电偶类型保存后仅持久化到 profile，不会立即下发到已连接设备（与 DAQ-T-1603 现状一致）。

## Rollback

- 可直接卸载后重装 0.15.0 / 0.14.1；无配置或数据格式变化。注意回退即恢复 MC4 不可达时的启动崩溃。
