# Wind-DAQ v0.13.0

Release date: 2026-08-05
Package: wind-daq-0.13.0-amd64-installer.exe

## Summary

七孔探针插值算法加载与插值链路修复（共享算法包 `shared/algorithms/go/sevenhole/interpolation`）：校准 CSV 系数改为从原始压力列全精度重算，替代历史 3 位小数 K 列；新增网格节点精确往返路由，修复内区边界网格节点被误路由到大角度区、以及自提取 PRB 反推场景下网格边界节点无法定位的问题。Wind-DAQ 七孔校准 CSV 加载链路（`services/api-go/internal/adapters/interpolation`）同步受益，adapter 退化边抖动测试随新加载行为更新。

## User-visible Changes

- **七孔校准 CSV 系数全精度重算**（共享算法包）：系数（ka/kb/cpt/cps）不再直接采用 CSV 中 col12..15 的 3 位小数 K 列，改为由原始压力列（col3=P0、col4=Ps、col5..11=P1..P7）在 float64 全精度下按公式重算。历史 3dp K 列误差最大约 5e-4，全精度重算误差约 1e-6。
- **网格节点精确往返修复**（共享算法包）：内区 21 个边界网格节点此前被误路由到大角度区，现正确路由到内区并精确命中网格节点；校准行按自身网格节点精确往返，自提取 PRB 反推不再因浮点噪声漏判网格边界点。
- **退化边抖动消除**（wind-daq adapter）：全精度重算消除了 3dp 截断导致的精确 ka/kb 相等退化边，加载七孔 CSV 不再产生退化边抖动警告。
- 内/外区边界节点结果会随上述修复变化。

## Compatibility

- 配置文件格式：兼容。
- 数据文件格式：CSV 校准文件兼容（列位置契约不变，仍按 col0/1 角度 + col3..11 压力读取）；历史 3 位小数 K 列（col12..15）不再参与网格构建，仅用于表头诊断。
- 历史 PRB 文件：旧 3dp PRB 与新的全精度网格存在约 5e-4 差异，建议用新版本重新生成/导出 PRB 校准文件后再加载。
- API 契约：兼容（无字段变更）。
- 设备协议行为：不变。
- 插值结果：普通测量点（非网格节点）结果连续，不受网格节点短路径影响。

## Install / Upgrade

- 可直接覆盖安装 0.12.x，无需卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本 Wind-DAQ。
- 运行 `wind-daq-0.13.0-amd64-installer.exe`，安装后启动应用确认主窗口正常出现、设备扫描与采集功能可用。
- 使用七孔插值前，建议用新版本重新加载/生成七孔校准 PRB。
