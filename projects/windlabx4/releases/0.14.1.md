# Wind-DAQ v0.14.1

Release date: 2026-08-12
Package: wind-daq-0.14.1-amd64-installer.exe

## Summary

修复 DAQ-P-1604 / DAQ-P-1604Pre 设备大气辅助通道单位在 UI 上的漂移问题：CH17（大气压力）与 CH18（大气温度）在通道卡片、实时波形 tooltip / y 轴、设备总览中固定显示 Pa 与 ℃，不再随全局压力单位切换或其他命令改写而显示为 psi/kPa 等错误单位。

同步修复七孔探针校准的两个缺陷：校准结果保存 CSV 不分区且 169 个小角度点后角度与系数全为 0；完整模式外区扇区划分错位 30° 导致 6 个大角度区系数与特性曲线全错。

## User-visible Changes

- DAQ-P-1604/Pre 设备 CH17（大气压力）在通道卡片、波形 tooltip / y 轴、设备总览中固定显示 `Pa`。
- DAQ-P-1604/Pre 设备 CH18（大气温度）在上述位置固定显示 `℃`。
- 无论用户将全局压力单位切换为 psi/kPa/MPa，还是 profile 通道单位被其他命令改写，这两个通道的单位展示保持不变。
- 七孔校准保存 CSV 按分区导出 7 份参考数据集格式文件（`(小角度区)` / `(大角度1区)`…`(大角度6区)`，18 列 + GBK 编码），大角度区文件首两列为滚转角 φ / 俯仰角 θ，可直接用于七孔插值加载。
- 七孔大角度区特性曲线（Kθ-Kφ 网格图、φ-K0/φ-Ks 曲线）显示正确。

## Fixes

- 通道卡片单位展示（`DeviceDetailPanel.vue`）对 CH17/CH18 固定为 Pa/℃。
- 实时波形 tooltip 与 y 轴单位（`RealtimeChart.vue`）对 CH17/CH18 固定为 Pa/℃。
- 设备总览通道单位（`DeviceOverviewPanel.vue`）对 CH17/CH18 固定为 Pa/℃。
- 新增共享工具 `src/utils/channelUnit.ts`，三类展示点统一复用，避免各组件各自维护硬编码。
- 七孔 `SaveCsv` 按 region+sector 分区导出（18 列参考数据集格式 + GBK），扇区边界点按几何邻接共享，每区对齐 13 条 φ 网格线。
- `computeSectorFromPhi` 改为扇区居中约定，修复外区系数按错误扇区编号计算。
- `SevenHoleCharts` 跨零修正判据改为 φ 极差 > 180°，修复 4 区误判。
