# WindLabX4 v0.17.2

Release date: 2026-08-27
Package: WindLabX4-0.17.2-amd64-installer.exe

## Summary

修复 DAQ-P-1603 打压读数约为真实值一半的严重换算错误（0-20mA 双极性零点被当成 0），并补充探针校准坐标模式切换、校准完成模态提示等能力；同时修复设备断连后界面状态不翻转的问题。

## User-visible Changes

- 探针校准新增相对/绝对坐标模式切换配置项，适配不同测量基准的现场需求。
- 五孔/三孔/总压/七孔探针校准完成时弹出模态提示框，进度条变色反馈完成状态。
- 总压校准 CPT-α 曲线更名为「压力系数曲线」，移除 CPT Y 轴标签，命名与物理含义对齐。
- 压力系数曲线 Y 轴默认显示范围改为 0.99~1.01，聚焦系数典型区间。

## Fixes

- 修复 DAQ-P-1603 打压读数只有约一半（斜率错误约 2 倍）：`readLoop` 原按 0-20mA 单极性、码值 0=0mA 换算电流，实际硬件为双极性 ±20mA、零点码值 32768，导致所有压力读数压缩到约一半。改用 `GetVoltRangeInfo` 权威参数按 `(code-32768)*CodeWidth - OffsetVolt` 换算。真机（192.168.3.104）打压 -1000Pa 读数由约 -480Pa 修正为约 -1000Pa。**修复后需清掉旧 `tareOffset` 重新校零**（旧值基于错误换算记录）。
- 修复 DAQ-P-1603 禁用 CH1/CH2 后通道错位：`SetTare`/`GetTare` 改为按真实硬件号 `ChannelConfig.Index` 遍历查找，不再按数组下标误判越界。
- 修复设备断连后 UI 状态轮询感知不到断连：轮询能感知 404 并翻转设备状态为已断开。

## Compatibility

- 配置文件格式：兼容，无变化。
- 数据文件格式：兼容，无变化。
- 设备协议行为：无变化；但 DAQ-P-1603 打压读数换算修正，历史数据基于错误换算，旧校零值不再适用，需重新校零。

## Install / Upgrade

- 兼容覆盖安装，无需卸载旧版本。

- 无需清理用户数据目录或 WebView2 缓存。
