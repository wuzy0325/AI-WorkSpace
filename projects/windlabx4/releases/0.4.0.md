# Wind-DAQ v0.4.0

Release date: 2026-07-10
Package: wind-daq-0.4.0-amd64-installer.exe

## Summary

全面国际化 i18n 重构（覆盖所有 UI 模块），遍历测试 UI 大改，三孔/五孔/总压/总温校准 UI 重构，DAQ-P-1603 FFI 驱动稳定性修复。

## User-visible Changes

- 全面国际化 i18n：新增中英文全局切换，覆盖设备/校准/遍历/存储/布局/设置等所有 UI 模块。
- 遍历测试左侧栏与布点画布 UI 全面优化，前端补算预估剩余时间。
- 校准采样进度实时反馈（自动校准过程可视化）。
- 三孔系数重命名（Kt→K0, Sb→Kv），马赫数指针化避免零值歧义。
- 五孔/三孔/总压/总温校准 UI 全面重构：组件拆分、配置面板重排、表单校验增强。
- 日志查看器（LogViewer）布局重构。

## Internal

- i18nStore 新增 1078 行中英文字典。
- 校准 CSV writer 新增中文表头支持（BOM 前缀）。
- 前端 useCalibrationWorkflow composable 重构。
- 后端新增 total_pressure、total_temperature CSV 测试。
- DAQ-P-1603 驱动 FFI 超时参数传指针修复 readLoop 立即退出。
- traversal_view.go 单位转换逻辑修正 + 463 行单元测试。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：CSV 新增中文表头，旧文件仍可读取。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `wind-daq-0.4.0-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
