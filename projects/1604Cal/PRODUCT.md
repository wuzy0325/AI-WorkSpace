# Product

## Register

product

## Users

一线计量/标定工程师与设备调试人员，在工位现场进行设备连接、参数配置、采集控制与报告导出。

主要任务是快速完成标定与计量流程，减少误操作，及时发现设备状态异常与单位不一致问题。使用环境以 Windows 工控机为主，常见为中高分辨率显示器，部分场景需要快速切换窗口与长时间连续操作。

## Product Purpose

Cal1604 是一个统一的工业压力标定系统，将两个遗留应用（1605MeassureApp 计量应用、1604 标定软件）合并为一个 Go 后端 + Vue 3 前端的现代 Web/Desktop 应用。

成功标准：操作路径更短、状态可见性更强、单位一致性检查自动化、设备管理集中化。

## Brand Personality

三个关键词：**清爽、专业、现代**。

情绪目标：让操作者感到"高效、可信、舒适"，界面清晰不压抑。语气偏工程化与结果导向，强调状态反馈与可追溯性。

## Anti-references

- 禁止使用深色主题（与清爽风格冲突，长时间使用压抑）
- 禁止高饱和度渐变色（保持专业感，工业场景不需要炫技）
- 禁止过度动画（工控机性能有限，操作响应优先）
- 禁止卡片嵌套卡片（保持层次清晰）
- 禁止使用非 Element Plus 组件（保持一致性）

## Design Principles

1. **清爽优先**：白色为主，避免压抑感，适合长时间工作。
2. **状态先于装饰**：任何视觉元素优先服务设备状态与流程状态表达。
3. **操作防误触**：关键动作有确认或禁用门禁，按钮层级明确。
4. **信息可扫读**：通过分组、对齐、间距和权重建立快速扫描路径。
5. **一页闭环**：设备管理、会话控制、单位检查与模板选择在同一工作台完成。
6. **持续一致**：颜色语义、交互反馈、文案术语在全站统一。

## Accessibility & Inclusion

工业环境使用，无特殊无障碍要求。基础要求：文字对比度足够、操作目标尺寸合理（≥44px 触控区域）、颜色不只作为唯一状态标识。
