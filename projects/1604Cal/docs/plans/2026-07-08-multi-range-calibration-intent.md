## 1. 背景与问题陈述

计量模块需支持 16 通道压力传感器计量，但**16 个通道不是同一量程**（可能含 1 MPa / 10 MPa / 100 MPa 等混合量程）。旧模块（1605MeassureApp + 1604标定软件）的工作流存在以下痛点：

1. **流程不连贯**——每批计量需进入独立任务页面，无法在一个总任务下连续完成多批
2. **无智能分组提示**——操作员靠记忆判断哪些通道属同量程
3. **无错配警告**——手动勾选通道时容易将不同量程通道混入同一批，存在超量程损坏传感器风险
4. **结果散落各处**——各批结果分散，最终报告需手动拼合
5. **选错量程通道**——手动选通道本身就容易出错

## 2. 意图陈述（Confirmed）

- **Outcome（结果）**：一套面向 16 通道多量程压力传感器的计量流程，让操作员在一个总任务内连贯完成分批计量，最后自动合并报告

- **User（用户）**：一线计量操作员——怕流程散、怕报告散、怕切错硬件、怕手动选通道麻烦

- **Why now（为什么现在）**：旧模块每批要独立任务页、手动拼报告、无连贯编排；混合重构时这是核心痛点

- **Success（成功标准）**：
  1. 操作员进任务 → **现场录入每通道量程**（量程是任务输入，不是预存台账）
  2. 系统自动统计量程分布，提示"本次共需 N 个批次"，**默认把同量程通道勾选为每批次目标**
  3. 操作员可调整每批通道，系统做**同批量程一致性校验**（不一致警告 + 二次确认）
  4. 逐批跑：每批前弹**物理切换提示**弹窗，操作员点击"已确认"后，该批的"开始加压"按钮才启用并自动触发加压序列。操作员也可点"跳过"直接进入加压（留日志），但弹窗**强制展示**不可关闭绕过
  5. 全部批次跑完 → **自动合并到同一输出模板**

- **Constraint（约束）**：
  - 量程是任务现场录入的输入，**不是预存基准**——系统不做"防错配"，只做"输入一致性校验"
  - 物理切换卡点是**提示性**，不强制阻止加压
  - 遵循 [AGENTS.md](../../AGENTS.md)：设备抽象层 + 每设备独立线程 + 统一错误码
  - "同量程"定义：**精确数值匹配**（单位相同 + 数值相同视为同量程）
  - 每批容量：**无强制上限**——系统默认按量程自动划分，一个量程所有通道作为一批。操作员可手动拆分多批（如硬件限制一次只处理 8 通道时）

- **Out of scope（明确不做）**：
  - 通道量程的预存台账（量程每次任务现场录入）
  - 防错配的智能警告（系统没有独立基准，只做输入校验）
  - 强制物理切换闸（卡点只是提示，可继续）
  - 跨任务的批合并（合并只在一个总任务内做）

## 3. 关键设计决策（含权衡记录）

### 决策 1：量程信息采用"现场录入"而非"预存台账"

| 选项 | 说明 | 选择 |
|------|------|------|
| A. 现场录入为主，台账不预存 | 量程每次任务由操作员输入，接受"输入即真相"风险 | **选定** |
| B. 台账预存为主，任务中可覆盖 | 台账是默认值，操作员可修改并留痕 | 未选 |
| C. 台账预存为唯一基准，任务中不可改 | 完全预存，最防错但最不灵活 | 未选 |

**权衡说明**：
- 选 A 的代价——"错配警告"退化为"输入一致性校验"。系统无法识别"操作员输错量程"（如把 1 MPa 通道输成 10 MPa），只能识别"同批内通道量程不一致"。
- 用户已明确接受此代价。
- 风险缓解依赖操作员自检 + 后续报告复核。

### 决策 2：物理切换卡点为"强制展示弹窗 + 双路径确认"

- 卡点行为：每批开始前弹出"请确认已完成量程 X 的物理切换（换标准器 / 管路 / 压力源量程档位）"提示弹窗。弹窗**不可关闭绕过**，必须选择一个操作：
  - 点击"已确认"：该批"开始加压"按钮启用，自动触发加压序列
  - 点击"跳过"：直接进入加压（留操作日志，标注"跳过物理切换确认"），回溯时可用于责任追溯
- 选此方案的理由：既保证提示信息一定被操作员看到（防遗漏），又保留灵活性（不因确认卡死流程），同时操作日志提供追溯依据

### 决策 3：系统主动代操作员做"默认批划分"

- 不是仅"分组显示"让操作员手动选，而是**默认把同量程通道勾选好**作为每批次目标。
- 操作员在此基础上可增减通道，调整后系统做一致性校验。
- 这降低了"手动选错"的概率，是"方便操作员"的关键体现。

## 4. 数据模型与交互规则

### 4.1 通道基础模型

- 通道标识：固定 16 通道，编号 CH1 ~ CH16
- 量程录入格式：数值 + 单位下拉（MPa / kPa / bar / psi），默认单位 MPa
- 通道可标记为"跳过"（不参与本次计量），跳过通道不参与批次划分和一致性校验
- 量程录入值记录到最终报告中，便于复核时发现录入错误

### 4.2 一致性校验规则

- 同批内所有参与通道的**量程数值 + 单位必须完全相同**（精确匹配）
- 校验时机：操作员调整批次通道后实时触发，不一致时显示红色警告 + 列出冲突通道
- 校验结果处理：警告 + 二次确认后**允许继续**（不强制阻止），但该批次报告标注"量程不一致"警告标记
- 默认批划分阶段：系统只按量程分组，不会主动将不同量程通道放入同一批，因此默认划分不会触发校验警告

### 4.3 逐批加压执行模式

- 每批内的加压序列**自动连续执行**——操作员确认后，系统按预设加压点列表自动跑完全部加压点
- 操作员可随时**暂停 / 中止**当前批次
- 每批独立运行，批与批之间由操作员手动切换（含物理切换提示弹窗）

## 5. 非功能性需求

- 操作日志粒度：记录每次"确认" / "跳过" / "校验警告" / "校验二次确认" / "批次开始" / "批次完成" / "暂停" / "中止"，含时间戳和操作员标识
- 合并报告：最终输出为单一 PDF 报告，按批次分段，每批标注通道列表、量程、加压点结果
- 性能：无硬性耗时上限，但单批加压序列应支持最长 10 分钟不超时
- 扩展性：通道数量（16）和量程单位列表通过配置管理，便于后续扩展
