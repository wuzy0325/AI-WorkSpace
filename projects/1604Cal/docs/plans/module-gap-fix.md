# 模块业务功能缺口修复计划

## 计量模块 (MeasurementView) — 对照 1605MeassureApp

### M1. 单位一致性检查展示
- **现状**: 后端有 `GET /api/v1/checks/unit-consistency`，前端无展示
- **遗留**: UnitConsistencyIndicator 组件 + 不一致时禁止采集
- **方案**: 在 MeasurementView 侧边栏添加单位一致性状态指示，不一致时在控制条显示警告

### M2. 报警通道选择对话框
- **现状**: 有 4 个开关（启用/声音/确认/通道），通道选择无交互
- **遗留**: 16 通道网格对话框 + 全选/全不选
- **方案**: 添加 el-dialog 通道选择弹窗，点击"通道"开关时弹出

### M3. 实时数据展示
- **现状**: 轮询获取 currentPressure/isStable/channelData，但未渲染
- **遗留**: 打压设备卡片显示实时压力，计量设备卡片显示通道预览
- **方案**: 在控制条 progress-section 中显示实时压力和稳定状态

### M4. 阀门控制
- **现状**: Device1604Panel 有打开/关闭阀门按钮，`valve-change` 事件悬空
- **遗留**: w0C01 校准状态 / w0C00 测量状态
- **确认**: 后端没有独立阀门 API，阀门控制由标定流程内部自动管理（StartCalibration/EndCalibration 自动切换）。阀门按钮仅做本地 UI 显示即可，暂不修复

### M5. 数据表格增强
- **现状**: 目标值不可编辑，无正/回程标识，无自动滚动
- **遗留**: 目标值可编辑、颜色编码、正/回程标识
- **方案**: 表格目标值列改为 el-input-number 可编辑，回程模式添加正/回标签

### M6. 精度Level自定义模式
- **现状**: 只有下拉预设选项
- **遗留**: 勾选"自定义"后可输入任意值
- **方案**: 添加自定义开关，切换为数字输入框

### M7. 控制模式实际影响后端
- **现状**: controlMode 和 pressureMode 只改本地 UI 状态
- **遗留**: 切换后影响采集行为（自动循环 vs 手动单步）
- **方案**: 在 startCalibration 时将 controlMode/pressureMode 传入后端 config

## 标定模块 (CalibrationView) — 对照 1604标定软件

### C1. 结束校准后端清理
- **现状**: `endCalibration()` 仅重置前端状态
- **遗留**: 断开设备 + 阀门回测量模式 + 后端状态重置
- **方案**: endCalibration 先调用 `triggerSessionAction('stop')`，再重置前端

### C2. 阀门控制（标定）
- **确认**: 同 M4，后端自动管理，暂不修复
