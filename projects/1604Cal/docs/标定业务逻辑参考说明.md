## 1. 系统概述

### 1.1 产品定位

本软件是一款专业的压力扫描阀标定工具,用于对 **WTN1604/1605 系列压力扫描阀** 进行多点压力校准。通过向设备施加多个已知压力点,采集传感器原始数据,执行线性拟合计算,最终将校准系数写入设备,确保设备测量的准确性。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 自动化校准 | 替代人工操作,实现多点压力自动施加和数据采集 |
| 高精度拟合 | 通过多点数据采集和线性拟合,提高校准精度 |
| 多设备协同 | 协调压力扫描阀和打压设备协同工作 |
| 过程可视化 | 实时显示校准进度、设备状态和数据结果 |

### 1.3 涉及的硬件实体

| 硬件实体 | 业务角色 | 说明 |
|----------|----------|------|
| WTN1604/1605 压力扫描阀 | 被标定设备 | 具有16个传感器通道,需要定期校准以保证测量精度 |
| ConST 811A/820 压力控制器 | 压力源设备 | 用于向被标定设备施加精确的已知压力 |

## 2. 核心业务角色

### 2.1 用户角色

**校准工程师**: 负责操作本软件完成压力扫描阀的标定工作,主要职责包括:
- 连接和配置硬件设备
- 设置校准参数(通道、压力点等)
- 监控校准流程执行
- 查看和评估校准结果

### 2.2 业务实体关系

```
校准工程师
    │
    ├── 操作 ──▶ 1604压力扫描阀(被标定设备)
    │               ├── 包含16个传感器通道
    │               ├── 具有阀门状态(校准状态/测量状态)
    │               └── 存储校准系数
    │
    └── 操作 ──▶ 打压设备(压力源)
                    ├── ConST 811A(高精度型)
                    └── ConST 820(快速型)
```

### 5.2 校准参数配置流程

#### 5.2.1 采样平均次数设置

| 参数 | 取值范围 | 默认值 | 业务含义 |
|------|----------|--------|----------|
| 采样平均次数 | 1-100次 | 根据配置 | 每个数据点采集多次取平均,提高数据精度 |

**业务影响**: 采样次数越多,数据越稳定,但采集时间越长。

#### 5.2.2 压力点配置流程

### 6.2 阀门状态管理

#### 6.2.1 阀门状态定义

| 状态 | 业务含义 | 何时使用 |
|------|----------|----------|
| 校准状态 | 阀门切换到校准模式,允许接收校准命令和写入系数 | 校准执行期间 |
| 测量状态 | 阀门切换到正常工作模式,用于日常压力测量 | 校准前后 |

#### 6.2.2 状态转换规则

```
正常使用状态
    │
    ▼
[测量状态] ──▶ 开始校准 ──▶ [校准状态]
    ▲                          │
    │                          │
    │    校准完成/取消         │
    └──────────────────────────┘
```

**关键业务规则**:
- 校准开始前必须确认阀门处于校准状态(阻断性验证)
- 校准结束后应切换回测量状态(容错处理,失败不阻断)

### 6.4 打压控制业务逻辑

#### 6.4.1 打压模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 自动打压 | 系统自动控制打压设备施加目标压力 | 已连接打压设备 |
| 手动打压 | 操作员手动施加压力,系统仅负责采集 | 未连接打压设备或特殊场景 |

#### 6.4.2 自动打压流程

### 6.5 数据采集业务逻辑

#### 6.5.1 采集数据内容

对于每个压力点,系统采集以下数据:

## 8. 业务规则汇总

### 8.1 设备连接规则

| 规则编号 | 规则描述 | 规则类型 | 违反后果 |

| R-DEV-02 | 阀门状态必须为"校准状态"才能开始校准 | 阻断性 | 无法开始校准 |

| R-DEV-04 | 两设备压力单位应保持一致 | 警告性 | 提示用户,不阻断 |

### 8.2 通道选择规则

| 规则编号 | 规则描述 | 规则类型 | 违反后果 |
|----------|----------|----------|----------|
| R-CH-01 | 必须选择至少1个通道 | 阻断性 | 无法开始校准 |
| R-CH-02 | 最多选择16个通道 | 约束性 | 界面限制 |
| R-CH-03 | 通道编号必须在1-16范围内 | 约束性 | 界面限制 |

### 8.3 校准参数规则

| 规则编号 | 规则描述 | 规则类型 | 违反后果 |

| R-PARAM-01 | 压力点数量必须在2-6之间 | 阻断性 | 无法开始校准 |

## 10. 业务场景示例

### 10.1 场景一: 标准校准流程

**场景描述**: 校准工程师对1604设备的8个通道进行4点压力校准。

**前置条件**:
- 1604设备和ConST 811A打压设备均已连接
- 阀门状态为"校准状态"
- 压力单位一致(kPa)

**操作步骤**:

| 步骤 | 操作 | 系统响应 |
|------|------|----------|
| 1 | 选择通道1-8 | 显示已选8个通道 |
| 2 | 设置采样平均次数为10 | 参数已保存 |
| 3 | 设置压力点数量为4 | 显示4个压力点配置项 |
| 4 | 设置目标压力: 10, 30, 50, 70 kPa | 压力点配置完成 |
| 5 | 点击"开始校准" | 系统验证参数,发送开始校准命令 |
| 6 | 系统自动执行校准流程 | 逐点施加压力并采集数据 |
| 7 | 校准数据采集完成 | 显示"数据拟合"按钮 |
| 8 | 点击"数据拟合" | 执行拟合,显示拟合结果 |
| 9 | 点击"结束标定" | 写入系数,阀门回测量状态 |

**预期结果**:
- 8个通道在4个压力点的数据被采集
- 拟合系数自动写入1604设备
- 显示拟合优度(R²)供用户评估

### 10.2 场景二: 手动打压模式

**场景描述**: 打压设备未连接,用户手动施加压力进行校准。

**前置条件**:
- 仅1604设备已连接
- 打压设备未连接

**业务差异**:

| 环节 | 自动模式 | 手动模式 |
|------|----------|----------|
| 压力施加 | 系统自动控制 | 用户手动操作外部压力源 |
| 压力稳定 | 系统自动等待 | 用户自行判断 |
| 数据采集 | 系统自动触发 | 用户点击"采集"按钮触发 |
| 流程控制 | 全自动 | 半自动,用户控制节奏 |

**操作流程**:

```
用户配置校准参数(同标准流程)
    │
    ▼
开始校准
    │
    ▼
┌──────────────────────────────────┐
│ 对于每个压力点:                  │
│                                  │
│ 1. 系统提示用户施加目标压力      │
│ 2. 用户手动操作压力源            │
│ 3. 用户确认压力已稳定            │
│ 4. 用户点击"采集"按钮            │
│ 5. 系统采集数据                  │
│ 6. 系统提示用户释放压力          │
│ 7. 进入下一个压力点              │
└──────────────────────────────────┘
    │
    ▼
所有压力点完成后执行拟合(同标准流程)
```

### 10.3 场景三: 校准中断恢复

**场景描述**: 校准过程中1604设备意外断开连接。

**处理流程**:

| 步骤 | 系统行为 | 用户可见 |
|------|----------|----------|
| 1 | 检测到连接断开 | 显示连接断开警告 |
| 2 | 立即停止打压设备 | 打压设备停止工作 |
| 3 | 保存已采集的数据 | 提示"已保存X个压力点数据" |
| 4 | 尝试恢复阀门状态 | 后台自动执行 |
| 5 | 报告错误并提供建议 | 显示错误信息和恢复建议 |

**恢复选项**:
- **重新连接后继续**: 重新连接设备,从下一个压力点继续
- **重新开始校准**: 清除已有数据,重新配置并执行
- **导出已有数据**: 将已采集的数据导出用于分析

### 10.4 场景四: 高精度校准

**场景描述**: 使用ConST 811A进行高精度校准,需要更长的稳定时间。

**配置特点**:

| 参数 | 标准校准 | 高精度校准 |
|------|----------|------------|
| 采样平均次数 | 10次 | 50-100次 |
| 压力点数量 | 4个 | 6个(最大) |
| 压力稳定等待 | 2秒 | 3-5秒 |
| 打压设备 | ConST 820 | ConST 811A |

**业务价值**:
- 更多采样次数减少随机误差
- 更多压力点提高拟合精度
- 更长稳定时间确保压力准确
- 高精度打压设备提供更好压力源

## 附录A: 业务术语表

| 术语 | 定义 |
|------|------|
| 压力扫描阀 | 一种可以测量多个通道压力的设备,本系统中指WTN1604/1605系列 |
| 标定/校准 | 通过施加已知压力并采集数据,计算修正系数的过程 |
| 通道 | 压力扫描阀的单个压力测量输入点,1604设备有16个通道 |
| 压力点 | 校准过程中施加的一个特定压力值 |
| 打压设备 | 用于产生精确压力的设备,本系统中指ConST系列压力控制器 |
| 阀门状态 | 1604设备的工作模式,分为校准状态和测量状态 |
| 数据拟合 | 根据采集的压力数据计算线性关系系数的过程 |
| 拟合优度(R²) | 衡量拟合曲线与实际数据点贴合程度的指标,范围0-1 |
| 采样平均 | 对同一数据点多次采样后取平均值,用于减少随机误差 |
