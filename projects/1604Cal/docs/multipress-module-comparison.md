## 三、缺失功能详细分析

### 3.1 高优先级缺失功能

#### (1) 采集控制服务
**描述**: 自动化的压力校准采集流程控制

**参考实现**:
- 文件: `CollectionService.ts`
- 功能:
  - 自动/手动采集模式切换
  - 压力点生成算法（等分、自定义）
  - 稳定性等待逻辑
  - 多设备同步采集
  - 进度跟踪与回调
  - 报警检测与处理

**影响**: 无法实现自动化校准流程，需要人工干预每个压力点

#### (2) 批量设备操作
**描述**: 一次性连接/断开多台设备

**参考实现**:
```typescript
// DeviceManager.ts
async connectAll(filter?: DeviceType): Promise<void>
async disconnectAll(filter?: DeviceType): Promise<void>
```

**影响**: 多设备场景下操作效率低

#### (3) 单位一致性检查
**描述**: 确保打压设备与计量设备使用相同单位

**参考实现**:
```typescript
checkUnitConsistency(): { consistent: boolean; devices: DeviceStatus[] }
```

**影响**: 可能因单位不一致导致校准数据错误

### 3.2 中优先级缺失功能

#### (4) 压力限幅设置
**描述**: 设置设备压力上下限，防止超压

**影响**: 存在安全隐患

#### (5) 设备健康检查
**描述**: 定期检查设备连接状态和响应能力

**影响**: 无法及时发现设备异常

#### (6) 自动重连机制
**描述**: 设备断开后自动尝试重连

**影响**: 网络抖动导致设备掉线后需要手动重连

#### (7) 通用模拟器
**描述**: 用于无真实设备时的测试验证

**影响**: 开发测试依赖真实设备

### 3.3 低优先级缺失功能

#### (8) 设备型号识别
**描述**: 连接后自动识别设备型号

**影响**: 需要手动指定设备型号

#### (9) 命令回退机制
**描述**: 某型号不支持某命令时自动回退到兼容命令

**影响**: 部分设备可能因命令不兼容报错

#### (10) 自定义协议支持
**描述**: 支持非SCPI协议的设备

**影响**: 无法接入非标准协议设备

## 四、架构差异分析

### 4.1 通信机制

| 方面 | 参考项目 | 当前项目 |
|------|----------|----------|
| 通信方式 | IPC (进程间通信) | REST API + SSE |
| 实时性 | 高 (内存共享) | 中 (HTTP开销) |
| 跨平台 | Electron限定 | 通用HTTP |
| 调试便利性 | 需Electron DevTools | 可用任意HTTP客户端 |

### 4.2 状态管理

| 方面 | 参考项目 | 当前项目 |
|------|----------|----------|
| 后端状态 | EventEmitter | Go struct + mutex |
| 前端状态 | Pinia Store | Pinia Store |
| 状态同步 | IPC事件推送 | SSE事件推送 |
| 持久化 | localStorage | 文件存储 |

### 4.3 并发控制

| 方面 | 参考项目 | 当前项目 |
|------|----------|----------|
| 锁机制 | async-mutex | sync.Mutex |
| 多设备并行 | Promise.all | goroutine |
| 命令队列 | 无显式队列 | 无显式队列 |

## 五、实现建议

### 5.1 短期补充 (建议优先实现)

1. **批量设备操作API**
   - `POST /api/v1/multipress/connect-all`
   - `POST /api/v1/multipress/disconnect-all`

2. **单位一致性检查API**
   - `GET /api/v1/multipress/unit-consistency`

3. **压力限幅设置**
   - 扩展设备配置，增加 `minPressure`, `maxPressure` 字段
   - 在 `SetTargetPressure` 时进行限幅检查

4. **设备健康检查**
   - 后台定期 ping 设备
   - 超时标记为异常状态

### 5.2 中期补充

5. **采集控制服务**
   - 新建 `internal/application/collection/service.go`
   - 实现压力点生成、稳定性等待、数据采集流程
   - 提供采集进度SSE事件

6. **自动重连机制**
   - 设备断开时自动重试连接
   - 可配置重试次数和间隔

7. **通用模拟器驱动**
   - 实现 `SimulatedPressureDriver`
   - 返回模拟的压力值和稳定状态

### 5.3 长期补充

8. **设备型号自动识别**
   - 连接后发送识别命令
   - 根据响应判断型号

9. **命令回退机制**
   - 定义命令兼容映射表
   - 失败时自动尝试兼容命令
