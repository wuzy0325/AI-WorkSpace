# SPC4000 完整命令参考（Mensor 指令集）

来源：`docs/spc4000_v1_web.pdf` 第 4 章「Remote Operations」Table 4.1。

> 命令为短助记词，写命令（不含 `?`）通常无响应；查询命令（含 `?`）返回
> `<sp>{value}<cr><lf>`。部分命令可带 `1`~`4` 前缀指定传感器/量程（如 `1RP`、`3GP 53.47`）。

## 通道特定命令说明

命令默认作用于**当前激活通道**（见 `Chan` 命令）。例外：`GP`、`GN`、`RP`、
`RP/C`、`ZO` 当带 `1`~`4` 前缀时可指定特定传感器/量程。

## 完整命令表

### 校准与零点

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Autozero` | none | 对所有能量测排气压力的量程重新调零（约 60 秒，不保存） |
| `Autozero?` | — | 返回 `S,T,X,X`：S=状态（0 完成/1 本地/2 远程），T=预计剩余秒数，X=未用(0) |
| `Autozero-abort` | none | 中止调零 |

### 通道与身份

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Chan {A or B}` | A/B | 设置激活通道 |
| `Chan?` | — | 返回激活通道 `A`/`B` |
| `ID?` | — | 返回 `MENSOR,600,{序列号},{版本}` |
| `Listcal?` | — | 返回各传感器序列号与校准日期 |
| `Listrange?` | — | 返回激活通道所有传感器的 min/max 量程 |
| `Sensorid?` | — | 返回激活传感器序列号与固件版本 `MENSOR,600SNSR,{sn},V{v.vv}` |

### 压力控制

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `GP <sp>{value}` | 正压力值 | 切入控制模式并设定正压力（可带 `1~4` 前缀，如 `3gp 53.47`） |
| `GN <sp>{value}` | 负压力值 | 切入控制模式并设定负压力（可带 `1~4` 前缀，如 `2gn 10`） |
| `Measure` | none | 切入 Measure（陷阱）模式 |
| `Measure?` | — | 返回 `YES`（Measure 模式）/ `NO` |
| `Mode?` | — | 返回激活通道操作模式字符串 |
| `ZO` | none | 泄压 + 正/负气路短接（可带 `1~4` 前缀，如 `1zo`） |

### 压力读取

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `RP` | none | 读当前压力（`<n>RP` 指定传感器，`n=1~4`） |
| `RP/C` | none | 连续返回压力（`<esc><cr>` 终止） |
| `Baro?` | — | 返回大气压传感器读数 |
| `Peakmax?` | — | 返回 `Peakreset` 以来的最大压力 |
| `Peakmin?` | — | 返回 `Peakreset` 以来的最小压力 |
| `Peakreset` | none | 复位峰值 |

### 量程

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `RangeMax?` | — | 返回激活传感器量程上限（当前单位，单值） |
| `RangeMin?` | — | 返回激活传感器量程下限（当前单位，单值） |

### 单位

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Units {code or text}` | 数字代码或文本 | 设置工程单位 |
| `Units?` | — | 返回单位**文本字符串**（如 `psi`） |

单位数字代码见 SKILL.md 第 4 节（`psi=1, atm=13, bar=14, mbar=15, mmHg=19, kPa=22, Pa=23, kgf/cm²=26, MPa=36`）。

### 显示与精度

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Decpt {4,5,6}` | 有效位数 | 设置显示有效数字位数 |
| `Decpt?` | — | 返回显示有效位数 |
| `Resolution {4 to 6}` | 有效位数 | 设置有效数字位数（见 decpt） |
| `Resolution?` | — | 返回有效数字位数 |
| `Rdecpt?` | — | 返回速率小数点位数（见 Resolution） |

### 稳定配置（只写参数，无只读标志）

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Stabletime {0~65535}` | 秒 | 设置稳定时间 |
| `Stabletime?` | — | 返回稳定时间 |
| `Stabledelay {0~65535}` | 秒 | 设置稳定延迟 |
| `Stabledelay?` | — | 返回稳定延迟 |
| `StableWin {%fs}` | %FS | 设置稳定窗口（% 满量程） |
| `StableWin?` | — | 返回稳定窗口（% Span） |

### 速率与调节

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Rsetpt {value}` | 速率 | 设置激活通道速率设定点（当前单位/秒，须在量程内） |
| `Volume {cc}` | 体积 cc | 设置系统体积（仅低压调节器通道适用） |
| `Volume?` | — | 返回系统体积（cc） |

### 滤波

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Filter {Off, Low, Normal, High}` | — | 设置读数滤波 |
| `Filter?` | — | 返回读数滤波 |

### 网络

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `IP {nnn.nnn.nnn.nnn}` | IP | 设置仪器 IP 地址 |
| `IP?` | — | 返回 IP 地址 |
| `Netmask {nnn.nnn.nnn.nnn}` | 掩码 | 设置网络掩码 |
| `Netmask?` | — | 返回网络掩码 |
| `Port {value}` | 端口 | 设置以太网端口 |
| `Port?` | — | 返回以太网端口 |

### 串口

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Sbaud {9600,19200,38400,57600}` | — | 设置串口波特率 |
| `Sbaud?` | — | 返回波特率 |
| `Sdata {7 or 8}` | — | 设置数据位 |
| `Sdata?` | — | 返回数据位数 |
| `Sparity {Even, ODD, NONE}` | — | 设置校验位 |
| `Sparity?` | — | 返回校验位 |
| `Sstop {1 or 2}` | — | 设置停止位 |
| `Sstop?` | — | 返回停止位 |

### 系统与杂项

| 命令 | 数据 | 功能 / 响应 |
|------|------|------------|
| `Default` | none | 恢复默认值（约 20 秒） |
| `Error?` | — | 返回错误描述 |
| `Errorno?` | — | 返回错误码与文本 |
| `Keylock {Yes or No}` | — | 锁定/解锁屏幕按键 |
| `Keylock?` | — | 返回按键锁定状态 |
| `Locale?` | — | 返回语言与地区 |
| `Repeat` | none | 串口连续重复输出 |
| `Versions?` | — | 返回固件、GPIB 驱动、门阵列、安装程序、图形库版本 |

## 驱动未使用但可用的命令

以下命令手册定义但当前驱动（`spc4000_driver.go`）未接入，后续如需扩展可参考：

- `Autozero` / `Autozero?` / `Autozero-abort`：自动调零（约 60 秒）
- `Baro?`：大气压读数
- `Chan` / `Chan?`：通道切换
- `Peakmax?` / `Peakmin?` / `Peakreset`：峰值统计
- `Listcal?` / `Listrange?` / `Sensorid?`：传感器/校准信息
- `Stabletime` / `Stabledelay` / `StableWin`：稳定参数读写（可用于校准判稳）
- `Rsetpt` / `Volume`：速率与体积调节
- `Filter`：读数滤波
- `IP` / `Netmask` / `Port` / `Sbaud` 等：网络与串口配置
