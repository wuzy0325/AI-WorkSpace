# Cal1604 校准系统 v1.0.1

Release date: 2026-08-27
Package: Cal1604-1.0.1-amd64-installer.exe

## Summary

通讯日志面板不再记录实时压力轮询（poll）命令与响应，避免高频轮询日志不断刷新、干扰现场排查。

## User-visible Changes

- 通讯日志面板（系统日志 / 悬浮通讯日志）不再显示实时压力读取的轮询命令与响应（标记为轮询 poll=true 的条目不再记录）。
- 非轮询的硬件命令/响应（如连接、打压、单位设置等）与系统错误日志保持不变。

## Compatibility

- 配置文件格式：兼容，无变化。
- 数据文件格式：兼容，无变化。
- 设备协议行为：无变化，仅停止前端日志面板记录轮询条目。

## Install / Upgrade

- 可覆盖安装，无需卸载旧版本。
- 无需清理用户数据目录。
- 安装步骤：
  1. 关闭正在运行的旧版本 Cal1604。
  2. 运行 `Cal1604-1.0.1-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现、通讯日志面板不再刷新轮询日志。
