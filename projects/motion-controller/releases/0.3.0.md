# Motion Controller v0.3.0

Release date: 2026-07-02
Package: motion-controller-0.3.0-amd64-installer.exe

## Summary

B140 编码器补偿全链路支持：新增编码器补偿编辑器 UI、两阶段状态机（settling/checking/compensating）、三层精度约束校验链。操作员可在轴配置中设置编码器补偿参数，系统在运动停止后自动执行补偿修正。

## User-visible Changes

- 新增编码器补偿编辑器：支持预设/自定义补偿参数、实时 warning 校验、帮助提示。
- 轴配置卡片新增光栅尺分辨率可编辑输入入口。
- 保存配置时阻断 error 级补偿告警（配置不合理时阻止保存，并给出明确提示）。
- encoderScale 归一化显示。

## Fixes

- 修复补偿 compensating 分支重读 TP 失败不再静默吞错（原 IIFE return 0 会使修正量退化为整段目标，PR+BG 造成机械猛冲）。
- 修复 Status() 编码器读取失败不再静默回退到寄存器位置，收集到 LastError 使故障对操作员可见。

## Compatibility

- 配置文件格式：兼容，新增 `encoderCompensation` 字段，旧配置无此字段时补偿功能不启用。
- 数据文件格式：兼容，无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 从 v0.2.x 可直接覆盖安装。
- 从 v0.1.x（Wails v2 时代版本）必须先卸载旧版本，再安装本版本。
- 安装步骤：
  1. 关闭正在运行的旧版 motion-controller。
  2. 如果从 v2 时代升级，先卸载旧版。
  3. 运行 motion-controller-0.3.0-amd64-installer.exe。
  4. 启动后打开轴配置页面，确认编码器补偿编辑器可用。
