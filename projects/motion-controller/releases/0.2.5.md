# Motion Controller v0.2.5

Release date: 2026-06-29
Package: motion-controller-0.2.5-amd64-installer.exe

## Summary

修复窗口缩放时运动控制主面板下方出现大片空白的问题，轴卡片现在能随窗口高度合理填充。

## User-visible Changes

- 拉大窗口时，四个轴卡片会占满主面板可用高度，下方不再出现大片空白。
- 轴卡片内部内容（位置读数、监视/点动/定位区域）仍保持顶部对齐，不影响操作。

## Fixes

- 修复 MotionControlPanel 根容器与主面板 section 未建立完整高度继承链导致内容只占自然高度、剩余空间留空的问题。
- `.axis-content` 改为 flex 列布局，`.axis-grid` 增加 `flex: 1; min-height: 0`，`.axis-card` 改为 `height: 100%`。

## Compatibility

- 配置文件格式：兼容，无变化。
- 数据文件格式：兼容，无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 如果安装过 v0.2.x（Wails v3 版本），可直接覆盖安装。
- 如果安装过 v0.1.x 或更早（Wails v2 时代版本），**必须先卸载旧版本**（控制面板 → 卸载或运行 Uninstall.exe），再安装本版本。
- 安装步骤：
  1. 关闭正在运行的旧版 motion-controller。
  2. 如果从 v2 时代升级，先卸载旧版。
  3. 运行 motion-controller-0.2.5-amd64-installer.exe。
  4. 启动后确认 GUI 正常出现，拉大窗口验证轴卡片布局填充正常。
