# Motion Controller v0.2.1

Release date: 2026-06-26
Package: motion-controller-0.2.1-amd64-installer.exe

## Summary

修复安装后桌面快捷方式无应用图标的问题，构建流程补充图标资源嵌入步骤。

## Fixes

- 修复安装包无应用图标显示：icon.ico 文件损坏（仅 562 字节，结构错误），导致 `.exe` 未嵌入图标资源。重新生成 6 分辨率 32bpp 的 `icon.ico`，并新增 `rsrc` 生成 `.syso` 构建步骤确保图标嵌入 `.exe`。
