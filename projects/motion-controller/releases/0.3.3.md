# Motion Controller v0.3.3

Release date: 2026-07-22
Package: motion-controller-0.3.3-amd64-installer.exe

## Summary

WTNMC4A 控制器配置界面隐藏端口字段：WTNMC4A 不基于 TCP 端口通信，端口字段无意义。

## User-visible Changes

- WTNMC4A 控制器：基本信息区不再显示「端口」字段。
- WTNMC4A 控制器：地址字段扩展为占 2 列，填满 5 列网格，避免空位。
- B140 / 模拟控制器：端口字段保持显示，行为不变。

## Compatibility

- 配置文件格式：兼容，无需迁移。WTNMC4A 的 `port` 字段仍由 `defaultPortForType` 维护默认 5000，仅 UI 隐藏。
- 数据文件格式：无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `motion-controller-0.3.3-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
