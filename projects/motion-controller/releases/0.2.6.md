# Motion Controller v0.2.6

Release date: 2026-06-29
Package: motion-controller-0.2.6-amd64-installer.exe

## Summary

修复窗口标题栏左上角图标不显示的问题。任务栏图标正常（由 `rsrc.syso` 嵌入 EXE 资源），但窗口标题栏图标需要通过 `application.Options.Icon` 显式提供 PNG 数据。

## User-visible Changes

- 窗口左上角标题栏图标现在正常显示应用图标。
- 任务栏图标行为不变（已正常）。

## Fixes

- 在 main.go 中添加 `//go:embed build/appicon.png` 嵌入应用图标，并在 `application.Options` 中设置 `Icon: appIcon`。
- 该实现与 wind-daq、daq-t1603、daq-p1604、five-hole-interpolator、three-hole-interpolator 等其他 Wails v3 项目保持一致。

## Compatibility

- 配置文件格式：兼容，无变化。
- 数据文件格式：兼容，无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 从 v0.2.x 可直接覆盖安装。
- 从 v0.1.x（Wails v2 时代版本）必须先卸载旧版本，再安装本版本。
- 安装步骤：
  1. 关闭正在运行的旧版 motion-controller。
  2. 如果从 v2 时代升级，先卸载旧版。
  3. 运行 motion-controller-0.2.6-amd64-installer.exe。
  4. 启动后确认窗口左上角图标正常显示。
