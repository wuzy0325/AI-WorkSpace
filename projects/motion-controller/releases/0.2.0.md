# Motion Controller v0.2.0

Release date: 2026-06-26
Package: motion-controller-0.2.0-amd64-installer.exe

## Summary

Wails v2 → v3 全平台迁移，运动控制器全链路改造（B140 实时位置读取、优先级命令通道、状态推送重构），多项稳定性加固。

## User-visible Changes

- 实时位置读取：B140 控制器支持实时读取轴位置
- 状态推送重构：UI 状态更新更及时、更准确
- UI 交互增强：运动控制主画面和配置画面布局优化
- 配置保存不断连：应用配置后无需重新连接控制器

## Fixes

- Stop/EmergencyStop 完全绕过锁调用 DLL，消除锁竞争导致的响应延迟
- 提高停止/急停优先级，不与 Status 轮询争抢写锁
- WTNMC4A 驱动 DLL 崩溃防护、输入校验、锁优化
- Stop 改用 instStop 立即停止 + atomic 无锁读
- UI spatial rules compliance + token system fixes

## Compatibility

- 配置文件格式：兼容
- 数据文件格式：无变化
- 设备协议行为：无变化
