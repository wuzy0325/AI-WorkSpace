# Motion Controller v0.2.2

Release date: 2026-06-26
Package: motion-controller-0.2.2-amd64-installer.exe

## Summary

修复 v0.2.1 安装后无法启动的问题。根因是 Windows 资源生成时把未替换占位符的 Wails manifest 模板嵌入 `.exe`，导致 Windows Side-by-Side 装载失败。

## Fixes

- 修复启动时报“应用程序无法启动，因为应用程序的并行配置不正确”。
- Windows 资源生成保留图标嵌入，但不再嵌入 `build/windows/wails.exe.manifest` 模板文件。

## Compatibility

- 配置文件格式：兼容
- 数据文件格式：无变化
- 设备协议行为：无变化
