# Motion Controller v0.3.1

Release date: 2026-07-06
Package: motion-controller-0.3.1-amd64-installer.exe

## Summary

轴配置卡片 UI 改进和 motion 工具函数提取到共享模块。自 v0.3.0 以来仅含 PATCH 级别调整和内部重构。

## User-visible Changes

- 轴配置卡片：直线轴显示"导程 mm"，旋转轴显示"传动比"，取代固定双字段布局。
- 标签文案优化：步距角加单位"°"、"反转"→"方向反转"、"位置源"→"位置来源"、速度标签自适应（直线轴"最大速度" / 旋转轴"最大转速"）。
- 点动静步默认值从 1 改为 0.1，降低调试时意外碰撞风险。

## Internal

- 将 motion 配置工具函数提取到 workspace 级共享模块 `shared/frontend/motion-utils`，motion-controller 通过 re-export 使用。保留项目级 maxSpeed 低速默认值 10。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `motion-controller-0.3.1-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
