# Motion Controller v0.2.3

Release date: 2026-06-29
Package: motion-controller-0.2.3-amd64-installer.exe

## Summary

移除轴启用开关，强制所有轴始终启用；设置 Windows GUI subsystem 修复正式构建兼容性。

## User-visible Changes

- 轴启用/禁用开关已移除，所有轴始终启用，简化配置流程。
- 旧配置文件读入时自动迁移（enabled 被强制设置为 true）。
- Windows 正式构建程序不再显示控制台窗口。

## Fixes

- 设置 Windows GUI subsystem，确保正式构建以 GUI 模式运行。

## Compatibility

- 配置文件格式：兼容，旧配置的 enabled 字段在读入时自动归一化为 true。
- 数据文件格式：无变化。
- 设备协议行为：无变化。
