# Motion-Controller v0.3.1-win7.1 (Windows 7 LTS)

Release date: 2026-07-24
Package: Motion-Controller-Win7-Setup-0.3.1-win7.1-x64.exe
SHA-256: BC6777CCEB42F2F28AE8626F1AB7AF16DB14D1093C7A5D8E7D75FCF36DB89E34

## Summary

Windows 7 LTS 首个可交付版本。基于 Electron 22.3.27（Chromium 108，最后兼容 Win7 的 Electron 主版本）承载 Vue 3 前端，Go 后端改为 `net/http` server 监听 `127.0.0.1:16888`，前端通过 HTTP fetch + WebSocket 与后端通信。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:16888` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket |

## User-visible Changes

- 与 master 0.3.1 功能对齐：运动控制、B140 编码器补偿、WTNMC4A 负方向运动等核心功能完整迁移。
- Win7 专属：所有 Wails v3 IPC 调用改为 HTTP fetch，前端 `bridge/` 层重新实现。

## Compatibility

- 配置文件格式：与 master 0.3.1 兼容。
- 运动参数：与 master 0.3.1 一致。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 master 安装包不可共存：两者注册表项、安装目录独立，但同名快捷方式可能冲突，建议二选一。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `Motion-Controller-Win7-Setup-0.3.1-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，运动轴列表能加载。
  4. （可选）实机验证：连接运动控制器，确认轴移动、回零、编码器补偿正常。
- 安装目录默认 `%LOCALAPPDATA%\Programs\motion-controller-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- WTNMC4A 负方向运动问题在 Win7 版与 master 行为一致，根本修复仍在跟进。

## Rollback

- 可回退到 master 0.3.1（Wails 版）。配置文件格式兼容。
- 卸载 Win7 版后安装 master 版即可，两者注册表项独立。
