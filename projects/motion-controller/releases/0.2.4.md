# Motion Controller v0.2.4

Release date: 2026-06-29
Package: motion-controller-0.2.4-amd64-installer.exe

## Summary

规范化生产构建标签，确保所有对外交付 exe 均使用 -tags production 构建。

## Internal

- Taskfile.yml `build-go` 增加 `-tags production -trimpath -buildvcs=false -ldflags="-w -s -H windowsgui"`。
- 新增 `clean` 和 `release` 任务，确保打包前清理旧产物。
- 发布说明模板新增 Install / Upgrade 段。

## Install / Upgrade

- 如果安装过 v0.2.x（Wails v3 版本），可直接覆盖安装。
- 如果安装过 v0.1.x 或更早（Wails v2 时代版本），**必须先卸载旧版本**（控制面板 → 卸载或运行 Uninstall.exe），再安装本版本。
- 安装步骤：
  1. 关闭正在运行的旧版 motion-controller。
  2. 如果从 v2 时代升级，先卸载旧版。
  3. 运行 motion-controller-0.2.4-amd64-installer.exe。
  4. 启动后确认 GUI 正常出现。
