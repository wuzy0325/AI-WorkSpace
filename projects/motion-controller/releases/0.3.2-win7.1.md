## Summary

Win7 LTS 维护版本，自 0.3.1-win7.1 以来同步 master 0.3.2~0.3.4 全部业务改动：WTNMC4A 隐藏端口字段、编码器补偿配置仅 B140 + 编码器轴显示、AxisCard 工业面板风重构、主面板子组件拆分 + 布局与文案优化、配置编辑器扩展 + motion-utils 增强、硬件控制器默认最大速度分层（编辑态切换 clamp 到安全上限）。所有变更通过 master→lts/win7 cherry-pick 同步，业务层零代码差异，仅 Win7 平台壳保持 Electron 22.3.27 + Go 1.20.14。

## Changes vs 0.3.1-win7.1

### Added

- **WTNMC4A 隐藏端口字段**（同步 master 0.3.x）：WTNMC4A 控制器配置界面隐藏不暴露给用户的端口字段。
- **编码器补偿配置仅 B140 + 编码器轴显示**（同步 master 0.3.x）：编码器补偿配置项仅在 B140 控制器且该轴位来源选择了编码器时显示；WTNMC4A / 模拟控制器不显示配置项，避免误配不支持的功能。
- **配置编辑器扩展**（同步 master 0.3.x）：配置编辑器扩展 + motion-utils 增强。
- **硬件控制器默认最大速度分层**（同步 master 0.3.x）：默认最大速度按低速/中速/高速分层，编辑态切换时 clamp 到安全上限。

### Changed

- **AxisCard 工业面板风重构**（同步 master 0.3.4）：轴配置卡片重构为工业面板风格，含 code-review 修复。
- **主面板子组件拆分 + 布局与文案优化**（同步 master 0.3.4）：主面板按职责拆分子组件，布局与文案优化。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:16888` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket |

## Compatibility

- 配置文件格式：与 0.3.1-win7.1 兼容。
- 运动参数：与 0.3.1-win7.1 一致。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 0.3.1-win7.1 安装包可覆盖升级。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `Motion-Controller-Win7-Setup-0.3.2-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，运动轴列表能加载。
  4. （可选）实机验证：连接运动控制器，确认轴移动、回零、编码器补偿正常；切换 B140 / WTNMC4A 控制器验证编码器补偿配置项显隐逻辑。
- 安装目录默认 `%LOCALAPPDATA%\Programs\motion-controller-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- WTNMC4A 负方向运动问题在 Win7 版与 master 行为一致，根本修复仍在跟进。

## Rollback

- 可回退到 0.3.1-win7.1（功能差异：缺少 master 0.3.2~0.3.4 同步的功能改进，包括编码器补偿显隐、AxisCard 工业面板风、子组件拆分等）。配置文件格式兼容。
- 卸载 0.3.2-win7.1 后安装 0.3.1-win7.1 即可，两者注册表项独立。
