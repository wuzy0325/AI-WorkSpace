# Motion Controller v0.3.2

Release date: 2026-07-22
Package: motion-controller-0.3.2-amd64-installer.exe

## Summary

收紧编码器补偿配置的可见范围：仅在 B140 控制器且对应轴「位置来源」选了编码器时显示配置项，避免在 WTNMC4A / 模拟控制器上误配置不支持的功能。

## User-visible Changes

- 编码器补偿配置区仅在「B140 控制器 + 该轴位置来源为编码器」时显示对应轴的配置卡片。
- WTNMC4A / 模拟控制器：编码器补偿区显示提示「仅 B140 控制器支持编码器补偿配置」。
- B140 控制器但所有轴位置来源均为寄存器：显示提示「暂无可配置的轴，请先将轴的「位置来源」设为编码器」。
- B140 控制器且有编码器轴但都未启用补偿：显示提示「未启用任何轴的编码器补偿」。

## Fixes

- 修复用户从 B140 切换到其他控制器类型时，遗留的编码器补偿配置仍触发保存阻断的问题。

## Compatibility

- 配置文件格式：兼容，无需迁移。已配置的 `encoderCompensation` 字段在非 B140 控制器下保留不删，仅 UI 隐藏。
- 数据文件格式：无变化。
- 设备协议行为：无变化。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `motion-controller-0.3.2-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
