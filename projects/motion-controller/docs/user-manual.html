软件概述

运动控制器是一款独立的桌面应用程序，用于配置、测试和操作运动控制器设备。本软件支持多种控制器型号，提供直观的轴控制界面，帮助您轻松完成运动控制任务。

主要功能

  • 支持多种运动控制器型号（模拟控制器、B140、WTNMC4A）
  • 多轴实时控制（X、Y、Z、U 轴）
  • 轴参数配置与编码器补偿
  • 实时位置监视与限位状态显示
  • 点动（Jog）与定位（Move）两种运动模式
  • 紧急停止与安全保护机制
  • 深色/浅色主题切换
  • 中英文语言切换

系统要求

项目要求
操作系统Windows 10/11
内存4GB 及以上
网络与控制器的网络连接（IP 可达）
分辨率1280×720 及以上

控制器配置

在使用软件控制运动设备之前，您需要先配置控制器参数。点击左侧控制器列表上方的「配置」按钮，打开配置面板。

添加新控制器

  1. 点击左侧控制器列表上方的「配置」按钮，打开配置面板。
  2. 在配置面板左下角点击「新建」按钮，或点击左侧列表上方的「+」图标。
  3. 在「通信设置」区域填写控制器信息： n
    • 名称：控制器的显示名称
    • 类型：选择控制器型号（模拟控制器 / B140 / WTNMC4A）
    • 地址：控制器的 IP 地址或主机名
    • 端口：控制器的通信端口号
    • 自动连接：勾选后软件启动时自动连接此控制器
  4. 在「轴配置」区域配置每个轴的机械和电气参数。
  5. 点击「保存」按钮完成配置。

轴配置说明

每个控制器最多支持 4 个轴（X、Y、Z、U）。在轴配置区域，您可以为每个轴设置以下参数：

参数类别参数名说明
机械参数轴类型直线轴（单位 mm）或旋转轴（单位 °）
丝杆导程丝杠旋转一周，螺母移动的直线距离（mm），仅直线轴有效
传动比电机转速与负载转速的比值，仅旋转轴有效
方向反转勾选后轴的运动方向与默认方向相反
电气参数步距角电机每步转过的角度，常见值：1.8°、0.9°、7.5°
细分数驱动器的细分数，越高运动越平滑但扭矩越小
运动参数最大速度轴的最大运动速度（mm/s 或 °/s）
位置源寄存器（内部）或编码器（外部反馈）

编码器补偿（仅 B140 控制器）

当使用 B140 控制器且轴的位置源设置为「编码器」时，可以配置编码器补偿功能，用于补偿机械间隙和反向间隙。

参数说明
容差编码器位置与指令位置的允许误差范围
最大周期补偿执行的最大周期数，防止无限循环
稳定时间补偿到位后的稳定等待时间（毫秒）
最小步长每次补偿的最小移动步长
超时单次补偿操作的最长等待时间（毫秒）

编码器补偿功能仅支持 B140 控制器。如果您使用的是其他型号控制器，此区域将显示「编码器补偿仅支持 B140 控制器」的提示。

连接与断开

连接控制器

  1. 在左侧控制器列表中，点击选择要连接的控制器。
  2. 点击右侧标题区域的「连接」按钮（绿色按钮）。
  3. 等待连接成功，状态指示灯变为绿色，显示「系统在线」。
截图占位

【请在此处插入连接状态截图】

截图应显示已连接状态，绿色指示灯和「系统在线」文字

断开控制器

  1. 确认当前已连接的控制器。
  2. 点击「断开」按钮（灰色边框按钮）。
  3. 状态指示灯变为灰色，显示「系统离线」。

如果配置了「自动连接」，软件启动时会自动尝试连接该控制器，无需手动操作。

轴控制操作

连接成功后，您可以在轴控制面板中对各个轴进行操作。每个轴卡片包含四个功能区域：位置读数、监视、点动、定位。

【请在此处插入单个轴卡片截图】

截图应清晰显示轴卡片的四个区域：位置读数、监视、点动、定位

位置读数

轴卡片顶部显示当前轴的实时位置。位置值以大字显示，单位为毫米（mm）或度（°），取决于轴类型。

  • 位置数值实时更新，反映轴的当前位置。
  • 底部的彩色条带显示最近 50 次位置采样历史，帮助观察运动趋势。
  • 状态指示灯显示轴是否正在运动：绿色闪烁表示运动中，灰色表示静止。

监视区域

监视区域显示轴的限位状态和常用操作按钮。

元素说明
负限位指示灯红色亮起表示触发负方向限位开关
正限位指示灯红色亮起表示触发正方向限位开关
归零按钮将当前位置设为零点（相对坐标系原点）
停止按钮立即停止该轴的运动

点动操作（Jog）

点动模式用于微调轴的位置。您可以设置步长，然后通过前进/后退按钮进行精确移动。

  1. 在步长输入框中输入每次点动的距离（单位与轴类型一致）。
  2. 点击「←」按钮向负方向移动一个步长。
  3. 点击「→」按钮向正方向移动一个步长。

点动操作在轴运动过程中会被禁用，等待当前运动完成后才能进行下一次点动。

截图占位

【请在此处插入点动区域截图】

定位操作（Move）

定位模式用于将轴移动到指定的目标位置。

  1. 在目标位置输入框中输入要移动到的位置（相对于零点的坐标）。
  2. 系统会自动检查目标位置是否在限位范围内。
  3. 如果目标位置超出限位，输入框会显示红色警告。
  4. 点击「移动」按钮，轴将运动到目标位置。

当目标位置接近限位（距离限位 10% 范围内）时，系统会显示黄色警告「接近限位，请谨慎操作」。请确认安全后再执行移动。

状态监视

控制器状态

在右侧标题区域，您可以查看当前控制器的连接状态：

  • 在线 绿色指示灯表示控制器已连接，通信正常。
  • 离线 灰色指示灯表示控制器未连接。
  • 显示控制器名称、型号和 IP 地址。

报警信息

当控制器发生错误时，界面顶部会显示红色报警条，包含错误信息。点击右侧的「×」按钮可以清除报警显示。

急停与安全

紧急停止

紧急停止（E-Stop）用于在紧急情况下立即停止所有轴的运动。

紧急停止会立即停止所有运动！ 请在真正紧急的情况下使用，如发生碰撞、人员安全受到威胁等。

触发急停的方式

  1. 点击界面右上角的红色「急停」按钮。
  2. 按下键盘上的 ESC 键。

【请在此处插入急停按钮截图】

解除急停

触发急停后，界面会显示黄色警告条，提示「急停已激活」。此时所有操作按钮将被禁用。

  1. 确认现场安全，排除故障原因。
  2. 点击黄色警告条中的「解除急停」按钮。
  3. 急停解除后，可以恢复正常操作。

【请在此处插入急停激活状态截图】

停止所有轴

如果需要停止所有轴的运动（非紧急情况），可以点击「停止全部」按钮（黄色按钮）。此操作会平滑停止所有轴，不会触发急停状态。

故障排除

无法连接控制器

可能原因解决方法
IP 地址或端口错误检查配置中的地址和端口是否正确
网络不通使用 ping 命令测试网络连通性
控制器未启动确认控制器设备已上电并正常运行
防火墙阻止检查防火墙设置，放行对应端口

轴无法运动

可能原因解决方法
控制器未连接先点击「连接」按钮建立连接
急停已激活点击「解除急停」按钮
触发限位反向点动离开限位开关
目标位置超限修改目标位置到限位范围内

位置显示异常

可能原因解决方法
零点未设置点击「归零」按钮设置当前位置为零点
编码器方向反了在配置中勾选「方向反转」
丝杆导程错误检查并修正轴配置中的丝杆导程参数

如果问题仍然无法解决，请记录错误信息并联系技术支持人员。
