# DAQ-T-1603 v0.6.7

Release date: 2026-08-04
Package: daq-t1603-0.6.7-amd64-installer.exe

## Summary

为设备配置面板新增设备名修改入口与改名唯一性校验，对齐 daq-p1604 v0.7.4 同款修复。此前 daq-t1603 配置面板头部只读显示设备名，用户改名需重新扫描或修改 profile 文件；现可在面板内直接改名并防止重名冲突导致 sidebar/monitor 出现多个同名设备无法区分。

## User-visible Changes

- 设备配置面板"硬件参数" section 顶部新增"设备名称"输入框，用户可随时改名（采集期间禁用，与采样频率等硬件参数一致）。
- 改名保存时校验名字唯一性：若与其它设备重名，阻断保存并提示"设备名称已被其他设备占用，请修改后重试"。

## Fixes

- **配置面板缺少设备名修改入口**：`DaqT1603Config.vue` 头部只读显示 `profile.name`，整个面板没有设备名 input，`saveConfig` 也不写 `name` 字段。修复：新增 `deviceName` ref，在 `syncFormFromProfile` 回填、watcher 监听、`saveConfig` 写入 `nextProfile.name`；改名不触发 `applyConfig`（`hasHardwareConfigChanged` 不含 name），只走 `saveProfile` 持久化。设备名 trim 后写入，空字符串由 sidebar/monitor 的兜底逻辑显示为"未命名"。
- **改名缺少唯一性校验**：daq-t1603 扫描路径不提供内联改名，用户通过添加对话框手动命名，addProfile 仅按 IP:port 去重不校验名字；新增的配置面板改名路径走 `saveProfile` 仅按 `id` 替换，不校验名字是否与其他 profile 重复。修复：`saveConfig` 开头加唯一性校验，排除当前 profile 自身（用户未改名直接保存不应触发冲突），与 daq-p1604 v0.7.4 配置面板改名约束对齐。

## Compatibility

- 配置文件格式兼容（`DeviceProfile.name` 字段类型不变）。
- CSV 数据格式不变。
- 设备协议命令链不变。
- 扫描协议（UDP 广播 + 单播响应）不变。

## Install / Upgrade

- 可覆盖安装 0.6.4 / 0.6.6，无需先卸载或清理用户配置（0.6.5 含槽位泄漏 bug 请勿使用）。
- 若当前设备无法连接（0.6.5 遗留槽位泄漏）：先退出所有 DAQ-T-1603 进程（或重启设备），再安装 0.6.7。
- 安装前先关闭正在运行的旧版本。
- 运行 `daq-t1603-0.6.7-amd64-installer.exe`，安装后启动应用确认主窗口正常出现。
