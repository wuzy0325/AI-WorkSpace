# DAQ-T-1603 v0.3.3-win7 (Windows 7 LTS)

Release date: 2026-07-24
Package: DAQ-T-1603-Win7-Setup-0.3.3-x64.exe
SHA-256: BDF6C82946C4552913C58D903DD1DC1B2C716B9AFE6C0FB2BF53C1E50285650C

## Summary

Windows 7 LTS 首个可交付版本。基于 Electron 22.3.27（Chromium 108，最后兼容 Win7 的 Electron 主版本）承载 Vue 3 前端，Go 后端改为 `net/http` server 监听 `127.0.0.1:18181`，前端通过 HTTP fetch + WebSocket 与后端通信。同步 cherry-pick master 上 daq-t1603 相关提交（停止采集后 drainConnection、shutdown panic guard、CSV session mask 清理、async state push 等）。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:18181` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket + `recover` 防 shutdown panic |

## User-visible Changes

- 与 master 0.3.3 功能对齐：修复停止采集后 TCP 缓冲区残留导致配置参数报错的问题。
- Win7 专属：`EmitDeviceState` 增加 `recover` 保护，避免 WebSocket 关闭期间触发 panic。
- Win7 专属：CSV 录制 session mask 在停止采集时正确清理，避免下次录制通道掩码残留。
- Win7 专属：错误正则表达式加固，避免误匹配设备型号字符串。

## Compatibility

- 配置文件格式：与 master 0.3.3 兼容。
- 数据文件格式：CSV 列格式无变化。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 master 安装包不可共存：两者注册表项、安装目录独立，但同名快捷方式可能冲突，建议二选一。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `DAQ-T-1603-Win7-Setup-0.3.3-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接 DAQ-T-1603，确认热电偶类型配置、采集、CSV 录制正常。
- 安装目录默认 `%LOCALAPPDATA%\Programs\daq-t1603-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- `daq-t1603` 仍使用单模块布局（`apps/desktop-wails/{core,ports,usecase,adapters}`），与 split-layout 项目（daq-p1604）目录结构不同。

## Rollback

- 可回退到 master 0.3.3（Wails 版）。配置文件格式兼容；CSV 格式一致。
- 卸载 Win7 版后安装 master 版即可，两者注册表项独立。
