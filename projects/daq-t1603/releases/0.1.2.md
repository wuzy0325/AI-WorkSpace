# DAQ-T-1603 v0.1.2

Release date: 2026-06-18
Package: daq-t1603-amd64-installer.exe (6.7 MB NSIS installer)

## Built Artifacts

| 产物 | 路径 | 大小 |
|---|---|---|

| NSIS 安装包 | `build/bin/daq-t1603-amd64-installer.exe` | 6.7 MB |

## Summary

修复硬件通信协议问题（移除命令尾部 `\n`），增强帧解析健壮性（metadata mode / Resync），修复前端状态闪烁和频率显示错误，采样率输入改为自由数字框。

## User-visible Changes

- 采样率输入从下拉选择框（预设值）改为自由数字输入框（1-1000Hz）。
- 连接/断开按钮在 "Starting"/"Stopping" 过渡状态正确显示加载动画和"断开"文字。
- 详情面板频率显示位置修正为读取 `t1603Config.samplingRate`。

## Fixes

- 修复 `SendCommand`/`SendCommandIdle`/`SendCommandExact` 向命令追加 `\n` 导致的硬件协议错误。
- 修复前端 DeviceSidebar/MonitorView 缺少 "Starting" 状态导致的状态闪烁。
- 修复 MonitorView 频率显示从错误的顶层 `samplingRate` 字段读取（实际值在 `t1603Config` 中）。
- 修复 `parseSpaceSeparatedFrame` 对 17 token 元数据格式（单独启用 TIME 或 HEAD）的支持。
- 新增帧偏移重同步 `Resync()` 方法，防止残留数据导致持续帧错位。

## Compatibility

- 配置文件格式：兼容
- 数据文件格式：兼容
- 设备协议行为：有变化——命令不再追加 `\n`。如果现场设备固件依赖 `\n` 作为命令结束标记，本次更新将导致通信失败。已在固件验证中确认 T1603 设备不需要 `\n`。
