# DAQ-T-1603 v0.1.1

Release date: 2026-06-10
Package: DAQ-T-1603-v0.1.1-windows-amd64-20260610.exe

## Summary

修复前端边界违规：将错误驻留在前端的领域逻辑（硬件状态判断、状态码映射）转移到 Go 后端，清理死代码，修复配置保存时硬件错误被吞没的问题。

## User-visible Changes

- 配置保存时，若硬件参数下发成功则显示"配置已保存并应用到设备"，若失败则显示具体错误信息。
- 移除"采集中不允许变更配置"的前端限制——此检查现已由后端执行，前端不再需要了解此硬件行为。

## Fixes

- 修复前端 DaqT1603Config.vue 中硬件配置应用失败被空 catch 静默吞没的问题。
- 修复前端 deviceStore 在采集启动/停止失败时通过解析后端数值枚举推断状态的问题。
- 移除前端未使用的 TC_RANGES 热电偶量程常量和 updateT1603Config 函数。
- 适配器状态变更统一走 SetStatus()，确保 Status 和 StatusText 同步。
