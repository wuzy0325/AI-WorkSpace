# DAQ-T-1603 v0.6.2

Release date: 2026-07-29
Package: daq-t1603-0.6.2-amd64-installer.exe

## Summary

补全 0.6.1 Windows UDP 扫描修复中遗漏的 watchdog 兜底,确保 `SO_RCVTIMEO` 在特定 Windows 环境失效时仍能强制解除阻塞的 `Recvfrom`,符合 ADR-009 第 5 条要求。

## User-visible Changes

- 设备扫描行为与 0.6.1 一致:固定时间内返回已发现设备,不会永久卡死。
- 无 UI 变化。

## Fixes

- Windows Winsock discovery socket 补回 `time.AfterFunc(timeout, Closesocket)` watchdog,与 `SO_RCVTIMEO` 形成"软超时 + 硬兜底"双重保护。
- `sockaddrString` 出现非 IPv4 sockaddr 时显式返回错误,不再静默丢弃设备响应。

## Compatibility

- 配置文件格式兼容。
- CSV 数据格式不变。
- 设备发现命令和响应协议不变。

## Install / Upgrade

- 可覆盖安装 0.6.0/0.6.1,无需先卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本。
- 运行 `daq-t1603-0.6.2-amd64-installer.exe`,安装后启动应用确认主窗口正常出现。
