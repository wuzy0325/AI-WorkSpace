# DAQ-T-1603 v0.5.0-win7.1 (Windows 7 LTS)

Release date: 2026-07-25
Package: DAQ-T-1603-Win7-Setup-0.5.0-win7.1-x64.exe
SHA-256: 04908ec51a8f23d509c8059500390b04aa4302f07f0dd87d0c1036f399d80336

## Summary

主版本号与 master 0.5.0 对齐的 Win7 LTS 维护版本。相对 0.4.0-win7.1 新增一项核心改动：drainConnection 改为连续 2 个静默窗口才退出（同步 master 0.5.0），避免快速启停后残留帧尾被下一次命令读取当作响应乱码。

## Changes vs 0.4.0-win7.1

| 维度 | 0.4.0-win7.1 | 0.5.0-win7.1 |
|---|---|---|
| drainConnection 退出策略 | 单次静默即返回 | 连续 2 次静默才返回 |
| 回归测试覆盖 | 无 | `TestDAQT1603DrainConnectionWaitsForDelayedFrameTail` |
| master 对齐版本 | 0.4.0 | 0.5.0 |

## User-visible Changes

- **采集启停后命令响应乱码问题修复**：快速 StartAcquisition → StopAcquisition → ApplyConfig 序列下，原 drainConnection 单次静默即返回，残留帧尾若延迟到达（如 100ms 后）会被下一次 ApplyConfig 的命令响应读取当作乱码。现要求连续 2 次静默窗口才结束 drain，确保延迟到达的帧尾被吸收。
- 版本号升级到 `0.5.0-win7.1`，与 master 0.5.0 主版本号对齐。

## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:18181` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket + `recover` 防 shutdown panic |
| UI 刷新率调整 | `SetUIRefreshRateHz` Wails Bind | `POST /api/device/set-ui-refresh-rate` HTTP fetch（0.4.0-win7.1 引入） |

## Compatibility

- 配置文件格式：与 0.4.0-win7.1 兼容。
- CSV 文件格式：与 0.4.0-win7.1 一致（18 列 `Timestamp,Unit,CH01..CH16`）。

- 与 0.4.0-win7.1 安装包可覆盖升级。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `DAQ-T-1603-Win7-Setup-0.5.0-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接 DAQ-T-1603，确认热电偶类型配置、采集、CSV 录制正常；快速启停采集后立即下发配置参数验证命令响应不再乱码。
- 安装目录默认 `%LOCALAPPDATA%\Programs\daq-t1603-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- `daq-t1603` 仍使用单模块布局（`apps/desktop-wails/{core,ports,usecase,adapters}`），与 split-layout 项目（daq-p1604）目录结构不同。
- `frontend/bindings/` 目录保留 master 上的 Wails v3 .ts binding 文件，但 `frontend/src/` 已无引用（lts/win7 用 fetch + WebSocket 替代）。这些文件作为历史遗留保留，不影响构建。

## Rollback

- 可回退到 0.4.0-win7.1（功能差异：drainConnection 单次静默即返回，可能在快速启停后出现命令响应乱码）。配置文件格式兼容；CSV 列数一致。
- 卸载 0.5.0-win7.1 后安装 0.4.0-win7.1 即可，两者注册表项独立。
