# DAQ-T-1603 v0.3.3

Release date: 2026-07-03
Package: daq-t1603-0.3.3-amd64-installer.exe

## Summary

修复停止采集后配置参数报错的问题。根因是停止采集后 TCP 缓冲区残留采集数据帧，后续 ApplyDaqT1603Config 的 sendCommand 把残留当作命令响应读出，导致配置命令失败。

## User-visible Changes

- 无新增功能，仅缺陷修复。

## Fixes

- 修复停止采集后立即配置参数（热电偶类型、二进制格式、时间戳等）时命令响应乱码或失败的问题。在 stopAcquisitionLocked 停止命令后增加 drainConnection 排空 TCP 缓冲区残留数据帧；在 ApplyDaqT1603Config 调用 applyHardwareConfig 前增加 drainConnection。

## Compatibility

- 配置文件格式：兼容，无需迁移。
- 数据文件格式：兼容，CSV 格式无变化。
- 设备协议行为：无变化，仅在配置命令前增加缓冲区排空。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `daq-t1603-0.3.3-amd64-installer.exe`。
  3. 启动新版本并确认 GUI 正常出现。
