# DAQ-T-1603 v0.6.3

Release date: 2026-07-29
Package: daq-t1603-0.6.3-amd64-installer.exe

## Summary

补齐 0.6.2 未发布的 TCP 连接卡死修复。0.6.2 只修了 UDP discovery 卡死，TCP `Dial` / `syncHardwareConfigLocked` / 前端 `connect` 三条路径仍可能在 ADR-009 故障 Windows 机器上永久卡死，导致 UI 一直显示"连接中"无法翻转。0.6.3 通过 watchdog goroutine + 软超时 + 前端 10s 兜底三层防护彻底解决。

## User-visible Changes

- 连接失败时 UI 状态会在 10s 内从"连接中"翻转为"未连接"并显示真实错误，不再永久卡死。
- 故障 Windows 机器上 `Dial` 超时后会立即返回 `os.ErrDeadlineExceeded`，错误信息明确，便于现场定位。

## Fixes

- **TCP `Dial` watchdog 兜底**：`protocol.DialTCP` 用子 goroutine 跑 `Dial` + 主 goroutine `time.After` 软超时，超时立即返回，Dial 较晚返回时通过 select-default 关闭 conn 防 FD 泄漏。
- **`readAllConfig` 不再吞 watchdog 错误**：检测到 `protocol.ErrWatchdogTriggered` 立即返回，不再走完剩余 9 条 `@fd` 查询 + 3 条 `@fe` 强制命令，暴露真正的"连接被 watchdog 强制关闭"根因。
- **前端 `connect` 10s 超时兜底**：新增 `CONNECT_TIMEOUT_MS = 10000`（覆盖后端最坏 9s + 1s 余量），与 `startAcquisition` / `applyConfig` 一致采用 `withTimeout` 包装。
