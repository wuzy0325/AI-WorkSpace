## Architecture (Win7 vs master)

| 维度 | master (Wails v3) | lts/win7 (Electron 22) |
|---|---|---|
| GUI 壳 | Wails v3 (Edge WebView2) | Electron 22.3.27 (Chromium 108) |
| Go↔前端 IPC | Wails binding | HTTP fetch + WebSocket |
| Go 后端入口 | `application.New()` | `net/http` server @ `127.0.0.1:18181` |
| 日志库 | `log/slog`（Go 1.21+） | `shared.local/device-sdk/go/pkg/slog` polyfill（Go 1.20） |
| 安装包 | NSIS via `project.nsi` | NSIS via `electron-builder` |
| 事件推送 | `app.Event.Emit` | `hub.EmitEvent` over WebSocket + `recover` 防 shutdown panic |
| UI 刷新率调整 | `SetUIRefreshRateHz` Wails Bind | `POST /api/device/set-ui-refresh-rate` HTTP fetch |

## User-visible Changes

- **UI 刷新率真正生效**：原 0.3.3-win7 后端 `relayStream` 硬编码 10Hz 推送 daq:payload，前端 MainTopBar 切换 2/5/15/20/30Hz 档位时只控制 flushPendingSnapshots 节奏，不影响后端推送频率。本次新增 `SetUIRefreshRateHz` 后端方法 + 前端 HTTP 调用，切换档位时即时同步后端 `uiTicker`（`Ticker.Reset` 动态跟随，最长等一个旧间隔生效），数值卡与图表的更新节奏真正改变。
- **CSV 表头简化为 18 列**：原 20 列 `DeviceID,Timestamp,Millisecond,Unit,CH01..CH16` 改为 18 列 `Timestamp,Unit,CH01..CH16`。DeviceID 列移除（文件名已含 deviceSlug）；Millisecond 列移除（时间戳回到秒级 `'YYYY-MM-DD HH:MM:SS'`，与 0.3.2 决策一致；1000Hz 同秒样本共享同一时间戳，靠文件名毫秒后缀区分文件）。
- **MonitorView 连接按钮简化**：移除未使用的 Loader2 图标与 .spin 动画，仅保留 Connecting 态 loading。

## Compatibility

- 配置文件格式：与 0.3.3-win7 兼容。
- **CSV 文件格式破坏性变更**：列数从 20 减为 18，旧 CSV 文件读取脚本需同步更新列索引。建议归档 0.3.3-win7 时期的 CSV 数据后再升级。
- 操作系统：仅支持 Windows 7 SP1 x64、Windows 8.1 x64、Windows 10/11 x64。**不支持 Windows XP/Vista**。
- 与 0.3.3-win7 安装包可覆盖升级。

## Install / Upgrade

- 支持覆盖安装，无需先卸载旧版本。
- 推荐步骤：
  1. 关闭正在运行的旧版本。
  2. 运行 `DAQ-T-1603-Win7-Setup-0.4.0-win7.1-x64.exe`。
  3. 启动后确认 GUI 正常出现，设备列表能加载。
  4. （可选）实机验证：连接 DAQ-T-1603，确认热电偶类型配置、采集、CSV 录制正常；切换 MainTopBar 刷新率档位观察数值卡更新节奏变化。
- 安装目录默认 `%LOCALAPPDATA%\Programs\daq-t1603-win7\`。

## Known Issues

- 360 安全卫士主动防御可能锁定 `app.asar` 文件，导致重复打包时 `win-unpacked` 目录无法清理。建议在 360 信任区添加项目目录。
- Electron 22.3.27 不支持 `color-mix()` CSS 函数，UI 渲染与 master 可能有细微差异，已用 rgba fallback 规避。
- `daq-t1603` 仍使用单模块布局（`apps/desktop-wails/{core,ports,usecase,adapters}`），与 split-layout 项目（daq-p1604）目录结构不同。
- `frontend/bindings/` 目录保留 master 上的 Wails v3 .ts binding 文件，但 `frontend/src/` 已无引用（lts/win7 用 fetch + WebSocket 替代）。这些文件作为历史遗留保留，不影响构建。

## Rollback

- 可回退到 0.3.3-win7（功能差异：UI 刷新率不生效、CSV 20 列）。配置文件格式兼容；CSV 列数有破坏性变更，回退后旧 CSV 仍可读但新 CSV 列数会恢复 20。
- 卸载 0.4.0-win7.1 后安装 0.3.3-win7 即可，两者注册表项独立。
