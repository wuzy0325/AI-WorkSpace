# DAQ-T-1603 v0.1.3

Release date: 2026-06-23
Package: daq-t1603-0.1.3-amd64-installer.exe

## Summary

修复适配器死锁、CSV 录制数据丢失、状态卡在 Acquiring 等关键问题；移除模拟模式，聚焦纯物理设备采集路径；前端扫描列表防重复添加。

## User-visible Changes

- 扫描结果列表对已添加设备显示"已添加"徽章，不再显示"+"按钮，防止重复添加。
- 添加设备时自动拒绝重复 IP:Port（store 层二次校验，有提示信息）。
- 硬件时间戳开关文案"显示/隐藏" → "启用/禁用"，更准确地反映语义。
- 文档文件移至项目顶层 `docs/` 目录。

## Fixes

- 修复适配器 StopAcquisition/Disconnect 与 readLoop 回调之间的互锁死锁。
- 修复 readLoop 异常退出后驱动未断开，下次采集在坏连接上重试的问题。
- 修复 Status() 在停止采集后仍返回 Acquiring 的问题。
- 修复 CSV 录制: relayStream 每条 snapshot 即时写入，不再每秒合入一条记录。
- 修复设置命令后概率出现采集数据解析乱码的问题。

## Removed

- 移除 `SimulatedAdapter`、`SimulatedScanner`、`DAQ_T1603_MODE=simulated` 环境变量及所有模拟模式测试。该应用仅支持真实 T1603 设备。

## Performance

- CSV 文件名 `FormatFloat` 替代 `fmt.Sprintf`，每秒减少 16000 次格式串解析。
- CSV 使用 `sync.Mutex` 替代 `sync.RWMutex`（降低开销）。
- CSV `IsActive()` 使用 `atomic.Bool`，relayStream 热路径无锁判断录制状态。
- 采集 channel 缓冲区 8192 → 65536（1000Hz 下 ~65s 缓冲）。
- CSV flush 行阈值 100 → 2000，减少多设备场景磁盘同步次数。

## Compatibility

- 配置文件格式：兼容（`showTimestamp` 字段语义不变）
- 数据文件格式：兼容
- 设备协议行为：无变化
- 移除环境变量 `DAQ_T1603_MODE=simulated`，模拟模式不再可用。
