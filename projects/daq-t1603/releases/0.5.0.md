# DAQ-T-1603 v0.5.0

Release date: 2026-07-25
Package: daq-t1603-0.5.0-amd64-installer.exe

## Summary

本版本聚焦 UI 刷新率真正生效与采集启动稳健性：修复后端 `uiPayloadRefreshInterval` 硬编码 100ms 导致前端刷新率下拉项无效；将 drainConnection 改为连续 2 个静默窗口才退出，避免快速启停后残留帧尾被下一次命令读取当作响应乱码；新增 Taskfile.yml 统一构建流程。

## User-visible Changes

- 顶部刷新率下拉项现在真正生效：10Hz → 30Hz 数值卡更新更快、10Hz → 2Hz 数值卡与图表同步变慢（此前数值卡始终 10Hz）。
- 启动时自动同步 localStorage 中的刷新率偏好到后端。
- 连接按钮 Connecting 态 loading 保留，移除多余的 Loader2 旋转动画。

## Fixes

- 修复 UI 刷新率设置不生效（后端硬编码 100ms，前端设置仅控制图表 flush 节奏，不影响后端推送频率）。
- 修复 drainConnection 单次静默即返回导致快速启停后残留帧尾被当作命令响应乱码。

## Compatibility

- 配置文件格式：兼容。JSON profile 字段无破坏性变更。
- 数据文件格式：无变化，仍为 0.4.0 引入的 18 列结构（Timestamp,Unit,CH01..CH16）。
- 设备协议行为：无变化，仍使用 ASCII 文本命令协议（@e3/@fd/@f0 等）。

## Install / Upgrade

- 覆盖安装兼容：直接运行 `daq-t1603-0.5.0-amd64-installer.exe` 覆盖旧版本即可，无需先卸载。
- 安装前请先关闭正在运行的旧版本（托盘退出或任务管理器结束 `DAQ-T-1603.exe`）。
- 推荐步骤：
  1. 关闭旧版本。
  2. 运行 `daq-t1603-0.5.0-amd64-installer.exe`。
  3. 启动新版本，确认 GUI 正常出现、设备可连接与采集。
