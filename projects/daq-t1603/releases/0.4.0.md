# DAQ-T-1603 v0.4.0

Release date: 2026-07-24
Package: daq-t1603-0.4.0-amd64-installer.exe

## Summary

本版本提升连接/录制稳健性与现场可排查性：设备状态改为异步推送，UI 状态更新更及时；CSV 录制对禁用通道输出空列保持列对齐；日志面板支持搜索与轮转；适配器扩展支持新 SDK 接口。同时修复了退出阶段 panic、录制会话间禁用通道掩码泄漏，以及错误信息误判等缺陷。

## User-visible Changes

- 设备状态异步推送，UI 状态更新更及时。
- 禁用通道在 CSV 中输出空列（列顺序/表头不变）。
- 日志面板支持关键字搜索，后端日志按大小轮转。
- 通道卡片数值不再闪烁。

## Fixes

- 修复应用退出阶段 readLoop 收尾时状态推送在已关闭 app 上 panic。
- 修复 CSV 录制 Stop→Start 会话间禁用通道掩码泄漏。
- 修复错误信息匹配误判（connection pool exhausted / permission_token 等非目标场景被误判为连接错误）。

## Compatibility

- 配置文件格式：兼容。JSON profile 字段无破坏性变更。
- 数据文件格式：注意变更。CSV 现在对禁用通道输出空列（此前禁用通道整列省略）；按固定列位置解析的旧脚本需确认仍能对齐，建议按表头列名解析。
- 设备协议行为：无变化，仍使用 ASCII 文本命令协议（@e3/@fd/@f0 等）。

## Install / Upgrade

- 覆盖安装兼容：直接运行 `daq-t1603-0.4.0-amd64-installer.exe` 覆盖旧版本即可，无需先卸载。
- 安装前请先关闭正在运行的旧版本（托盘退出或任务管理器结束 `DAQ-T-1603.exe`）。
- 推荐步骤：
  1. 关闭旧版本。
  2. 运行 `daq-t1603-0.4.0-amd64-installer.exe`。
  3. 启动新版本，确认 GUI 正常出现、设备可连接与采集。
