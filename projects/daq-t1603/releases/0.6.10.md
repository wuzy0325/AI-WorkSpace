# DAQ-T-1603 v0.6.10

Release date: 2026-08-13
Package: daq-t1603-0.6.10-amd64-installer.exe

## Summary

设备列表侧栏新增按名称/地址搜索过滤功能，"添加设备"入口从顶栏移到侧栏头部，并区分"暂无设备"与"搜索无匹配"两种空状态，避免设备较多时误重复添加。

## User-visible Changes

- 设备列表侧栏新增搜索框，可按设备名称或 `IP:端口` 过滤（不区分大小写），搜索结果即时刷新设备计数与列表。
- 搜索无匹配时显示"未找到匹配设备"与"清除搜索"按钮；无设备时仍显示原有的"暂无设备"引导。
- "添加设备"入口从顶栏移到侧栏头部（+ 图标），与扫描按钮并列，操作位置更贴近设备列表。
- 中英文文案同步更新（新增搜索/清除相关词条）。

## Fixes

- 无（本版本为 UI 与交互调整）。

## Compatibility

- 配置文件格式兼容。
- CSV 数据格式不变。
- 设备协议命令链不变。

## Install / Upgrade

- 可覆盖安装 0.6.9，无需先卸载或清理用户配置。
- 安装前先关闭正在运行的旧版本。
- 运行 `daq-t1603-0.6.10-amd64-installer.exe`，安装后启动应用确认主窗口正常出现。
