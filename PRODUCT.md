# Product

## Register

product

## Users

Wind tunnel test engineers and technicians operating measurement equipment in lab environments. They configure hardware, run tests, monitor live data, and analyze results. Primary context: a lab workstation with multiple monitors, focused on data accuracy and workflow efficiency rather than visual delight.

## Product Purpose

Industrial desktop tools for data acquisition, calibration, motion control, and probe interpolation in wind tunnel testing. Success means operators complete measurements accurately and efficiently, with minimal cognitive friction and maximum data clarity.

## Brand Personality

Precise, restrained, industrial.

Voice is technical and direct. No marketing flourish, no enthusiasm where data does the talking. Tone shifts only for alerts and errors where clarity and urgency matter.

## Anti-references

Consumer/Mac-style interfaces. No rounded-everything, no light-and-airy pastels, no gradient icons, no frosted-glass marketing surfaces. These are tools for a lab, not a lifestyle product.

## Design Principles

1. **Data first, chrome last.** Every pixel either carries data or supports data legibility. If it doesn't help the operator read or act on information, it doesn't belong.
2. **Restrained palette, deliberate contrast.** Dark theme as default. Color is reserved for data states and alarms, not decoration. Body text must clear WCAG AA at minimum.
3. **High information density without clutter.** Operators work with many channels and values simultaneously. Layouts pack information tightly but maintain visual breathing room through consistent spacing and alignment, not through whitespace.
4. **Consistent spatial grammar.** Fixed layout for desktop at 1280x720 minimum. No mobile breakpoints. Panels, headers, and rails use consistent dimensions defined in tokens, not ad-hoc values.
5. **Motion is functional, never decorative.** Transitions and animations exist only to communicate state change or maintain operator orientation. No hero animations, no parallax, no entrance effects.

## Accessibility & Inclusion

Basic desktop accessibility: keyboard navigable controls, screen reader labels on interactive elements, sufficient color contrast (WCAG AA 4.5:1 body, 3:1 large text). Color is a supplement, not the sole carrier of meaning in data displays.
