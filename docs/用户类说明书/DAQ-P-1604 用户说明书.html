适用软件版本：v0.5.0 ｜ 适用设备：DAQ-P-1604 压力采集器（18 通道）｜ 文档日期：2026-07

1. 软件简介

DAQ-P-1604 压力采集软件是一款 Windows 桌面应用，用于 DAQ-P-1604 压力采集设备的实时监控、波形显示与数据录制。软件通过以太网（TCP/IP）与设备通信，支持多设备并行管理。

主要功能：

  • 18 通道采集：CH01–CH16 压力通道 + CH17 大气压力 + CH18 大气温度；
  • 实时波形：多通道曲线同屏显示，支持按需勾选通道、自定义曲线颜色；
  • 通道监控卡：各通道实时数值大字显示；
  • 数据保存：一键录制为 CSV 文件，可直接用 Excel 打开分析；
  • 设备扫描：一键发现同一网络内的所有 P1604 设备并批量添加；
  • 运行日志：通信与采集过程全程记录，可保存为日志文件用于问题排查；
  • 深/浅主题：适应不同现场光照环境。
设备通讯细节 本说明书面向软件日常操作。设备底层通讯协议（命令字、数据帧格式）请参见同目录《DAQ-P-1604 通讯协议说明书》。

2. 安装与启动

2.1 运行环境

项目要求
操作系统Windows 10 / 11，64 位
运行依赖Microsoft Edge WebView2 运行时（Windows 10/11 通常已内置；如启动失败请先安装 WebView2）
网络与设备处于同一网段的以太网连接（详见第 3 节）

2.2 安装步骤

关闭正在运行的旧版本（如任务栏或任务管理器中存在 DAQ-P-1604.exe / daq-p1604.exe）。
运行安装包 daq-p1604-0.5.0-amd64-installer.exe，按向导完成安装。覆盖安装旧版本无需先卸载。
启动软件，确认主界面正常出现、设备可连接与采集（见第 5 节快速上手）。

2.3 卸载

通过「控制面板 → 程序和功能」卸载，或运行安装目录下的 Uninstall.exe。卸载不会删除用户配置与已保存的 CSV 数据（见第 13 节）。

3. 设备网络连接

软件与设备通过以太网通信，对网络的要求如下：

项目说明
设备数据端口TCP 9000（软件主动向设备发起连接）
设备扫描UDP 广播（设备发现端口 7000，本机监听 7001）
网段要求电脑与设备须处于同一网段（例如设备为 192.168.1.7，电脑可设为 192.168.1.x）
防火墙首次使用若 Windows 防火墙弹出提示，请允许本软件进行网络通信；否则设备扫描与连接会失败
提示 不确定设备是否在线时，可先用 ping 设备IP（如 ping 192.168.1.7）确认网络连通，再在软件中连接。

软件主界面由五个区域组成：顶栏、设备侧栏、监控主区、日志面板（右侧，默认收起）、底栏状态栏。

开始保存 / 停止保存开始将采集数据录制为 CSV（先弹出目录选择框）；录制中变为红色「停止保存」

齿轮图标打开当前选中设备的配置面板（见第 7 节）；无设备时不可用

4.2 设备侧栏

  • 顶部显示设备数量，右侧放大镜按钮为扫描设备（见 6.1）；
  • 每台设备一张卡片：设备名称、IP:端口、状态图标；点击卡片选中设备，监控主区随即显示该设备；
  • 鼠标悬停卡片时出现删除按钮（见 6.4）。

设备状态图标的含义：

状态颜色含义

自上而下为：设备头卡（名称、地址、单位、采样率、状态、连接/断开与配置按钮）、实时波形（见 8.2）、通道监控（见 8.3）。未选中任何设备时显示引导提示页。

4.4 日志面板与底栏

右侧窄条为收起的日志面板（点击展开，见第 10 节）；底部为状态栏（见第 12 节）。

5. 快速上手

完成一次「从开机到保存数据」的标准流程（各步骤的详细说明见后续章节）：

添加设备：点击侧栏放大镜扫描设备，勾选发现的设备后「添加所选」；或点击顶栏 ＋ 手动输入 IP 与端口（见 6.1 / 6.2）。
连接设备：在设备卡片或监控主区点击连接，状态变为「已连接」。开启过「自动连接」的设备会在软件启动时自动连接。
（可选）调整配置：点击配置设置采样频率、压力单位、显示精度与通道（见第 7 节）。
开始采集：点击顶栏开始采集，实时波形与通道数值开始刷新。
开始保存：点击顶栏开始保存，在弹出的系统对话框中选择保存目录，软件即开始写入 CSV。
停止保存 / 停止采集：试验结束后先点停止保存关闭 CSV 文件，再点停止采集。CSV 可直接用 Excel 打开。
建议 保存数据前先让采集运行几秒，确认各通道数值合理后再开始录制，避免录到空文件。

6. 设备管理

6.1 扫描添加设备（推荐）

点击设备侧栏右上角的放大镜按钮，软件会在当前网络内广播发现报文，列出所有在线的 P1604 设备。

扫描结果中每台设备显示：设备名称（默认 DAQ-P-1604-<MAC末6位>）、IP:端口、序列号、MAC 地址与固件版本（FW x.y）。

  • 扫描完成后，未添加过的设备会自动预勾选；勾选的设备可直接在列表中修改名称；
  • 已在设备列表中的设备会置灰并显示「已添加」，不可重复添加；
  • 顶部复选框「添加的设备默认启用开机自动连接」默认勾选：添加后立即尝试连接设备，且以后启动软件时自动连接；
  • 点击添加所选 (N) 完成批量添加；结果未变化时可点重新扫描。

6.2 手动添加设备

点击顶栏 ＋，在弹窗中填写：

字段说明校验规则
设备名称便于识别的名称，如「压力采集器 1」必填，为空提示「请输入设备名称」
IP 地址设备的 IP，如 192.168.1.7必填，为空提示「请输入 IP 地址」
端口设备数据端口默认 9000，范围 1–65535

IP 与端口均与已有设备完全相同时会提示「该设备已添加，请勿重复添加」。输入框中按 Enter 等同点击「添加」。

6.3 连接与断开

  • 选中设备后，点击监控主区头卡的连接按钮；连接成功后状态变为「已连接」，按钮变为「断开」；
  • 连接成功后，软件会以设备硬件当前的压力单位为准自动同步界面单位（日志中有对应记录）；
  • 连接失败时状态变为「错误」，头卡下方显示具体原因（如连接超时、拒绝连接）；
  • 在设备配置中开启自动连接后，软件每次启动都会自动连接该设备（见第 7 节）。

6.4 删除设备

鼠标悬停侧栏中的设备卡片，点击出现的垃圾桶图标，在确认对话框中点「删除」。

注意 删除设备会同时移除其全部配置（通道名称、精度、自动连接等），且不影响已保存的 CSV 数据文件。

7. 设备配置

选中设备后，点击顶栏齿轮或监控主区的配置按钮打开配置面板。面板分「硬件参数」与「通道配置」两区。

7.1 硬件参数

配置项说明取值 / 默认
采样频率设备每秒采样次数，保存时下发设备生效1–1000 Hz 整数，默认 10 Hz
压力单位（全部通道）CH01–CH16 压力通道的显示与保存单位，下发设备psi / Pa / kPa / MPa / kgf/cm²，默认 psi
全局精度（全部通道）数值显示与 CSV 保存的小数位数；点「应用到全部」一键同步到 18 个通道0–6 位小数，默认 3 位
自动连接开启后软件启动时自动连接本设备默认关闭
设备硬件时间戳开启：CSV 与波形使用设备硬件时间戳；关闭：使用电脑系统时间默认开启

7.2 通道配置

  • 共 18 行，标题旁显示「N/18 启用」；每行可设置：通道名称（如「总压」「静压」）、精度（0–6 位小数，覆盖全局精度）、启用开关；
  • 被禁用的通道：不出现在监控界面与波形中，CSV 中对应列留空（保持列对齐）；
  • CH17 固定为大气压力（单位 Pa），CH18 固定为大气温度（单位 ℃），单位不可修改；
  • CH1–CH16 的单位跟随全局「压力单位」设置。

7.3 保存与生效

  • 修改后标题旁出现「未保存」标记；点击保存提交，重置恢复为已保存配置；
  • 硬件相关项（采样频率、压力单位）保存时会下发到设备，底部状态显示「配置已保存并应用到设备」；仅界面类修改显示「配置已保存」；
  • 下发等待约 15 秒无响应会提示「应用配置超时，设备可能无响应」，请检查设备连接后重试。
采集中禁止修改配置 设备处于采集状态时，配置面板全部置灰并提示「采集中不允许变更配置，请先停止采集」。请先在顶栏停止采集再修改。

8. 实时监控

8.1 开始 / 停止采集

设备「已连接」后，点击顶栏开始采集：所有已连接设备同时启动采集，按钮变为红色「停止采集」，底栏「采集状态」变为「运行中」，右侧开始计时。再次点击即停止所有设备的采集。

8.2 实时波形

  • 波形图滚动显示最近约 30 秒的数据；鼠标悬停显示该时刻各通道精确数值（按各通道精度格式化）；
  • 右上角图例显示当前绘制的通道；
  • 默认绘制 CH01–CH16；CH17/CH18 因量纲与量级不同，默认不勾选，可在「通道选择」中手动勾选。

通道选择

点击波形卡片右上角的通道选择按钮，在弹层中勾选需要显示的通道，支持全选 / 全取消。

8.3 通道监控卡

波形下方为每个已启用通道的监控卡片：大号实时值（按通道精度显示）、单位、通道名称；卡片左上角圆点颜色与波形曲线一致。点击卡片上的调色盘按钮可自定义该通道的波形颜色（长久保存）。

8.4 界面刷新率

点击顶栏仪表盘图标可选择界面刷新率（2 / 5 / 10 / 15 / 20 / 30 Hz，默认 10 Hz）。刷新率只影响屏幕显示的流畅度与 CPU 占用，不影响设备采样频率与 CSV 保存的数据密度。

9. 数据保存（CSV）

9.1 开始与停止

确认采集已在运行（底栏「采集状态：运行中」）。
点击顶栏「开始保存」，在弹出的 Windows 目录选择对话框中选择保存目录（可新建文件夹），确认后即刻开始录制。
录制中：顶栏按钮变为红色「停止保存」，底栏「记录状态」变为「保存中」，并显示当前写入的文件名、已记录条数、丢弃条数与文件数。
点击「停止保存」结束录制，文件关闭落盘。

9.2 文件命名与格式

  • 每台设备生成一个 CSV 文件，文件名格式：
    DAQ-P1604-<设备名>-<年月日-时分秒>-<序号>.csv
    示例：DAQ-P1604-DAQ-P-1604-374D87-20260726-084714-001.csv（设备名中的空格与 \/:*?"<>| 等字符会替换为下划线）；
  • 文件在首个数据到达时创建；表头固定 19 列：Timestamp,CH01,…,CH16,CH17_AtmPressure,CH18_AtmTemp；
  • 数值按各通道配置的精度输出；禁用通道对应列留空（列位保持不变，便于多文件对比）；
  • 时间戳带英文单引号前缀（如 '2026-07-26 16:46:03），使 Excel 按文本原样显示、不自动转换格式。

CSV 实际内容示例（真实设备录制）：

Timestamp,CH01,CH02,CH03,CH04,CH05,CH06,CH07,CH08,CH09,CH10,CH11,CH12,CH13,CH14,CH15,CH16,CH17_AtmPressure,CH18_AtmTemp
'2026-07-26 16:46:03,10.7,40.7,-26.2,-38.1,-19.8,-16.7,-23.0,-18.5,-32.4,-44.7,-51.9,-3.0,42.1,-37.1,0.3,-26.5,0.0,0.0
'2026-07-26 16:46:03,10.1,41.0,-25.0,-37.1,-19.4,-17.9,-23.5,-18.1,-32.2,-45.1,-50.9,-2.5,42.9,-37.1,-0.5,-27.4,0.0,0.0

9.3 异常保护

  • 设备断连自动停止：录制中若设备断连，软件自动停止录制并在底栏「录制错误」中注明原因（多设备同时录制时，单台断连只给出警告，其余设备继续录制）；
  • 丢弃计数：磁盘写入过慢导致缓冲队列溢出时，底栏「丢弃」会计数并变黄；正常硬盘上应为 0，持续上升请更换保存目录到更快的磁盘；
  • 软件退出时自动停止录制并关闭文件，不会产生损坏文件。

10. 日志面板

右侧窄条为日志面板，点击展开；再次点击工具栏「收起」或窄条收回。

  • 级别过滤：Debug / Info / Warn / Error，表示「显示的最低级别」（默认 Info，即 Info 及以上）；
  • 分类过滤：全部 / 系统 / 通信（设备命令收发）/ 采集；
  • 保存日志到文件：点击后选择目录，日志持续写入 daq-log_年月日-时分秒.log，再次点击停止。软件每次启动也会自动在 %APPDATA%\daq-p1604\logs 下保存一份运行日志，便于事后排查；
  • 拷贝全部日志：把当前过滤结果复制到剪贴板，可直接粘贴给技术支持；悬停单条日志可复制该条；
  • 清空日志：清空面板（不影响已写入文件的日志）；
  • 面板最多保留最近 500 条；高频通信日志自动合并显示「… 及 N 条同类日志」。

11. 界面主题

点击顶栏月亮 / 太阳图标在浅色（默认）与深色主题间切换，选择结果自动保存，下次启动保持。深色主题适合暗室或夜间试验环境。

14. 常见问题

14.1 扫描不到设备

  • 确认设备已上电、网线连接正常，电脑与设备在同一网段；
  • 检查 Windows 防火墙是否放行了本软件（扫描使用 UDP 广播，被拦截时无结果）；
  • 扫描不到时可改用手动添加（6.2），直接输入设备 IP 与端口 9000。

14.2 连接失败 / 状态显示「错误」

  • 在命令行执行 ping 设备IP 确认网络连通；
  • 确认 IP 与端口（9000）填写正确，且设备未被其他软件占用；
  • 查看头卡下方错误条与日志面板中的具体原因。

14.3 波形或数值不刷新

  • 确认已点击开始采集且底栏为「运行中」；
  • 确认目标通道在「通道选择」中已勾选、且在配置中为「启用」；
  • 界面刷新率被调到很低（如 2 Hz）时刷新会变慢，属正常现象。

14.4 CH17 / CH18 显示 0

CH17（大气压力）、CH18（大气温度）的数值取决于设备是否接入对应传感器。未接入或设备未提供数据时显示 0，不影响 CH01–CH16 的使用。

14.5 CSV 中同一秒出现多行

设备固件的时间戳字段存在已知缺陷，软件统一将 CSV 时间戳截断到秒级以规避。高采样率下同一秒出现多行属正常现象，行序即为采集顺序。

14.6 「开始保存」点击后没有生成文件

  • 确认在目录对话框中点击了「选择文件夹」而非取消；
  • 确认采集正在运行——文件在首个数据到达时才创建；
  • 确认对所选目录有写入权限（避免选择系统保护目录）。

14.7 配置面板全部置灰无法修改

设备正在采集中。请先在顶栏点击「停止采集」，再打开配置面板修改。

技术支持 如遇本说明书未覆盖的问题，请导出日志（日志面板 → 拷贝全部日志，或提供 %APPDATA%\daq-p1604\logs 下对应时段的日志文件）并联系技术支持。

DAQ-P-1604 Pressure Acquisition Software User Manual

Software Version: v0.5.0 | Device: DAQ-P-1604 Pressure Collector (18 channels) | Date: 2026-07

1. Introduction

The DAQ-P-1604 Pressure Acquisition Software is a Windows desktop application for real-time monitoring, waveform display, and data recording of DAQ-P-1604 pressure acquisition devices. It communicates with devices over Ethernet (TCP/IP) and supports parallel management of multiple devices.

Key features:

  • 18-channel acquisition: CH01–CH16 pressure channels + CH17 atmospheric pressure + CH18 atmospheric temperature;
  • Real-time waveforms: multi-channel curves on a single chart, with per-channel visibility toggles and customizable curve colors;
  • Channel monitor cards: large real-time numeric readouts for each channel;
  • Data recording: one-click CSV recording — open directly in Excel for analysis;
  • Device scanning: discover all P1604 devices on the same network and add them in bulk;
  • Runtime logs: full communication and acquisition logging, exportable for troubleshooting;
  • Dark / light theme: adaptable to different ambient lighting conditions.
Device Communication Details This manual covers daily software operation. For the device communication protocol (command set, data frame format), please refer to the DAQ-P-1604 Communication Protocol Manual in the same folder.

5. Quick Start

The standard workflow from power-on to saving data (detailed instructions in later sections):

Add device: click the magnifying glass in the sidebar to scan for devices, check the found devices, then click “Add Selected”; or click the + button on the top bar to manually enter the IP and port (see 6.1 / 6.2).
Connect device: click Connect on the device card or monitor area header; the status changes to “Connected”. Devices with “Auto-connect” enabled will automatically connect on software startup.
(Optional) Adjust configuration: click Config to set sample rate, pressure unit, display precision, and channels (see Section 7).
Start acquisition: click Start Acquire on the top bar; real-time waveforms and channel values begin updating.
Start recording: click Start Record on the top bar, select a save directory in the system dialog, and CSV recording begins immediately.
Stop recording / Stop acquisition: after the experiment ends, first click Stop Record to close the CSV file, then click Stop Acquire. The CSV can be opened directly in Excel.
Recommendation Let the acquisition run for a few seconds before starting recording to confirm that all channel values are reasonable, avoiding empty files.

6. Device Management

6.1 Scan & Add Devices (Recommended)

Click the magnifying glass button in the upper-right corner of the device sidebar. The software broadcasts a discovery message on the current network and lists all online P1604 devices.

Each device in the scan results shows: Device Name (default DAQ-P-1604-<last_6_MAC_chars>), IP:Port, Serial Number, MAC Address, and Firmware Version (FW x.y).

  • After scanning completes, previously unadded devices are automatically pre-checked; checked devices can be renamed directly in the list;
  • Already-added devices are grayed out with “Added” label and cannot be added again;
  • The top checkbox “Enable auto-connect on startup for added devices” is checked by default: devices are immediately connected after adding, and reconnected automatically on future launches;
  • Click Add Selected (N) to batch-add; click Rescan if results haven’t changed.

6.2 Add Device Manually

Click the + button on the top bar and fill in the dialog:

FieldDescriptionValidation
Device NameA recognizable name, e.g. “Pressure Collector 1”Required; empty triggers “Please enter device name”
IP AddressDevice IP, e.g. 192.168.1.7Required; empty triggers “Please enter IP address”
PortDevice data portDefault 9000, range 1–65535

If both IP and port match an existing device, a “Device already added; duplicate not allowed” message is shown. Pressing Enter in an input field is equivalent to clicking “Add”.

6.3 Connect & Disconnect

  • Select a device, then click the Connect button on the monitor area header card; once connected, status changes to “Connected” and the button becomes “Disconnect”;
  • After connecting, the software automatically syncs the interface unit to the device hardware’s current pressure unit (logged accordingly);
  • On connection failure, status becomes “Error” and the specific reason is shown below the header card (e.g., connection timeout, connection refused);
  • Enabling Auto-connect in device configuration causes the software to automatically connect to this device on every startup (see Section 7).

6.4 Delete Device

Hover over a device card in the sidebar, click the trash icon that appears, and confirm deletion in the dialog.

Note Deleting a device also removes all its configuration (channel names, precision, auto-connect, etc.) but does not affect previously saved CSV data files.

8. Live Monitoring

8.1 Start / Stop Acquisition

After a device is “Connected”, click Start Acquire on the top bar: all connected devices begin acquiring simultaneously; the button turns red “Stop Acquire”; the status bar shows “Acquiring”; an elapsed timer starts on the right. Click again to stop acquisition on all devices.

8.2 Real-time Waveform

  • The waveform chart scrolls to show approximately the last 30 seconds of data; hovering the mouse shows precise per-channel values at that moment (formatted per each channel’s precision);
  • The top-right legend shows the currently plotted channels;
  • CH01–CH16 are plotted by default; CH17/CH18 are unchecked by default due to different dimension and magnitude, and can be manually enabled in “Channel Selector”.

Channel Selector

Click the Channel Selector button at the top-right of the waveform card to choose which channels to display; supports select all / deselect all.

8.3 Channel Monitor Cards

Below the waveform, each enabled channel has a monitor card showing: large real-time value (formatted per-channel precision), unit, channel name; the colored dot at the top-left matches the waveform curve color. Click the palette button on a card to customize that channel’s waveform color (persisted permanently).

8.4 UI Refresh Rate

Click the gauge icon on the top bar to select the screen refresh rate (2 / 5 / 10 / 15 / 20 / 30 Hz, default 10 Hz). The refresh rate only affects display smoothness and CPU usage — it does not affect the device sample rate or the data density saved to CSV.

9. Data Recording (CSV)

9.1 Start & Stop

Confirm acquisition is running (status bar shows “Acquiring”).
Click “Start Record” on the top bar, select a save directory in the Windows folder dialog (you can create a new folder), and recording begins immediately once confirmed.
While recording: the top bar button turns red “Stop Record”; the status bar shows “Recording” along with the current file name, recorded row count, dropped count, and file count.
Click “Stop Record” to end recording; the file is closed and flushed to disk.

9.2 File Naming & Format

  • One CSV file per device, naming pattern:
    DAQ-P1604-<device_name>-<YYYYMMDD-HHmmss>-<seq>.csv
    Example: DAQ-P1604-DAQ-P-1604-374D87-20260726-084714-001.csv (spaces and characters \/:*?"<>| in the device name are replaced with underscores);
  • The file is created upon the first data arrival; header is fixed at 19 columns: Timestamp,CH01,…,CH16,CH17_AtmPressure,CH18_AtmTemp;
  • Values are output per each channel’s configured precision; disabled channel columns are left empty (column positions preserved for cross-file comparison);
  • Timestamps are prefixed with a single quote (e.g. '2026-07-26 16:46:03) so that Excel treats them as text without auto-formatting.

9.3 Error Protection

  • Auto-stop on device disconnect: if a device disconnects during recording, the software automatically stops recording for that device and shows the reason in the status bar “Recording Error” (when multiple devices are recording, a single disconnect only produces a warning; other devices continue recording);
  • Drop counter: if the disk write is too slow and the buffer queue overflows, the “Dropped” counter in the status bar increments and turns yellow; on a normal hard drive this should be 0; if it keeps rising, switch the save directory to a faster drive;
  • When the software exits, recording stops automatically and files are properly closed; no corrupted files are left behind.

14. FAQ

14.1 No devices found during scanning

  • Confirm the device is powered on, the network cable is connected, and the computer and device are on the same subnet;
  • Check whether Windows Firewall has allowed this software (scanning uses UDP broadcast; if blocked, no results will appear);
  • If scanning fails, use manual add (6.2) and directly enter the device IP and port 9000.

14.2 Connection fails / Status shows “Error”

  • Run ping <device_IP> in a command prompt to verify network connectivity;
  • Confirm the IP and port (9000) are correct and the device is not occupied by another application;
  • Check the error bar below the header card and the log panel for the specific cause.

14.3 Waveform or values not updating

  • Confirm Start Acquire has been clicked and the status bar shows “Running”;
  • Confirm the target channel is checked in “Channel Selector” and enabled in configuration;
  • If the UI refresh rate is set very low (e.g. 2 Hz), updates will be slow — this is normal.

14.4 CH17 / CH18 display 0

CH17 (atmospheric pressure) and CH18 (atmospheric temperature) values depend on whether the corresponding sensors are connected to the device. If sensors are not connected or the device provides no data, they display 0; this does not affect CH01–CH16 usage.

14.5 Multiple rows with same timestamp in CSV

The device firmware timestamp field has a known limitation; the software uniformly truncates CSV timestamps to second-level precision to work around it. Multiple rows within the same second at high sample rates are normal — row order equals acquisition order.

14.6 No file generated after clicking “Start Record”

  • Confirm you clicked “Select Folder” rather than “Cancel” in the directory dialog;
  • Confirm acquisition is running — the file is created only when the first data point arrives;
  • Confirm you have write permission to the selected directory (avoid system-protected folders).

14.7 Configuration panel is all grayed out

The device is currently acquiring. First click “Stop Acquire” on the top bar, then open the configuration panel to make changes.
