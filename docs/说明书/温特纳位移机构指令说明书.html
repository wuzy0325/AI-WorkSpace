02轴映射关系

温特纳位移机构内部使用 A/B/C/D 表示 4 个物理轴。每个轴是平移轴还是旋转轴，由实际安装的位移台类型决定，需在系统中进行配置。用户发送指令时直接使用 A/B/C/D 即可，无需转换。

轴类型配置说明

每个轴的类型（平移轴 LINEAR 或旋转轴 ROTARY）不是由控制器固定决定的，而是由实际连接的位移台机械结构决定。例如：

• 若 A 轴连接的是直线位移台（丝杆传动），则配置为平移轴，使用导程（lead）参数进行脉冲换算

• 若 D 轴连接的是旋转台（蜗轮蜗杆传动），则配置为旋转轴，使用传动比（gearRatio）参数进行脉冲换算

• 同一套温特纳位移机构，根据所接位移台的不同，4 个轴可以全部是平移轴，也可以全部是旋转轴，或任意组合

轴类型配置仅影响上层软件中的脉冲换算公式，底层温特纳位移机构指令本身不区分轴类型，统一使用脉冲数进行控制。

注意

本说明书面向底层指令使用者，所有示例直接使用温特纳位移机构物理轴名 A/B/C/D。若使用上层软件，软件内部会自动将 X/Y/Z/U 映射为 A/B/C/D，并根据配置的轴类型选择对应的换算公式。

指令 格式 说明

发送BGA启动 A 轴运动
响应:命令执行成功

3.4 停止与急停

指令 格式 说明

5.2 运动状态查询

指令 格式 返回值 说明

示例：查询运动状态
发送TS查询所有轴状态

状态字节解析

状态字节为十进制数值，与 0x80（128）进行按位与运算可判断电机是否运动中：

128 & 0x80 = 128 ≠ 0 → 运动中

0 & 0x80 = 0 → 静止

07脉冲与工程单位换算

温特纳位移机构内部使用脉冲作为位置单位。用户需根据机械参数将 mm（平移轴）或度（旋转轴）换算为脉冲数。

7.1 核心参数

步距角
电机每步转动角度，默认 1.8°/step
细分数
驱动器细分数，默认 1（整步）
导程
丝杆每转移动距离（mm/rev），仅平移轴
传动比
减速机传动比，仅旋转轴

7.2 平移轴换算（A/B/C 轴）

pulsesPerUnit = (360 / stepAngle × microSteps) / lead
结果单位：脉冲/mm
平移轴换算示例

参数：步距角 1.8°，细分数 16，导程 5mm

计算stepsPerRev = 360 / 1.8 = 200每转步数
计算pulsesPerUnit = (200 × 16) / 5 = 640脉冲/mm
换算移动 50mm → 50 × 640 = 32000 脉冲
指令PAA=32000设置目标位置

7.3 旋转轴换算（D 轴）

pulsesPerUnit = (360 / stepAngle × microSteps × gearRatio) / 360
结果单位：脉冲/度
旋转轴换算示例

参数：步距角 1.8°，细分数 16，传动比 10:1

计算stepsPerRev = 360 / 1.8 = 200每转步数
计算pulsesPerUnit = (200 × 16 × 10) / 360 ≈ 88.89脉冲/度
换算旋转 45° → 45 × 88.89 ≈ 4000 脉冲
指令PAD=4000设置目标位置

7.4 快速换算表

轴类型 已知条件 换算公式
平移轴 目标位移（mm） 脉冲 = mm × (360/stepAngle × microSteps / lead)
平移轴 脉冲数 mm = 脉冲 / (360/stepAngle × microSteps / lead)
旋转轴 目标角度（度） 脉冲 = 度 × (360/stepAngle × microSteps × gearRatio / 360)
旋转轴 脉冲数 度 = 脉冲 / (360/stepAngle × microSteps × gearRatio / 360)
