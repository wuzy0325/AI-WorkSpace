角度计算器 - 整合版

使用说明：

  • 上传包含多组α、β、P1-P5数据的CSV文件生成网格图
  • 上传单个点的P1-P5数据，系统将自动选择合适的计算方法
  • 文件格式应为：α,β,P1,P2,P3,P4,P5（第一行为表头）
  • 系统会根据计算结果自动判断使用哪种公式进行最终计算

计算逻辑流程：

步骤1：先用AA1公式计算得到初步角度(α1, β1)

步骤2：根据(α1, β1)的位置判断：

  • 若α1和β1都在±15°之外（四个角区域）→ 直接输出(α1, β1)
  • 若α1在±15°内且β1在±20°之外，或β1在±15°内且α1在±20°之外 → 用AA2公式计算并输出(α2, β2)
  • 其他情况 → 用AA3公式计算并输出(α3, β3)

计算公式：

AA1公式（用于初步计算和四个角区域）：

Kα = (P4 - P5) / [(P2 + P第一大 + P第二大) / 3 - P平均]

Kβ = (P1 - P3) / [(P2 + P第一大 + P第二大) / 3 - P平均]

其中：P第一大、P第二大是P1、P3、P4、P5中的最高和第二高压力

P平均 = (P1 + P3 + P4 + P5) / 4

AA2公式（用于边缘区域）：

Kα = (P4 - P5) / [(P2 + P第一大 + P第二大 + P第三大) / 4 - P平均]

Kβ = (P1 - P3) / [(P2 + P第一大 + P第二大 + P第三大) / 4 - P平均]

其中：P第一大、P第二大、P第三大是P1、P3、P4、P5中的最高、第二高、第三高压力

P平均 = (P1 + P3 + P4 + P5) / 4

AA3公式（用于中心区域）：

Kα = (P4 - P5) / (P2 - P平均)

Kβ = (P1 - P3) / (P2 - P平均)

其中：P平均 = (P1 + P3 + P4 + P5) / 4

1. 上传网格数据文件（必选）

格式：α,β,P1,P2,P3,P4,P5

2. 上传单个点数据（必选）

格式：P1,P2,P3,P4,P5（仅需P1-P5，无需α,β）
