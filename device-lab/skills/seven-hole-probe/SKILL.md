# 七孔探针插值反算算法

> **文档定位**：纯算法说明。给定 7 个压力孔测量值 + 校准数据文件，反算 α、β、Pt、Ps、V、Ma。
> **校准业务流程**（分区判定、点遍历策略、状态机、CSV 录制、UI 交互）见 [spec-seven-hole-calibration.md](../../../projects/wind-daq/docs/specs/spec-seven-hole-calibration.md)。
> **Python 参考实现**：[seven_hole.py](./seven_hole.py)。

---

## 1. 算法概述

### 1.1 输入

| 字段 | 含义 | 单位 |
|------|------|------|
| p1~p7 | 7 个压力孔测量值 | Pa（表压） |
| t | 大气温度 | ℃ |
| pa | 大气压力 | Pa |

### 1.2 校准数据（.prb 文件）

校准数据是预先计算的**系数网格**——在已知角度 (a, b) 处测量压力，计算系数 (ka, kb, cpt, cps)，存入文件：

```
7.prb   — 小角度模式，13×13=169 点，a,b ∈ [-30°, 30°]
1.prb~6.prb — 大角度模式，每孔 4×12=48 点，a ∈ [30°, 45°], b ∈ [0°, 355°]
```

每行格式：`ka  kb  cpt  cps  a  b`

> **命名对应**：.prb 文件中的 `ka, kb, cpt, cps` 对应 spec 的 `Kα, Kβ, K0, Ks`（内区）和 `Kθ[n], Kφ[n], K0[n], Ks[n]`（外区）。spec 用大写 K 记校准系数，Python/Go 代码用小写记插值变量，物理含义相同。

### 1.3 输出

| 字段 | 含义 | 单位 |
|------|------|------|
| a, b | 小角度迎角/侧滑角（内区） | ° |
| θ, φ | 大角度俯仰角/方位角（外区） | ° |
| Pt | 总压 | Pa |
| Ps | 静压 | Pa |
| V | 速度 | m/s |
| Ma | 马赫数 | — |

### 1.4 双模式策略

小角度（θ ≤ 30°）和大角度（θ ≥ 30°）使用**不同的压力系数定义和校准数据**，切换点 θ=30°：

| | 小角度模式 | 大角度模式 |
|---|---|---|
| 中心孔 | P7 | Pn（n∈{1..6}，最大压力孔） |
| 系数定义 | 对称化 cpa/cpb/cpc | 非对称 ka/kb |
| 校准文件 | 7.prb | n.prb |
| 网格范围 | a,b ∈ [-30°, 30°] | a ∈ [30°, 45°], b ∈ [0°, 355°] |
| 输出角度 | 直接 (a, b) | 坐标变换 (θ,φ) → (a,b) |

## 2. 小角度插值模式

### 2.1 计算 ka, kb

```
周向平均压力: p_avg = (p1 + p2 + p3 + p4 + p5 + p6) / 6

// 保护：denom 接近 0 时返回错误
IF |p7 - p_avg| < 1e-12:
    ERROR "p7 与周向平均压力无差异，来流正对探针无法判定方向"

cpa = (p4 - p1) / (p7 - p_avg)
cpb = (p5 - p2) / (p7 - p_avg)
cpc = (p6 - p3) / (p7 - p_avg)

ka = (cpb + cpc) / √3
kb = -(2·cpa + cpb - cpc) / 3
```

### 2.2 校准网格构建

从 7.prb 的 169 个点构建 12×12=144 个四边形，网格步长 5°：

```
a: -30, -25, -20, ..., 25, 30  (13 个点)
b: -30, -25, -20, ..., 25, 30  (13 个点)

四边形 [i,j] 的 4 个顶点:
  X1 = (a=5i-30, b=5j-30)
  X2 = (a=5(i+1)-30, b=5j-30)
  X3 = (a=5(i+1)-30, b=5(j+1)-30)
  X4 = (a=5i-30, b=5(j+1)-30)
```

从校准数据中查找每个顶点对应的 (ka, kb) 值。

### 2.3 四边形定位与距离反比插值 (ka,kb → a,b)

遍历 144 个四边形，对每个四边形计算 4 条边的直线方程，判断 (ka, kb) 是否在四边形内：

```
对四边形顶点 X1~X4（顺序：X1→X2→X3→X4 闭合）:

边1 (X1→X2): k1 = (kb_X2 - kb_X1) / (ka_X2 - ka_X1),  b1 = kb_X1 - k1·ka_X1
边2 (X2→X3): k2 = (kb_X3 - kb_X2) / (ka_X3 - ka_X2),  b2 = kb_X2 - k2·ka_X2
边3 (X3→X4): k3 = (kb_X4 - kb_X3) / (ka_X4 - ka_X3),  b3 = kb_X3 - k3·ka_X3
边4 (X4→X1): k4 = (kb_X1 - kb_X4) / (ka_X1 - ka_X4),  b4 = kb_X4 - k4·ka_X4

判定条件:
  y1 = k1·ka + b1,  y3 = k3·ka + b3
  x2 = (kb - b2) / k2,  x4 = (kb - b4) / k4
  IF y1 ≤ kb ≤ y3 AND x2 ≥ ka ≥ x4:  点在四边形内
```

确定所在四边形后，用距离反比插值：

```
点到四边形 4 条边的距离:
  d1 = |(-k1)·ka + kb - b1| / √(k1² + 1)   // 到边1 (X1→X2, b=5j-30)
  d2 = |(-k2)·ka + kb - b2| / √(k2² + 1)   // 到边2 (X2→X3, a=5(i+1)-30)
  d3 = |(-k3)·ka + kb - b3| / √(k3² + 1)   // 到边3 (X3→X4, b=5(j+1)-30)
  d4 = |(-k4)·ka + kb - b4| / √(k4² + 1)   // 到边4 (X4→X1, a=5i-30)

距离反比插值:
  b = b_X1 + d1/(d1+d3) · 5    // 沿 b 方向
  a = a_X1 + d4/(d2+d4) · 5    // 沿 a 方向
```

> **精度说明**：该公式假设四边形近似矩形。校准网格 5° 步长下变形小，近似可接受。若需更高精度可替换为 Newton-Raphson 迭代（数值雅可比 + 3~5 轮迭代），Go 实现时通过 `Interpolator` 接口预留替换能力。

### 2.4 双线性插值 (a,b → cpt,cps)

定位 (a,b) 在网格中的四边形（`little_cptcps_square`），顶点排列：

```
X4(a=5k, b=5(l+1)) ─── X3(a=5(k+1), b=5(l+1))   [上边]
   │                        │
X1(a=5k, b=5l)      ─── X2(a=5(k+1), b=5l)       [下边]
```

**方向：先沿 a 算斜率，再沿 b 插值**：

```
对 cpt 和 cps 分别计算:

k_下 = (c_X2 - c_X1) / (a_X2 - a_X1)         // = (c_X2 - c_X1) / 5
c_下 = k_下 · a + (c_X1 - k_下 · a_X1)

k_上 = (c_X4 - c_X3) / (a_X4 - a_X3)         // = (c_X4 - c_X3) / -5
c_上 = k_上 · a + (c_X3 - k_上 · a_X3)

c = (c_上 - c_下) · (b - b_X1) / 5 + c_下
```

**边界回退**：当目标角度接近网格边界时（如 `int(a/5) == 9`），k 回退到 (k-1) 区间。

### 2.5 解析求解 Pt, Ps

```
cpt 和 cps 定义:
  cpt = (p7 - Pt) / (Pt - Ps)
  cps = (Ps - p_avg) / (Pt - Ps)

消元求解:
  denom = 1 + cpt + cps
  IF |denom| < 1e-12: ERROR "方程无唯一解"

  Pt = (p7·(1 + cps) + cpt·p_avg) / denom
  Ps = (cps·p7 + p_avg·(1 + cpt)) / denom
```

## 3. 大角度插值模式

### 3.1 计算 ka, kb（以孔 n 为中心，n ∈ {1..6}）

```
p_center = p{n}                              // 中心孔压力
p_left   = 左邻孔压力（n=1 时左邻为 p6）
p_right  = 右邻孔压力（n=6 时右邻为 p1）
p_side   = (p_left + p_right) / 2

denom = p_center - p_side
IF |denom| < 1e-12: ERROR "该扇区无法判定方向"

ka = (p_center - p7) / denom
kb = (p_left - p_right) / denom
```

### 3.2 校准网格构建

每个孔 n 的校准数据（n.prb）构建 3×12=36 个四边形，网格步长 5°：

```
a: 30, 35, 40, 45  (4 个值, 3 个区间)
b: 从 60·n - 30 开始，每次减 5°，共 12 行，角度归一化到 [0, 360)
```

四边形顶点（`big_create_square`）：

```
X4(a=ii, b=jj-5)   ─── X3(a=ii+5, b=jj-5)  [下边]
   │                        │
X1(a=ii, b=jj)     ─── X2(a=ii+5, b=jj)    [上边]
```

> 排列与小角度不同：大角度 X1/X2 在上边（b 较大），小角度 X1/X2 在下边（b 较小）。

### 3.3 边界多边形构建

每个扇区构建 4 条边界线，用于判定 (ka, kb) 是否在扇区内：

| 边界 | a 范围 | b 范围 | 点数 | 反转 |
|------|--------|--------|------|------|
| 边界0 | 30,35,40,45 | 右侧边缘 `ab_dict[n][1]` | 4 | 否 |
| 边界1 | 45 | 13 个 b 值（b = 5·i + 60·n - 90, i=0..12） | 13 | **是** |
| 边界2 | 30,35,40,45 | 左侧边缘 `ab_dict[n][0]` | 4 | **是** |
| 边界3 | 30 | 13 个 b 值（同上） | 13 | 否 |

**边缘 b 角度表**：

| 孔号 n | 左侧边缘 | 中心 | 右侧边缘 |
|--------|----------|------|----------|
| 1 | 330° | 0° | 30° |
| 2 | 30° | 60° | 90° |
| 3 | 90° | 120° | 150° |
| 4 | 150° | 180° | 210° |
| 5 | 210° | 240° | 270° |
| 6 | 270° | 300° | 330° |

> 反转规则的目的是让 4 条边界首尾相接形成闭合多边形，顶点顺序一致，射线法判定才正确。

### 3.4 四边形定位与距离反比插值 (ka,kb → a,b)

与小角度逻辑相同（§2.3），遍历 36 个四边形，用距离反比插值计算 (a, b)。

### 3.5 双线性插值 (a,b → cpt,cps) — 方向与小角度相反

定位 (a,b) 在网格中的四边形（`big_cptcps_square`），顶点排列：

```
X1(a=5k, b=5l)      ─── X2(a=5k, b=5(l+1))       [左边]
   │                        │
X4(a=5(k+1), b=5l)  ─── X3(a=5(k+1), b=5(l+1))   [右边]
```

> 排列与 §3.2 的 `big_create_square` 不同！`big_cptcps_square` 构造的四边形 X1/X2 在左边（a 较小），X3/X4 在右边（a 较大）。

**方向：先沿 b 算斜率，再沿 a 插值**（与小角度 §2.4 相反）：

```
对 cpt 和 cps 分别计算:

k_左 = (c_X2 - c_X1) / (b_X2 - b_X1)         // = (c_X2 - c_X1) / 5
c_左 = k_左 · b + (c_X1 - k_左 · b_X1)

k_右 = (c_X4 - c_X3) / (b_X4 - b_X3)         // = (c_X4 - c_X3) / -5
c_右 = k_右 · b + (c_X3 - k_右 · b_X3)

c = (c_右 - c_左) · (a - a_X1) / 5 + c_左
```

**边界回退**：
- `int(a/5) == 9`（a ∈ [45,50]）→ a 回退到 (k-1) 区间
- `int(b/5) == 71`（b ∈ [355,360]）→ b 边界处理为 X1.b=355, X2.b=0（跨 360° 周期）

### 3.6 解析求解 Pt, Ps

```
cpt = (p_center - Pt) / (Pt - Ps)
cps = (Ps - p_side) / (Pt - Ps)

denom = 1 + cpt + cps
IF |denom| < 1e-12: ERROR "方程无唯一解"

Pt = (p_center·(1 + cps) + cpt·p_side) / denom
Ps = (cps·p_center + p_side·(1 + cpt)) / denom
```

### 3.7 坐标变换 (θ,φ → a,b)

大角度模式下，校准数据中的 a 表示 θ（俯仰角），b 表示 φ（方位角）。最终输出需转换为标准角度 (a, b)：

```
θ = a（从校准数据插值得到）
φ = b（从校准数据插值得到）

IF |θ| < 89.5:
    tan_a = tan(radians(θ)) · sin(radians(φ))
    tan_b = tan(radians(θ)) · cos(radians(φ))
    a = -degrees(atan(tan_a))   // 负号来自方位角从 -Z 看顺时针的约定
    b =  degrees(atan(tan_b))
ELSE:
    a = -θ                       // θ 接近 90° 时退化
    b = φ
```

> **负号说明**：a 公式中的负号是因为方位角从 +Y 起算、从探针尾部看（-Z 方向）顺时针递增。α+ 对应 φ=270°（+X 方向），α- 对应 φ=90°（-X 方向）。

### 3.8 越界外推

当 (ka, kb) 不在任何扇区边界内时，沿边界外推：

```
1. 使用第一个候选孔的边界1（a=45°，已 reverse，b 降序）
2. 取 kb 范围: [kb_min, kb_max] = [list[0].kb, list[12].kb]

3. 沿 kb 方向线性插值 b 角度:
   IF kb > kb_max OR kb < kb_min:
       b = 孔 n 的中心角度 (0, 60, 120, 180, 240, 300)
   ELSE:
       找到 i 使 kb ∈ [list[i].kb, list[i+1].kb]
       b = -5 · (kb - list[i].kb) / (list[i+1].kb - list[i].kb) + list[i].b

4. 沿 kb 方向线性外推 a 角度（替代原硬编码 45°）:
   IF kb 在 [kb_min, kb_max] 范围内:
       沿边界1 (a=45°) 和边界3 (a=30°) 同 b 位置的 kb 值线性外推
       a = 30 + 15 · (kb - kb_30) / (kb_45 - kb_30)
       a = clamp(a, 30, 50)   // 最大外推 5°
   ELSE:
       a = 45   // 退化为原方案
```

**负号来源**：边界1 被 `reverse()` 后 b 降序（如孔1：b=30,25,...,0,355,...,330），b_{i+1} = b_i - 5。线性插值公式中的负号补偿降序方向——当 kb=kb_i 时 b=b_i，当 kb=kb_{i+1} 时 b=b_i-5=b_{i+1}。

## 4. 射线法多边形判断

用于判定 (ka, kb) 是否在边界多边形内（小角度：判定用 7.prb 还是大角度；大角度：判定属于哪个扇区）。

```
FUNCTION point_in_polygon(ka, kb, polygon_edges):
    // polygon_edges = 4 条边界拼接成的闭合顶点列表
    inside = false
    FOR 每条边 (p1, p2):
        IF (kb == p1.y AND kb == p2.y) AND (ka in [min(p1.x,p2.x), max(p1.x,p2.x)]):
            RETURN 0  // 在边界上
        IF min(p1.y, p2.y) < kb <= max(p1.y, p2.y) AND ka <= max(p1.x, p2.x):
            IF p1.y != p2.y:
                x_inters = (kb - p1.y) * (p2.x - p1.x) / (p2.y - p1.y) + p1.x
                IF p1.x == p2.x OR ka <= x_inters:
                    inside = !inside
    RETURN inside ? 1 : -1  // 1=内部, -1=外部
```

## 5. 速度与马赫数计算

```
FUNCTION 计算速度马赫数(Pt, Ps, t, pa):
    常数: R = 287.06 J/(kg·K), γ = 1.4

    T_k = t + 273.15                           // ℃ → K

    // Pt < Ps 是物理异常（总压不应低于静压，反向流或传感器故障）
    IF Pt < Ps:
        ERROR "Pt < Ps，总压低于静压"
        // 调用方可根据场景决定降级策略（取绝对值 / 跳过该点）

    ΔP = Pt - Ps                               // 动压
    速度: V = √( 2 · ΔP · R · T_k / pa )       // m/s

    压力比 = (Pt + pa) / (Ps + pa)
    IF 压力比 < 1:
        ERROR "压力比 < 1，无法计算马赫数"
    马赫数: Ma = √( 5 · ((压力比)^(0.4/1.4) - 1) )
```

> Python 原代码使用 `math.fabs` 取绝对值掩盖了 Pt < Ps 的异常——Go 实现应返回错误而非静默继续。

## 8. Go 实现注意事项

### 8.1 浮点比较

```
const EPSILON = 1e-6
func floatEqual(a, b float64) bool { return math.Abs(a-b) < EPSILON }
```

### 8.2 角度归一化

```
func normalizeAngle360(angle float64) float64 {
    angle = math.Mod(angle, 360)
    if angle < 0 { angle += 360 }
    return angle
}
```

### 8.3 接口预留

距离反比插值通过接口定义，方便后续替换为 Newton-Raphson：

```
type Interpolator interface {
    InterpolateKaKb(ka, kb float64, grid []Quad) (a, b float64, err error)
}
```

### 8.4 错误处理

所有函数统一返回 `(result, error)`，错误信息包含上下文：

```
// 好: 包含阶段 + 孔号 + 具体值
fmt.Errorf("大角度模式孔%d: |denom|=%.6e < 1e-12", n, denom)
```

### 8.5 校准数据缓存

校准数据在运行时不变，使用 `sync.Once` 加载并缓存。`big_create_square` 和 `big_create_line` 的构建结果（四边形列表、边界多边形）在构造时预计算，避免每次调用重新构建。
